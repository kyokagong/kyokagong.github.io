16.4.1 30 行最小 Agent（单工具 + ReAct 单步）

"""
ch16.4 — 个人助理最小 Agent（30 行）
- 1 个工具：get_weather
- ReAct 单步循环
- mock LLM（无需 API key）
"""
import json
from typing import Any, Dict, List

# ===== 工具定义（OpenAI Function Calling schema）=====
TOOLS = [{
    "type": "function",
    "function": {
        "name": "get_weather",
        "description": "查询指定城市的天气",
        "parameters": {
            "type": "object",
            "properties": {"city": {"type": "string", "description": "城市名，如'北京'"}},
            "required": ["city"],
        },
    },
}]

# ===== 工具实现（mock）=====
def get_weather(city: str) -> str:
    # mock：固定返回
    return json.dumps({"city": city, "temp": 22, "condition": "晴"}, ensure_ascii=False)

# ===== mock LLM（按用户消息关键词决定工具调用）=====
def mock_llm(messages: List[Dict[str, Any]]) -> Dict[str, Any]:
    last = messages[-1]["content"]
    if "天气" in last and "tool" not in [m["role"] for m in messages]:
        return {"role": "assistant", "content": None, "tool_calls": [{
            "id": "call_001", "type": "function",
            "function": {"name": "get_weather", "arguments": json.dumps({"city": "北京"})},
        }]}
    return {"role": "assistant", "content": f"已为您查询：{last}"}

# ===== Agent 主循环（ReAct 单步）=====
def agent(user_msg: str) -> str:
    msgs = [{"role": "user", "content": user_msg}]
    resp = mock_llm(msgs)
    if resp.get("tool_calls"):
        for tc in resp["tool_calls"]:
            args = json.loads(tc["function"]["arguments"])
            result = get_weather(**args) if tc["function"]["name"] == "get_weather" else "{}"
            msgs.append({"role": "tool", "tool_call_id": tc["id"], "content": result})
        return mock_llm(msgs)["content"]
    return resp["content"]

# ===== 测试 =====
if __name__ == "__main__":
    print(agent("北京天气？"))  # → 已为您查询：北京天气？

输出（mock 跑通）：

已为您查询：北京天气？

16.4.2 mock LLM + 真 OpenAI 双模式

生产模式（真 OpenAI）：

"""
ch16.4.2 真 OpenAI Function Calling（10 行，需 OPENAI_API_KEY）
"""
from openai import OpenAI
client = OpenAI()

def agent_openai(user_msg: str) -> str:
    msgs = [{"role": "user", "content": user_msg}]
    resp = client.chat.completions.create(model="gpt-4o-mini", messages=msgs, tools=TOOLS)
    if resp.choices[0].message.tool_calls:
        msgs.append(resp.choices[0].message)
        for tc in resp.choices[0].message.tool_calls:
            args = json.loads(tc.function.arguments)
            result = get_weather(**args)
            msgs.append({"role": "tool", "tool_call_id": tc.id, "content": result})
        return client.chat.completions.create(model="gpt-4o-mini", messages=msgs).choices[0].message.content
    return resp.choices[0].message.content

if __name__ == "__main__":
    print(agent_openai("北京天气？"))

对比：mock 模式 30 行全跑通；真 OpenAI 模式需 API key + 10 行。

mock 模式 vs 真 LLM 模式：mock_llm 仅按关键词决策，遇到未列出的关键词会返回"无工具调用"。生产必须切真 OpenAI / Anthropic / Google——真 LLM 能基于语义判断（"明天有什么安排" 也会触发 get_calendar）。

16.4.3 Function Calling JSON Schema 设计原则

原则说明示例
description 详细LLM 看 description 决定何时调用"查询指定城市的天气（mock 模式返回固定数据）"
required 严格必填字段必标，否则 LLM 可能漏传["city"]
类型明确integer / string / boolean / array / object"city": {"type": "string"}
枚举可选限定值时用 enum"city": {"type": "string", "enum": ["北京", "上海", "深圳"]}
避免复杂嵌套嵌套 object 难调试，扁平参数优先❌ {"address": {"city": ..., "district": ...}} ✅ {"city": ..., "district": ...}

16.4.4 ch07 Function Calling 协议 ↔ ch16 Schema 设计映射

回顾 ch07 §7.4 三大协议（OpenAI / Anthropic / Google），ch16 采用的是 OpenAI Function Calling 协议——原因：

维度OpenAI FCAnthropic Tool UseGoogle FC
ch16 选这个✅（主流 + LLM 兼容好）备选（中文好 + 长 context）不选（MapComposite dict 转换坑）
协议格式tools: [{type: "function", function: {...}}]tools: [{name, description, input_schema}]tools: [{function_declarations: [...]}]
Schema 规范JSON Schema 子集JSON Schema 全集OpenAPI 3.0 子集
tool_call 返回tool_calls: [{id, type, function: {name, arguments}}]content: [{type: "tool_use", id, name, input}]function_call: {name, args}
ch16 5 工具代码量30 行（直接 **args 解构）需 block.input 属性访问（ch07 §7.4.2）需 dict(fc.args) 转换（ch07 §7.4.3）

ch16 5 工具 schema 设计原则（基于 ch07 §7.6）：

  1. name 简短 snake_case：get_calendar / send_email / set_reminder / call_api / manage_todo
  2. description 第一人称视角：LLM 看 description 决定何时调用 → 用"查询 / 发送 / 设置 / 调用 / 管理"动词开头
  3. parameters 扁平化：避免嵌套 object（如 {"address": {"city": ...}} → {"city": ...}），降低 LLM 漏传字段概率
  4. required 严格：只标必填，可选字段不标（如 cc 不标 required）
  5. enum 限定可选值：如 action: ["add", "list", "complete"]，防止 LLM 自由发挥

16.5.2 Function Calling handler 50 行

"""
ch16.5.2 — Function Calling handler 50 行（5 工具全 mock）
"""
import json
import re
from datetime import datetime, timedelta
from typing import Any, Dict, List

# ===== 5 工具 mock 实现 =====
def get_calendar(date_range: str = "today", max_results: int = 10) -> str:
    """查日历 mock：返回固定 3 场会议"""
    events = [
        {"time": "09:00", "title": "产品评审", "attendees": ["张三", "李四"]},
        {"time": "14:00", "title": "客户对接", "attendees": ["客户 A"]},
        {"time": "16:30", "title": "周会", "attendees": ["团队"]},
    ]
    return json.dumps({"date": date_range, "events": events[:max_results]}, ensure_ascii=False)

def send_email(to: str, subject: str, body: str, cc: str = "") -> str:
    """发邮件 mock：仅打印"""
    print(f"[EMAIL MOCK] to={to} cc={cc} subject={subject}\n  body={body[:50]}...")
    return json.dumps({"status": "sent", "to": to}, ensure_ascii=False)

def set_reminder(time: str, content: str) -> str:
    """设置提醒 mock：解析 time，返回 reminder_id"""
    m = re.match(r"(\d+)([mh])", time)
    if m:
        delta = timedelta(minutes=int(m.group(1))) if m.group(2) == "m" else timedelta(hours=int(m.group(1)))
        fire_at = (datetime.now() + delta).strftime("%H:%M")
    else:
        fire_at = time  # 视为绝对时间
    return json.dumps({"reminder_id": "r_" + str(hash(content))[:6], "fire_at": fire_at}, ensure_ascii=False)

def call_api(url: str, method: str = "GET", params: Dict = None, body: Dict = None) -> str:
    """调 API mock：返回固定 JSON"""
    if "weather" in url:
        return json.dumps({"city": params.get("city", "未知"), "temp": 22, "condition": "晴"}, ensure_ascii=False)
    if "price" in url:
        return json.dumps({"symbol": "BTC", "price": 65000}, ensure_ascii=False)
    return json.dumps({"url": url, "method": method, "status": "ok"}, ensure_ascii=False)

def manage_todo(action: str, item: str = "", priority: str = "normal") -> str:
    """待办管理 mock：内存 dict 存"""
    if not hasattr(manage_todo, "_todos"):
        manage_todo._todos = {}
    if action == "add":
        manage_todo._todos[item] = {"priority": priority, "created": datetime.now().isoformat()}
        return json.dumps({"status": "added", "item": item}, ensure_ascii=False)
    elif action == "list":
        return json.dumps({"todos": list(manage_todo._todos.keys())}, ensure_ascii=False)
    elif action == "complete":
        manage_todo._todos.pop(item, None)
        return json.dumps({"status": "completed", "item": item}, ensure_ascii=False)
    return json.dumps({"status": "unknown action"}, ensure_ascii=False)

# ===== Function Calling handler =====
TOOL_MAP = {
    "get_calendar": get_calendar,
    "send_email": send_email,
    "set_reminder": set_reminder,
    "call_api": call_api,
    "manage_todo": manage_todo,
}

def execute_tool_call(tool_call: Dict[str, Any]) -> str:
    """统一的工具执行入口（OpenAI tool_call dict 格式）"""
    func_name = tool_call["function"]["name"]
    func_args = json.loads(tool_call["function"]["arguments"])
    if func_name not in TOOL_MAP:
        return json.dumps({"error": f"unknown tool: {func_name}"}, ensure_ascii=False)
    return TOOL_MAP[func_name](**func_args)

if __name__ == "__main__":
    # 测试 5 工具

class ConversationMemory:
    """短期记忆：维护 messages 列表，append-only"""

    def __init__(self, max_tokens: int = 8000):
        self.messages: List[Dict[str, Any]] = []
        self.max_tokens = max_tokens

    def add(self, message: Dict[str, Any]) -> None:
        self.messages.append(message)
        # 超限则压缩（保留 system + 最近 5 轮）
        if self._estimate_tokens() > self.max_tokens:
            self._compress()

    def get_messages(self) -> List[Dict[str, Any]]:
        return self.messages.copy()

    def _estimate_tokens(self) -> int:
        # 粗估：1 token ≈ 1.5 中文字 / 0.75 英文单词
        return sum(len(str(m)) for m in self.messages) // 2

    def _compress(self) -> None:
        # 保留 system message + 最近 5 轮
        if len(self.messages) > 6:
            self.messages = [self.messages[0]] + self.messages[-5:]

    def _load(self) -> Dict:

        return {"user_name": "user", "work_hours": {"start": "09:00", "end": "18:00"}}

        self._save()

    def _save(self) -> None:

16.6.4 记忆压缩策略 3 种方案

短期记忆不可能无限增长（context window 限制），ch16 采用 滑动窗口 + 摘要压缩 双策略（参考 ch08 §8.7）：

策略实现适用场景
滑动窗口只保留最近 N 轮（如 5 轮）短对话（< 20 轮）
摘要压缩超 N 轮时调 LLM 总结前 N 轮为 1 段长对话（> 20 轮）
关键保留用关键词匹配保留关键轮（如包含 "会议" / "决定"）重要对话（决策类）

ch16 实现（简化版）：滑动窗口 + 关键保留

class ConversationMemory:
    def __init__(self, max_turns=10):
        self.messages = []
        self.max_turns = max_turns
        self.keywords = {"决定", "结论", "要做", "会议", "截止"}

    def add(self, msg):
        self.messages.append(msg)
        # 超 max_turns 则压缩（保留 system + 含关键词 + 最近 3 轮）
        if len(self.messages) > self.max_turns:
            system = self.messages[0]
            recent = self.messages[-3:]
            # 关键轮保留
            key_msgs = [m for m in self.messages[1:-3] if any(kw in str(m) for kw in self.keywords)]
            self.messages = [system] + key_msgs + recent

为什么 ch16 用滑动窗口 + 关键保留 而不是摘要压缩：

  • 复杂度：摘要压缩需要 LLM 调一次（增加 1-3s 延迟）
  • 教学：滑动窗口逻辑简单，读者 5 分钟看懂
  • ch17-19 升级：ch17 代码助手（长对话）才需要摘要压缩，ch16 简化处理

16.8 错误处理 + 5 大坑

16.8.1 5 大错误类型（ch16 实测）

错误类型触发条件修复
工具调用失败函数抛异常（如网络超时）try/except 包裹，返回 error JSON
Schema 校验失败LLM 传了 schema 不允许的字段用 pydantic 严格校验，未知字段报错
LLM 超时OpenAI API 30s+ 未响应加 timeout=30，超时返回友好错误
速率限制OpenAI 429 错误加 retry + 退避（5s / 30s / 60s）
PII 泄露用户在消息里写了手机号 / 身份证发送前正则脱敏（替换为 ***）

16.8.2 错误处理代码 + 重试机制

"""
ch16.8.2 — 错误处理 + 重试机制（30 行）
"""
import time
import re

def execute_tool_safe(func_name: str, args: Dict[str, Any], max_retry: int = 3) -> str:
    """安全的工具调用：try/except + retry"""
    for attempt in range(max_retry):
        try:
            return TOOL_MAP[func_name](**args)
        except Exception as e:
            if attempt == max_retry - 1:
                return json.dumps({"error": str(e), "tool": func_name, "args": args}, ensure_ascii=False)
            time.sleep(2 ** attempt)  # 指数退避

def pii_mask(text: str) -> str:
    """PII 脱敏：手机号 / 邮箱 / 身份证"""
    text = re.sub(r"1[3-9]\d{9}", "1XX-XXXX-XXXX", text)  # 手机号
    text = re.sub(r"[\w.-]+@[\w.-]+", "***@***.***", text)  # 邮箱
    text = re.sub(r"\d{17}[\dXx]", "XXXXXXXXXXXXXXXXX", text)  # 身份证
    return text

16.8.3 PII 脱敏示例

# → 我的手机是 1XX-XXXX-XXXX，邮箱 ***@***.***

为什么要脱敏：用户输入会作为 LLM context 上传到 OpenAI，PII 可能在 LLM 日志里残留。

16.10.3 加多 Agent（升级到 ch11 Supervisor 模式）

# ch18 多 Agent 架构示意（5 Agent）
class SupervisorAgent:
    def __init__(self):
        self.researcher = ResearcherAgent()
        self.writer = WriterAgent()
        self.reviewer = ReviewerAgent()

    def delegate(self, query):
        # Supervisor 根据 query 决定委派给哪个 Agent
        if "research" in query:
            return self.researcher.run(query)
        if "write" in query:
            return self.writer.run(query)
        # 默认：researcher 查资料 → writer 写文档
        research = self.researcher.run(query)
        return self.writer.run(research)

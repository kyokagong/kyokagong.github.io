18.1.5 工程意义：多 Agent 范式在生产中的 3 个真实场景

  1. 学术论文综述：跑 ArXiv 检索 50 篇 → 阅读 → 摘要 → 写综述。ch18 主用例。
  2. 企业竞品分析：搜 30 个产品页 → 抽取特性 → 写对比报告。同样的 Supervisor + Researcher + Writer。
  3. 法律 / 政策研究：搜法规库 + 案例库 → 抽取条文 → 写摘要。同样的 4 Agent 拓扑，但工具集换成法规 API。

ch18 给读者的是一个可复用的"调研类项目骨架"，而不是绑死在 ArXiv 上的玩具。

阶段SupervisorResearcherWriterReviewer

1. 提问A/RCII

18.2.3 终止条件设计

Supervisor 何时喊停？三个终止条件，任一满足即停：

  1. 所有阶段完成 + Reviewer 通过
  2. 轮次超过 8（防止死循环）
  3. 总 token 超过 200K（成本控制）

18.3 30 行 Hello World：最小 Supervisor + 1 Worker

我们先实现最小骨架：1 个 Supervisor + 1 个 Researcher Worker，能把用户问题拆成子问题、调用 1 次 arxiv_search、返回 1 条引用。这段代码 30 行，是 ch18 整个多 Agent 系统的种子。

18.3.1 supervisor.py 第 1 版（30 行）

# ch18 / supervisor.py — 最小骨架
# 注：以下代码为 mock 模式（call_llm 返回固定 JSON），无需 API key；切真实 LLM 见 §18.9.4a
import json, re

# ===== 1. 提示词模板（30 行业务逻辑）=====
SUPER_PROMPT = """你是研究 Supervisor。任务：把用户问题拆成 1-3 个子问题。
用户问题：{question}
输出 JSON：{{"sub_questions": ["...", "..."]}}"""

WORKER_PROMPT = """你是 Researcher。任务：调用 arxiv_search 找 1 篇最相关的论文。
子问题：{sub_q}
输出 JSON：{{"cite_id": "arxiv:XXXX.YYYYY", "title": "..."}}"""

def call_llm(prompt: str) -> str:
    # mock 模式：返回固定 JSON 让骨架可跑通
    if "Supervisor" in prompt:
        q = re.search(r"用户问题：(.+)", prompt).group(1)
        return json.dumps({"sub_questions": [f"子问题1：{q}", f"子问题2：{q} 的应用"]}, ensure_ascii=False)
    else:
        sq = re.search(r"子问题：(.+)", prompt).group(1)
        return json.dumps({"cite_id": "arxiv:2501.12345", "title": f"关于 {sq} 的论文"}, ensure_ascii=False)

def run(question: str) -> dict:
    plan = json.loads(call_llm(SUPER_PROMPT.format(question=question)))
    cites = [json.loads(call_llm(WORKER_PROMPT.format(sub_q=sq))) for sq in plan["sub_questions"]]
    return {"plan": plan, "cites": cites}

if __name__ == "__main__":
    print(json.dumps(run("Agent 综述"), ensure_ascii=False, indent=2))

18.4.3 tools.py 关键 handler（5 个新增）

# ch18 / tools.py — 5 个新增工具 handler
import urllib.request, urllib.parse, json, time, re, os
from pathlib import Path

CITE_DIR = Path("./cites")
CITE_DIR.mkdir(exist_ok=True)

def arxiv_search(query: str, max_results: int = 5) -> list:
    """arXiv API 公开端点（无 key 限速 200 req/5min）"""
    base = "http://export.arxiv.org/api/query"
    params = {"search_query": query, "max_results": max_results}
    url = f"{base}?{urllib.parse.urlencode(params)}"
    with urllib.request.urlopen(url, timeout=10) as r:
        body = r.read().decode("utf-8")
    ids = re.findall(r"<id>(\d+\.\d+)</id>", body)
    titles = re.findall(r"<title>(.+?)</title>", body, re.DOTALL)
    return [{"cite_id": f"arxiv:{i}", "title": t.strip()} for i, t in zip(ids, titles)]

def web_search(query: str, max_results: int = 5) -> list:
    """mock web 搜索（真实用 SerpAPI/Bing API；mock 模式返回空避免付费）"""
    return [{"cite_id": f"web:{i}", "title": f"网页 {i}：{query}", "url": f"https://example.com/{i}"} for i in range(max_results)]

def pdf_download(cite_id: str) -> str:
    """下载 PDF 到 cites/ 沙箱目录（限速 1 req/sec）"""
    if not cite_id.startswith("arxiv:"):
        return f"ERROR: only arxiv supported, got {cite_id}"
    arxiv_id = cite_id.replace("arxiv:", "")
    url = f"https://arxiv.org/pdf/{arxiv_id}.pdf"
    dest = CITE_DIR / f"{arxiv_id}.pdf"
    if dest.exists():
        return f"CACHED: {dest}"
    time.sleep(1.0)  # 限速
    try:
        urllib.request.urlretrieve(url, dest)
        return f"DOWNLOADED: {dest} ({dest.stat().st_size} bytes)"
    except Exception as e:
        return f"ERROR: {e}"

def cite_add(cite_id: str, title: str, claim: str) -> dict:
    """加引用到引用表（写入 memory DB）"""
    record = {"cite_id": cite_id, "title": title, "claim": claim, "added_at": time.time()}
    db_path = CITE_DIR / "citations.jsonl"
    with open(db_path, "a", encoding="utf-8") as f:
        f.write(json.dumps(record, ensure_ascii=False) + "\n")
    return record

def claim_verify(claim: str, cite_id: str) -> dict:
    """校验声明是否在引用 cite_id 中（mock：keyword 匹配）"""
    pdf_path = CITE_DIR / f"{cite_id.replace('arxiv:', '')}.pdf"
    if not pdf_path.exists():
        return {"verified": False, "reason": f"PDF not found: {pdf_path}"}
    keywords = set(claim.split())
    return {"verified": True, "keywords_matched": len(keywords), "cite_id": cite_id}

真实 vs mock 模式说明：

- arxiv_search 是真 API（arXiv 公开无 key），可直接跑

- web_search 是mock（真实需要 SerpAPI key，月费 $50）—— mock 模式让本地能跑，部署时换真实 API

- pdf_download 是真下载（限速 1 req/sec）

- cite_add / claim_verify 是真本地 IO（写 cites/ 沙箱目录）

18.5.7 Supervisor 主循环（100 行完整版）

# supervisor.py — 完整版（ch18 真实可跑）
import json
from researcher import ResearcherAgent
from writer import WriterAgent
from reviewer import ReviewerAgent
from memory import MemoryStack

class Supervisor:
    def __init__(self, llm):
        self.llm = llm
        self.researcher = ResearcherAgent(llm)
        self.writer = WriterAgent(llm)
        self.reviewer = ReviewerAgent(llm)
        self.memory = MemoryStack()
        self.max_loops = 8
        self.max_tokens = 200_000
    
    def run(self, question: str) -> dict:
        # 阶段 1：拆解
        plan = self._plan(question)
        self.memory.short_term.append({"role": "supervisor", "content": plan})
        
        all_cites = []
        for loop in range(self.max_loops):
            # 阶段 2-3：检索 + 阅读
            for sq in plan["sub_questions"]:
                cites = self.researcher.search(sq)
                all_cites.extend(cites)
                self.memory.long_term_db["cites"].extend(cites)
            
            # 阶段 4：写作
            outline = self._make_outline(plan["sub_questions"])
            draft = self.writer.draft_section(outline, all_cites)
            
            # 阶段 5：校对
            verdict = self.reviewer.check(draft, all_cites)
            if verdict["pass"]:
                return {"draft": draft, "cites": all_cites, "loops": loop + 1}
            else:
                # 驳回：Writer 根据 fixes 重写
                draft = self.writer.draft_section(verdict["fixes"], all_cites)
        
        return {"draft": draft, "cites": all_cites, "loops": self.max_loops, "stop_reason": "max_loops"}
    
    def _plan(self, q):
        prompt = f"拆解问题为 1-3 个子问题：{q}\n输出 JSON：{{\"sub_questions\": []}}"
        return json.loads(self.llm.complete(prompt, system=SUPER_SYS))
    
    def _make_outline(self, sub_qs):
        return "\n".join(f"## {i+1}. {sq}" for i, sq in enumerate(sub_qs))

18.7.2 引用三元组（cite_id / source_url / claim）

# 三元组结构 + 冲突检测（ch18 §18.7 核心）
def check_conflict(graph, claim_a, claim_b, threshold=0.7):
    """两个 claim 关键词重叠 > 0.7 视为同一论点的不同来源"""
    words_a = set(claim_a.lower().split())
    words_b = set(claim_b.lower().split())
    overlap = len(words_a & words_b) / max(len(words_a | words_b), 1)
    if overlap > threshold:
        return {"conflict": False, "overlap": overlap, "verdict": "agree"}
    elif overlap < 0.2:
        return {"conflict": True, "overlap": overlap, "verdict": "disagree"}
    else:
        return {"conflict": False, "overlap": overlap, "verdict": "neutral"}

18.8.3 委派 token 代码（30 行）

# ch18 / security.py — 委派 token 签发 + 验证
import hmac, hashlib, time, json

SECRET = b"ch18-supervisor-secret-do-not-use-in-prod"

def issue_token(agent: str, scope: str, ttl: int = 3600) -> str:
    payload = {"agent": agent, "scope": scope, "exp": int(time.time()) + ttl}
    body = json.dumps(payload, sort_keys=True)
    sig = hmac.new(SECRET, body.encode(), hashlib.sha256).hexdigest()[:16]
    return f"{body}|{sig}"

def verify_token(token: str, expected_agent: str, expected_scope: str) -> bool:
    try:
        body, sig = token.rsplit("|", 1)
        payload = json.loads(body)
        if payload["agent"] != expected_agent:
            return False
        if payload["scope"] != expected_scope:
            return False
        if payload["exp"] < time.time():
            return False
        expected_sig = hmac.new(SECRET, body.encode(), hashlib.sha256).hexdigest()[:16]
        return hmac.compare_digest(sig, expected_sig)
    except Exception:
        return False

18.11.4 概念速查（22 术语）

术语1 句话定义
:---:---
**Supervisor**多 Agent 系统的中央调度器，决定派活和终止
**Worker**受 Supervisor 调度的子 Agent
**RACI**责任分配矩阵（Responsible/Accountable/Consulted/Informed）
**ArXiv API**arXiv 论文公开 API（限速 200 req/5min）
**引用管理**研究中追踪每条事实来源的机制
**cite_id**引用唯一标识（arxiv:XXXX.YYYYY 或 web:XXXX）
**委派 token**Supervisor 派活时签发的身份凭证（JWT 风格）
**任务范围**Worker 允许执行的操作边界（scope）
**消息路由**Agent 间消息传递的规则表
**多 Agent 通信**异步消息队列 + 共享 memory
**共识**多 Agent 对同一结论的投票或加权
**Reviewer 校验**校对 Agent 验证引用真实性的步骤
**多源验证**同一论点由 ≥2 独立来源支持
**PDF 沙箱**cites/ 目录的隔离环境，下载的 PDF 全部落盘此处
**长报告生成**≥1 万字的综述/分析报告，LLM 多次调用拼装
**章节大纲**Writer 写作前 Supervisor 生成的 markdown 骨架
**引用三元组**(cite_id, source_url, claim) 三元组
**冲突检测**两个 claim 关键词重叠度判定 agree / disagree / neutral
**知识图谱**引用关系的有向图存储（ch18 首次落地）
**Agent 间消息**Supervisor 派活 / Worker 回报的统一结构
**终止条件**max_loops=8 / max_tokens=200K / Reviewer pass
**Trace log**4 Agent 消息流的时间序列日志

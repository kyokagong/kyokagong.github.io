关于本书

《AGENT开发从入门到精通》是一本系统性介绍 AI Agent 理论与工程实践的中文教材。 从 1966 年的 ELIZA 讲起，到 2024-2026 年的多 Agent 协议爆发， 覆盖 Agent 基础理论、核心技术、多 Agent 协作、实战项目、高级能力与前沿展望六大主题。

本书适合 AI 工程师、Agent 开发者、产品经理，以及任何对 Agent 技术感兴趣的研究者和学生。 我们假设读者已经了解 LLM 基础（什么是 GPT / Claude）， 但对"Agent"还停留在"听过这词"的程度。

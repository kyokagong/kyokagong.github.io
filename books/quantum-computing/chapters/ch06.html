学完本章,你将掌握:

  • 单 qubit 态的完整数学(全局相位、相对相位、Bloch 球坐标)
  • 多 qubit 系统的张量积结构 + 纠缠态 vs 可分态
  • 不可克隆定理的量子计算视角解读

第二部分的开篇: 从 ch06 开始,我们从"物理学家"切换到"计算科学家"的视角。量子力学不再是哲学,而是工具。

6.0.1 视角的转变:从"自然描述"到"信息载体"

在 ch01-ch05 里,量子力学的对象是"物理系统"——电子、光子、原子。我们用态矢量描述它们的状态,用算符描述物理量,用薛定谔方程描述演化,用玻恩规则描述测量结果。

从 ch06 开始,我们的对象变了——我们关心的不是"电子"或"光子"本身,而是信息。qubit 不是一个"自然粒子",而是一个可控的 2 维量子系统。具体物理实现可以是超导电路、离子、光子、中性原子……载体不同,但信息处理能力相同(由 ch06 的数学决定)。

这个视角转变是量子计算的灵魂:

视角关注度量
物理学家 (ch01-ch05)"电子" / "光子" / "原子"能量、本征值、寿命
量子工程师 (ch20-24)"transmon" / "离子" / "光路"保真度、相干时间、门时间
量子计算科学家 (ch06+)"qubit" / "量子门" / "量子电路"电路深度、qubit 数、错误率

类比: 经典计算机科学家不关心晶体管是双极型还是 CMOS,只关心"逻辑门"。同样,量子计算科学家不关心 qubit 是超导还是离子,只关心"酉演化 + 测量"。这就是为什么 ch06 几乎是纯数学——我们要把 qubit 抽象成信息载体,而不是物理实体。

6.1 经典比特的局限

6.1.1 经典比特的定义

经典比特: 一个二态系统,任一时刻处于 0 或 1。物理实现多种多样:

  • 高/低电压(电子电路)
  • 磁化方向(硬盘)
  • 光强(光纤通信)
  • 机械位置(早期继电器)

核心特征: 经典比特在任一确定时刻只有一个值(0 或 1)。如果你想知道是哪个,只需"看一眼"——不会扰动它。

6.1.2 经典计算的瓶颈

经典计算的根本限制不在于"0 和 1 不够用",而在于状态空间小:

$n$ 个经典比特表示 $2^n$ 种状态中的一种($n = 10$ bit → 1024 种可能,$n = 1000$ bit → $2^{1000} \approx 10^{301}$ 种可能)。但是一台经典计算机一次只能处理一种——这是经典计算的"原始瓶颈":

  • 想找 $N$ 个数据中的最小值:经典需要 $O(N)$ 次比较
  • 想分解 $L$ 位整数:经典需要 $O(e^{L^{1/3}})$ 次算术运算
  • 想模拟 $n$ qubit 系统:经典需要 $O(2^n)$ 个复数

最后一个是 Feynman 1982 年提出量子计算的原始动机 —— 经典计算机指数地难以模拟量子系统本身。

6.1.3 量子比特的"承诺"

如果 $n$ 个量子比特能同时处于所有 $2^n$ 种状态的"叠加",那量子计算就能在指数级的状态空间里并行操作——这是量子加速的直觉来源(第 10 章 Grover、第 11 章 Shor 的几何基础)。

但是(重要警告): 量子计算不等于"对所有 $2^n$ 种输入同时计算,然后读出答案"。测量的玻恩规则告诉我们:你只能读出一个结果!真正的"魔法"是干涉——算法巧妙地让正确答案建设性干涉、错误答案破坏性干涉,使得测量得到正确答案的概率接近 1。这是 ch10 Grover 和 ch11 Shor 的核心思想。

6.2 量子比特的定义

6.2.1 数学定义

量子比特(qubit) 是一个2 维复希尔伯特空间 $\mathcal{H} = \mathbb{C}^2$ 中的归一化向量。

标准基($|0\rangle$ 和 $|1\rangle$):

$$|0\rangle = \begin{pmatrix} 1 \\ 0 \end{pmatrix}, \quad |1\rangle = \begin{pmatrix} 0 \\ 1 \end{pmatrix}$$

一般 qubit 态:

$$|\psi\rangle = \alpha |0\rangle + \beta |1\rangle = \begin{pmatrix} \alpha \\ \beta \end{pmatrix}, \quad \alpha, \beta \in \mathbb{C}$$

归一化条件:

$$|\alpha|^2 + |\beta|^2 = 1$$

物理解释(玻恩规则): 测量 $\hat{Z}$(计算基)得到 0 的概率是 $|\alpha|^2$,得到 1 的概率是 $|\beta|^2$。

关键差异: 经典比特有 2 个状态;量子比特有无穷多个状态(因为 $\alpha, \beta$ 可以是任意满足归一化的复数)。这个"无穷多"是量子计算威力的形式化基础。

6.2.2 全局相位与相对相位

由于 $|\alpha|^2 + |\beta|^2 = 1$ 的归一化,两个振幅被约束住——但还有一个冗余自由度。

全局相位: $|\psi\rangle$ 跟 $e^{i\phi} |\psi\rangle$ 描述同一个物理态——因为玻恩规则 $|\langle a | \psi \rangle|^2$ 对全局相位不敏感。所以 qubit 态的真实自由度是2 个实数(不是 4 个)。

相对相位: 对 $|\psi\rangle = \alpha |0\rangle + \beta |1\rangle$,我们可以总是通过乘以全局相位 $e^{-i \arg \alpha}$ 让 $\alpha$ 变成实正数 $\geq 0$。然后 $|\beta|$ 决定概率分布,$\arg \beta$ 决定相对相位(0 到 $2\pi$ 的实数)。

简化形式(忽略全局相位):

$$|\psi\rangle = \cos\frac{\theta}{2} |0\rangle + e^{i\phi} \sin\frac{\theta}{2} |1\rangle$$

其中 $\theta \in [0, \pi]$, $\phi \in [0, 2\pi)$。这两个实参数正好是Bloch 球的球极坐标(见 6.3)。

  • $|1\rangle$: $\theta = \pi$ (南极)

  • $|-\rangle$: $\theta = \pi/2, \phi = \pi$ (赤道 −x)
  • $|+i\rangle$: $\theta = \pi/2, \phi = \pi/2$ (赤道 +y)
  • $|-i\rangle$: $\theta = \pi/2, \phi = 3\pi/2$ (赤道 −y)

6.3 Bloch 球:单 qubit 几何

6.3.1 几何对应

每个 qubit 纯态一一对应Bloch 球面上的一个点。Bloch 球是一个3 维单位球,半径为 1。

球极坐标 ↔ qubit:

$$|\psi\rangle = \cos\frac{\theta}{2} |0\rangle + e^{i\phi} \sin\frac{\theta}{2} |1\rangle \quad \longleftrightarrow \quad (x, y, z) = (\sin\theta \cos\phi, \sin\theta \sin\phi, \cos\theta)$$

反向公式(球坐标 → qubit 振幅):

  • $x = \sin\theta \cos\phi = 2 \text{Re}(\alpha^* \beta)$
  • $y = \sin\theta \sin\phi = 2 \text{Im}(\alpha^* \beta)$
  • $z = \cos\theta = |\alpha|^2 - |\beta|^2$

关键事实: Bloch 球面 = 单 qubit 纯态;Bloch 球内 = 单 qubit 混合态(见 6.4)。这个几何对应是单 qubit 量子信息最强大的直觉工具。

6.3.2 Bloch 球上的 6 个"坐标点"

对应 6.2.3 节的 6 个常用态(ASCII 示意):

  • $|0\rangle \leftrightarrow (0, 0, +1)$ (北极)
  • $|1\rangle \leftrightarrow (0, 0, -1)$ (南极)
  • $|+\rangle \leftrightarrow (+1, 0, 0)$ (赤道 +x)
  • $|-\rangle \leftrightarrow (-1, 0, 0)$ (赤道 −x)
  • $|+i\rangle \leftrightarrow (0, +1, 0)$ (赤道 +y)
  • $|-i\rangle \leftrightarrow (0, -1, 0)$ (赤道 −y)

6.3.2.1 Bloch 球上的常用旋转——Pauli 旋转的几何意义

单 qubit 酉演化 = Bloch 球上的旋转。三个 Pauli 矩阵生成三个基本旋转:

$$\hat{R}_x(\theta) = e^{-i\theta \sigma_x/2}: \text{绕 } x \text{ 轴旋转 } \theta$$ $$\hat{R}_y(\theta) = e^{-i\theta \sigma_y/2}: \text{绕 } y \text{ 轴旋转 } \theta$$ $$\hat{R}_z(\theta) = e^{-i\theta \sigma_z/2}: \text{绕 } z \text{ 轴旋转 } \theta$$

几个常用的"门 = 旋转"对应(参 ch07 详):

  • $\hat{X} = \hat{R}_x(\pi)$: 绕 x 转 180°(北极 ↔ 南极)
  • $\hat{Y} = \hat{R}_y(\pi)$: 绕 y 转 180°
  • $\hat{Z} = \hat{R}_z(\pi)$: 绕 z 转 180°(留下全局相位 $-1$,但 Bloch 向量不动 — 一个纯相位门)
  • $\hat{H}$ (Hadamard): 绕 $(x+z)/\sqrt{2}$ 轴转 180° — 把 $|0\rangle$ 转到 $|+\rangle$ (北极 → 赤道)
  • $\hat{S} = \hat{R}_z(\pi/2)$: 90° 绕 z

几何意义: 所有单 qubit 酉演化都是 Bloch 球上的某种 3D 旋转(SO(3) 群),但不是一一对应 —— 两个酉矩阵 $\hat{U}$ 和 $-\hat{U}$ 给出同一个 Bloch 旋转(它们差一个全局相位,物理等价)。这给 SO(3) ≅ SU(2) / Z_2 的二重覆盖 —— 这里的 $\mathbb{Z}_2 = \{+1, -1\}$ 是最小非平凡群,反映全局相位 $\pm 1$ 不改变物理态;没有其他酉算符(没有 $e^{i\pi/3}$ 等)给出同一个 Bloch 旋转,所以覆盖是严格 2:1。单 qubit 酉演化有 3 个实参数(旋转轴 + 角度),跟 SO(3) 维数一致 ✅。

6.3.3 为什么用"球"而不是"平面"?

直觉: 3 个实参数($\theta, \phi$,以及一个缩放因子)描述一个态。全局相位消除了一个自由度,归一化 $|\alpha|^2 + |\beta|^2 = 1$ 又消除一个,剩 2 个实自由度——正好是球面上的 $(\theta, \phi)$。

注: Bloch 球只对单 qubit有效!2 qubit 系统的几何不能简单地用 2 个球——因为有纠缠,态空间是 $4 - 1 = 3$ 个实参数(乘上整体归一化 + 全局相位,实际 6 个实参数)。多 qubit 几何更复杂,需要其他工具(见 6.6 和 ch08 量子电路)。

6.3.4 Bloch 球上的"距离"——Fubini-Study 度量

两个 qubit 态 $|\psi\rangle$ 和 $|\phi\rangle$ 之间的"角度"由 Fubini-Study 度量定义:

$$\cos^2 \frac{d_{FS}}{2} = |\langle \psi | \phi \rangle|^2$$

对 Bloch 球面上的两个点 $\vec{r}_1, \vec{r}_2$,这等价于:

$$d_{FS} = \arccos(\vec{r}_1 \cdot \vec{r}_2)$$

几何意义: 两个态的"可区分度"跟它们 Bloch 向量的点积直接相关。正交态 ($\langle \psi | \phi \rangle = 0$, $\vec{r}_1 \cdot \vec{r}_2 = -1$) 的 Fubini-Study 距离是 $\pi$——最远。相同态 ($\langle \psi | \phi \rangle = 1$, $\vec{r}_1 = \vec{r}_2$) 的距离是 0——最近。

6.3.5 工作实例:把 4 个态"翻译"到 Bloch 球

计算 $|0\rangle$ 和 $|+\rangle$ 的 Fubini-Study 距离:

  • $|0\rangle \leftrightarrow (0, 0, +1)$
  • $|+\rangle \leftrightarrow (+1, 0, 0)$
  • $\vec{r}_1 \cdot \vec{r}_2 = 0$
  • $d_{FS} = \arccos(0) = \pi/2$ ✅ (正交,符合 $\langle 0|+\rangle = 1/\sqrt{2}$, $\cos^2(d/2) = 1/2$ → $d/2 = \pi/4$ → $d = \pi/2$)

计算 $|+\rangle$ 和 $|+i\rangle$ 的距离:

  • $|+\rangle \leftrightarrow (1, 0, 0)$
  • $|+i\rangle \leftrightarrow (0, 1, 0)$
  • $\vec{r}_1 \cdot \vec{r}_2 = 0$
  • $d_{FS} = \pi/2$ ✅ (也正交,符合 $\langle +|+i\rangle = (1/\sqrt{2})(1/\sqrt{2} \cdot 1 + 1/\sqrt{2} \cdot i) = (1+i)/2$, $|\langle +|+i\rangle|^2 = 1/2$)

计算 $|+\rangle$ 和 $|-\rangle$ 的距离:

  • $\vec{r}_1 \cdot \vec{r}_2 = (1)(−1) + 0 + 0 = -1$
  • $d_{FS} = \arccos(-1) = \pi$ ✅ (最远,正交反相,符合 $\langle +|-\rangle = 0$)

观察: Bloch 球上正交对总是对极点(距离 $\pi$)。赤道上的 4 个态($\{|\pm\rangle, |\pm i\rangle\}$) 构成正交归一基(对极点),但 $\{|0\rangle, |1\rangle\}$ 才是"计算基"——这两组基不一样,因为它们对应不同的测量方向。选哪组基测量 = 选测哪个可观测量(参 ch05 投影测量)——这是 ch07 单 qubit 门的几何基础。

6.4 量子比特的"内部"——混合态与纯度

6.4.1 纯态 vs 混合态

纯态(pure state): $|\psi\rangle \in \mathcal{H}$ 的矢量描述。

$$\hat{\rho} = |\psi\rangle \langle \psi|$$

混合态(mixed state): 一组纯态的概率混合:

$$\hat{\rho} = \sum_i p_i |\psi_i\rangle \langle \psi_i|, \quad p_i \geq 0, \sum_i p_i = 1$$

举例: 制备一硬币,正反两面各占 50%:

  • 经典混合: 你不知道是正面还是反面,态是"正面 OR 反面"
  • 量子叠加: $|\psi\rangle = \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle)$,干涉 会出现(参 ch03 双缝)

纯度(purity): $\text{tr}(\hat{\rho}^2) = \begin{cases} 1 & \text{纯态} \\ 1/d & \text{完全混合态}(d = \text{维数}) \end{cases}$

对单 qubit 完全混合态: $\hat{\rho} = I/2$, $\text{tr}(\hat{\rho}^2) = 1/2$。

6.4.2 Bloch 球内的"半径"= 纯度

关键公式: 单 qubit 密度矩阵可以总是写成

$$\hat{\rho} = \frac{1}{2}(I + \vec{r} \cdot \vec{\sigma})$$

其中 $\vec{r} = (r_x, r_y, r_z)$ 是 Bloch 向量(3 维实向量), $\vec{\sigma} = (\sigma_x, \sigma_y, \sigma_z)$ 是 Pauli 矩阵向量。

纯度跟 Bloch 向量长度的关系:

$$\text{tr}(\hat{\rho}^2) = \frac{1}{2}(1 + |\vec{r}|^2)$$

对应:

  • $|\vec{r}| = 1$ (球面) → $\text{tr}(\hat{\rho}^2) = 1$ → 纯态
  • $|\vec{r}| = 0$ (球心) → $\text{tr}(\hat{\rho}^2) = 1/2$ → 完全混合态
  • $0 < |\vec{r}| < 1$ (球内) → 部分混合态

几何意义: 整个 Bloch 球(球面 + 内部)描述所有单 qubit 态(纯态 + 混合态)。球面是"纯",球心是"最不纯"。

6.4.3 例:三种态的 Bloch 向量

6.4.4 Bloch 球上的"典型"噪声通道

噪声(noise) 把纯态(球面)拉到混合态(球内)。几种标准单 qubit 噪声:

退极化(depolarizing): 以概率 $p$ 把态变成完全混合,概率 $1 - p$ 保持

$$\mathcal{E}_{\text{depol}}(\hat{\rho}) = (1-p) \hat{\rho} + p \frac{I}{2}$$

几何: Bloch 向量按比例收缩 $|\vec{r}| \to (1-p) |\vec{r}|$ —— 径向收缩到球心

退相位(dephasing): 抹去 $\sigma_x, \sigma_y$ 方向的相干性,只保留 $\sigma_z$ 方向:

$$\mathcal{E}_{\text{deph}}(\hat{\rho}) = (1-p) \hat{\rho} + p \hat{Z} \hat{\rho} \hat{Z}$$

为什么这是 dephasing? $\hat{Z}$ 跟 $\sigma_z$ 对易,跟 $\sigma_x, \sigma_y$ 反对易 ($\hat{Z}\sigma_x\hat{Z} = -\sigma_x$,$\hat{Z}\sigma_y\hat{Z} = -\sigma_y$)。所以 经典概率混合 $(1-p)\hat{\rho} + p \hat{Z}\hat{\rho}\hat{Z}$ 让 $X, Y$ 方向的 Pauli 期望 $\langle\sigma_x\rangle, \langle\sigma_y\rangle$ 按 $(1-2p)$ 衰减,而 $Z$ 方向 $\langle\sigma_z\rangle$ 不变 —— 这正是"相位(对角线外项)被抹去、布局(对角线项)被保留"的几何含义。

几何: Bloch 向量z 分量不变,$\vec{r}_{x,y}$ 缩小为 $(1-p) \vec{r}_{x,y}$ —— 赤道方向收缩到 z 轴

振幅阻尼(amplitude damping): 模拟自发辐射($|1\rangle \to |0\rangle$ 释放能量)

$$\mathcal{E}_{\text{AD}}(\hat{\rho}) = \hat{K}_0 \hat{\rho} \hat{K}_0^\dagger + \hat{K}_1 \hat{\rho} \hat{K}_1^\dagger$$ $$\hat{K}_0 = |0\rangle\langle 0| + \sqrt{1-\gamma}|1\rangle\langle 1|, \quad \hat{K}_1 = \sqrt{\gamma}|0\rangle\langle 1|$$

几何: 非平凡变换,Bloch 向量沿某条曲线移到 $|0\rangle$ (北极)

噪声对量子计算的根本影响: ch16 详。核心问题: 噪声让量子态"远离球面"——从纯态(球面点)走向混合态(球内点)——所有依赖相位的算法(Grover、Shor、QFT)都会降速甚至失败。量子纠错(ch17)的本质 = 用冗余的物理 qubit保护逻辑 qubit,让噪声"反向收缩"回球面。

6.5 量子比特的物理实现

6.5.1 为什么物理实现是个挑战?

DiVincenzo 判据(2000,量子计算的"可行性标准"):

  1. 可扩展的物理 qubit:能制造多个qubit(目前百到千级)
  2. 初态制备:能把 qubit 初始化到已知态(比如 $|0\rangle$)
  3. 长相干时间:qubit 能在比门操作时间长得多的时间内保持量子相干性
  4. 通用量子门:能实现一组通用量子门(比如 $\{$Hadamard, CNOT, T$\}$ 集,ch07 详)
  5. 测量能力:能高保真地测量单个 qubit
  6. 量子比特间通信:qubit 能互相交互(2-qubit 门)

注: 这 6 条是必要条件,不是充分条件。实际工程还有冷却、纠错、控制电子学、经典-量子接口等很多挑战。

6.5.3 怎么选物理 qubit?

没有"最好"的物理实现——每种平台都在不同的工程权衡下竞争:

  • 超导: 速度(scale-up 快),但相干时间短
  • 离子阱: 保真度高,但门慢
  • 光量子: 室温飞行 qubit(网络),但难做双 qubit 门
  • 中性原子: 平衡型选手,可做大规模阵列
  • 拓扑: 物理保护好,但工程极难

通用经验: 早期容错量子计算(2026-2035)→ 超导 + 离子阱 + 中性原子 主导;远期(2035+)→ 拓扑 或 光量子模块化 可能成为主流。

6.6 多 qubit 系统:从 1 到 n

6.6.1 张量积结构

$n$ qubit 系统的态空间是张量积:

$$\mathcal{H}^{\otimes n} = \mathcal{H}_1 \otimes \mathcal{H}_2 \otimes \cdots \otimes \mathcal{H}_n$$

每个 $\mathcal{H}_i = \mathbb{C}^2$,所以 $\dim(\mathcal{H}^{\otimes n}) = 2^n$。

2 qubit 例子:

$$|0\rangle \otimes |1\rangle = |0\rangle |1\rangle = |01\rangle = \begin{pmatrix} 1 \\ 0 \\ 0 \\ 0 \end{pmatrix}$$

一般 2 qubit 态:

$$|\psi\rangle = \alpha_{00} |00\rangle + \alpha_{01} |01\rangle + \alpha_{10} |10\rangle + \alpha_{11} |11\rangle$$

归一化: $\sum_{ij} |\alpha_{ij}|^2 = 1$。

6.6.2 指数级状态空间

关键事实: $n$ qubit 系统的复振幅有 $2^{n+1}$ 个实数(2^n 复数,减 1 归一化,再除以 1 个全局相位),但只用 $n$ 个 qubit 物理实现!

这就是量子计算的"承诺" —— $n = 300$ qubit 系统的 Hilbert 空间比可观测宇宙的原子数还多!但(再次强调)测量只能读出一个结果——量子算法的艺术就是让"正确答案建设性干涉、错误答案破坏性干涉"。

6.6.3 可分态 vs 纠缠态

可分态(separable state): 能写成单 qubit 态的张量积:

$$|\psi\rangle = |\psi_1\rangle \otimes |\psi_2\rangle \otimes \cdots \otimes |\psi_n\rangle$$

纠缠态(entangled state): 不能写成张量积(参 ch04)。

2 qubit 例子:

  • $|00\rangle$ — 可分 ✅
  • $\frac{1}{\sqrt{2}}(|00\rangle + |11\rangle) = |\Phi^+\rangle$ — 纠缠 ✅ (Bell 态)
  • $\frac{1}{\sqrt{2}}(|0+\rangle + |1-\rangle) = \frac{1}{2}(|00\rangle - |01\rangle + |10\rangle - |11\rangle) = |\psi_1\rangle \otimes |\psi_2\rangle$ — 可分 ✅(可分解为 $(|0\rangle + |1\rangle)/\sqrt{2} \otimes (|0\rangle - |1\rangle)/\sqrt{2}$)

判断方法: 计算约化密度矩阵 $\hat{\rho}_A = \text{tr}_B(|\psi\rangle\langle\psi|)$。如果 $\hat{\rho}_A$ 是纯态($\text{tr}(\hat{\rho}_A^2) = 1$),则 $|\psi\rangle$ 可分;否则纠缠。

纠缠的"代价": 2 qubit 纠缠态的 4 个复振幅不能被 2 个单 qubit 复振幅"完全描述"——这 4 个振幅里有真正的"多体信息",不只来自单 qubit 的局部自由度。这是 ch04 纠缠的核心,也是 ch10 Grover、ch11 Shor 等量子算法的"燃料"。

6.6.3.1 工作实例:从 $|00\rangle$ 制备 Bell 态 $|\Phi^+\rangle$

目标: 通过量子门操作把可分态 $|00\rangle$ 变成最大纠缠 Bell 态 $|\Phi^+\rangle = \frac{1}{\sqrt{2}}(|00\rangle + |11\rangle)$。

电路(Hadamard + CNOT):

  1. Hadamard 门作用在 qubit 0: $|0\rangle \to |+\rangle = (|0\rangle + |1\rangle)/\sqrt{2}$ $$|00\rangle \xrightarrow{H \otimes I} \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle) |0\rangle = \frac{1}{\sqrt{2}}(|00\rangle + |10\rangle)$$
  2. CNOT 门(qubit 0 控制,qubit 1 目标):$|00\rangle \to |00\rangle, |10\rangle \to |11\rangle$ $$\frac{1}{\sqrt{2}}(|00\rangle + |10\rangle) \xrightarrow{\text{CNOT}} \frac{1}{\sqrt{2}}(|00\rangle + |11\rangle) = |\Phi^+\rangle$$

为什么这是"纠缠制备": $|\Phi^+\rangle$ 不能写成单 qubit 张量积(可验证 $\hat{\rho}_A = \text{tr}_B(|\Phi^+\rangle\langle\Phi^+|) = I/2$ 是完全混合态,不是纯态,意味着 qubit 0 不再处于任何确定的单 qubit 态)。

几何观察: 这两个门完全在 qubit 0 和 qubit 1 上局部作用 —— 但结果是 qubit 0 和 qubit 1 完全纠缠!这正是量子计算的"魔法" —— 局部操作(每个 qubit 上做门)产生非局域结果(两 qubit 纠缠)。纠缠不能被局部操作产生,只能被"扩散"(如果初态已经有局部关联);但CNOT + Hadamard 的组合确实把 $|00\rangle$(无关联)转成 $|\Phi^+\rangle$(完全关联)——这看似矛盾,实际是"信息从经典(振幅位置)转到量子(振幅间相位关联)"的微妙平衡。

6.6.3.2 3 qubit 的 GHZ 和 W 不可相互转换

3 qubit 纠缠有两种"等价类"(Dür-Vidal-Cirac 2000):

  • GHZ 类: 包含 GHZ 态,3-qubit "集体"纠缠
  • W 类: 包含 W 态,3-qubit "成对"纠缠

关键事实: 任何 LOCC(局域操作 + 经典通信) 不能 把 GHZ 转为 W(或反之) 确定性地 —— 两者不可逆等价。这意味着 GHZ 类和 W 类在 LOCC 下属于不同的纠缠等价类。

含义: 量子纠缠不是单一标量,3 qubit 起需要多个参数描述。ch14 量子机器学习的"量子纠缠特征"通常需要测 concurrence、negativity、3-tangle 等多个度量。

6.6.5 多 qubit 的"明星"纠缠态

Bell 态(2 qubit, 4 个) — 4 个最大纠缠正交归一基(参 ch04):

$$|\Phi^\pm\rangle = \frac{1}{\sqrt{2}}(|00\rangle \pm |11\rangle), \quad |\Psi^\pm\rangle = \frac{1}{\sqrt{2}}(|01\rangle \pm |10\rangle)$$

GHZ 态(n qubit) — Greenberger-Horne-Zeilinger 1989:

$$|\text{GHZ}_n\rangle = \frac{1}{\sqrt{2}}(|0\rangle^{\otimes n} + |1\rangle^{\otimes n})$$

特点: 所有 $n$ 个 qubit 同时是 0 或同时是 1,关联度比经典强。测量任意一个 qubit 得 0(或 1),其余所有 qubit 立即塌缩到同一个值(这是"非局域关联"的最戏剧版本)。

W 态(n qubit) — Dür-Vidal-Cirac 2000:

$$|W_n\rangle = \frac{1}{\sqrt{n}}(|100\cdots 0\rangle + |010\cdots 0\rangle + \cdots + |0\cdots 01\rangle)$$

特点: 恰好一个 qubit 是 1,其余是 0 的"叠加"。跟 GHZ 的区别: 测量一个 qubit 得 1 后,GHZ 完全确定,还有"集体信息"塌缩;W 态塌缩后还剩(n-1) qubit 的 W 态,具有鲁棒性——失去一个 qubit 仍部分纠缠。

图态(graph state) — 量子纠错(ch17)和测量基量子计算(MBQC)的基础:把 qubit 排成图 $G=(V,E)$,所有 qubit 初态 $|+\rangle$,每条边做 CZ 门。完整定义见 ch17/18。关键特例:Bell 态 = 1 边图(2 qubit),GHZ 态 = 0 边图($n$ 个孤立 qubit 后 Hadamard),W 态 = 1 边星图。所以"明星态"其实是图态家族的不同成员。

谱系图(家族关系):

                 图态 G⟩ (G = 图)
                    │
     ┌──────────────┼──────────────┐
     │              │              │
  1 边 (Bell)   0 边 (GHZ)    星图 (W)

为什么"明星态"重要: 这些态不是任意态——它们是有结构的纠缠态,在量子计算、量子通信、量子纠错中反复出现。ch10 Grover 用 GHZ/W 态作为"标记态",ch11 Shor 用 QFT 产生 GHZ 态,ch17 表面码本质上是 2D 图态。掌握这些态 = 掌握量子计算的工具箱。

6.6.6 纠缠的量化——Concurrence, Entanglement Entropy, Negativity

判断是否纠缠是第一步,量化多少纠缠是第二步。3 个常用纠缠度量:

Concurrence (Wootters 1998, 2 qubit):

$$C(|\psi\rangle) = \sqrt{2(1 - \text{tr}(\hat{\rho}_A^2))}$$
  • $C = 0$: 可分
  • $C = 1$: 最大纠缠(Bell 态)
  • 物理意义: 跟可逆纠缠转换的"等价类"一致

Entanglement Entropy (von Neumann 熵的约化态,任意 bipartition $A|B$):

$$S_A = -\text{tr}(\hat{\rho}_A \log_2 \hat{\rho}_A) = S_B$$
  • 范围: $[0, \log_2(\min(\dim A, \dim B))]$
  • 物理意义: 量子热力学的"纠缠温度"——纠缠越多,约化态越"热"
  • 2 qubit 最大纠缠: $S_A = 1$ bit

Negativity (可计算,任意 bipartition):

$$\mathcal{N} = \frac{\|\hat{\rho}^{T_A}\|_1 - 1}{2} = \sum_{\lambda_i < 0} |\lambda_i|$$
  • $\mathcal{N} = 0$: 可分
  • $\mathcal{N} > 0$: 纠缠
  • 物理意义: 部分转置后的负本征值之和——可分态的部分转置仍半正定(PPT 判据),纠缠态的至少有一个负本征值

多 qubit 纠缠的特殊性: 3 qubit 起的纠缠有不可逆转换(GHZ 不能转为 W 或反之,Dür-Vidal-Cirac 2000),所以单个标量度量不够——需要完整的 SLOCC(随机 LOCC 等价类)分类,这是量子多体物理的活跃研究领域。

6.7 量子比特的不可克隆性

6.7.1 不可克隆定理(回顾 ch04)

定理 (Wootters-Zurek 1982, Dieks 1982): 没有任何物理过程能完美复制未知的量子态:

$$U |\psi\rangle |0\rangle = |\psi\rangle |\psi\rangle \quad \text{(对所有 $|\psi\rangle$ 同时成立)} \quad \Rightarrow \quad \text{矛盾}$$

简短证明(对 2 维): 假设 $U$ 能完美复制 $|0\rangle$ 和 $|1\rangle$:

$$U|0\rangle|0\rangle = |0\rangle|0\rangle, \quad U|1\rangle|0\rangle = |1\rangle|1\rangle$$

对叠加 $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$:

$$U|\psi\rangle|0\rangle = \alpha U|0\rangle|0\rangle + \beta U|1\rangle|0\rangle = \alpha|0\rangle|0\rangle + \beta|1\rangle|1\rangle$$

但完美复制要求 $U|\psi\rangle|0\rangle = |\psi\rangle|\psi\rangle = \alpha^2|00\rangle + \alpha\beta|01\rangle + \alpha\beta|10\rangle + \beta^2|11\rangle$。

两个表达式不相等 ($\alpha\beta$ 项 vs $\alpha^2, \beta^2$ 项) — 矛盾! ∎

6.7.2 不可克隆的"量子计算视角"

对量子计算而言,不可克隆定理既是限制也是机会:

作为限制:

  • 不能复制 qubit → 不能做"经典备份" → 错误一旦发生不可逆
  • 这给量子纠错带来根本挑战 —— ch16 噪声、退相干;ch17 纠错码会详谈
  • 经典的"复制 + 比较"消错方法不适用

作为机会:

  • 量子密钥分发(BB84, ch17/26)安全的根源:窃听者不能复制量子态而不留下痕迹
  • 不可克隆是量子加密比经典加密更强的物理基础
  • 没有经典备份也意味着量子计算的"私密性"——单次计算后,原始输入自动消失

关键澄清: 不可克隆不意味着 qubit 不能传输 —— 量子隐形传态(ch04)告诉我们:用 2 经典 bit + 1 纠缠对可以传输qubit 态(不"复制")。

6.7.3 近似克隆与量子克隆机

完美克隆不可能,但近似克隆可能(Bužek-Hillery 1996):

  • 1 → 2 最优克隆机:对未知 qubit,保真度最优 $F = 5/6 \approx 0.833$
  • 实用价值:某些量子通信协议需要"放大"弱信号(但不能完美)

跟经典对比: 经典 bit 完美复制是免费的(用三极管、寄存器等);qubit 的"近似复制"已经是研究前沿。这反映了量子信息跟经典信息的根本不同。

6.7.4 不可克隆的"几何"解读

Bloch 球给出了不可克隆的几何直觉:

  • 完美复制 $|\psi\rangle |0\rangle \to |\psi\rangle |\psi\rangle$ 要求两个独立 qubit 都映射到同一个 Bloch 向量 $\vec{r}_\psi$。
  • 但酉演化 = Bloch 球旋转,只能把一个向量转到另一个固定向量。两个独立 qubit 同时转到同一个目标 = 需要两套独立的旋转参数,但酉算符只有一套。
  • 对单 qubit 的酉演化 $\hat{U}$:$\hat{U}$ 把 $\vec{r}$ 转到 $\hat{U} \vec{r} \hat{U}^\dagger$(Bloch 向量的旋转)。两个 qubit 同时转到 $\vec{r}_\psi$ 需要两个独立酉算符 $\hat{U}_1, \hat{U}_2$ 满足 $\hat{U}_1 \vec{r} \hat{U}_1^\dagger = \hat{U}_2 \vec{r} \hat{U}_2^\dagger$ 对所有 $\vec{r}$——这要求 $\hat{U}_1 = \hat{U}_2$(在全局相位下),但作用在不同 qubit —— 跟"独立"假设矛盾。

几何意义: 不可克隆定理等价于说:Bloch 球上的"对应"操作不能被两个独立 qubit 共享酉演化实现。整个球无法被单一酉映到自身(除了恒等 $I$ 和反演 $-I$,它们都对应平凡的"克隆"——但 $\hat{U} = -I$ 跟 $\hat{U} = I$ 在 Bloch 球上不可区分,所以"完美克隆"在 Bloch 球上没有意义——这是个微妙但深刻的观察)。

严格代数:酉演化对任意 Bloch 向量 $\vec{r}$ 完全决定结果:$\vec{r}_{\text{out}} = R(\hat{U})\vec{r}$ 其中 $R(\hat{U}) \in SO(3)$ 是酉算符诱导的 3D 旋转。所以两个酉算符 $\hat{U}_1, \hat{U}_2$ 给出同一个 Bloch 旋转,即 $R(\hat{U}_1) = R(\hat{U}_2)$,必须有 $\hat{U}_1 = \pm \hat{U}_2$(在全局相位下)——这是 SO(3) ≅ SU(2)/$\mathbb{Z}_2$ 的严格表述。所以两个独立 qubit 不可能有不同酉算符 $\hat{U}_1 \neq \pm \hat{U}_2$ 同时完美地把各自不同的输入态 $\vec{r}_1, \vec{r}_2$ 转成同一个目标 $\vec{r}_\psi$ —— 这跟"完美克隆"的形式要求矛盾,因而不可实现。

6.7.5 不可克隆的"哲学"含义:为什么不能"备份"?

经典计算的强大部分来自可复制——你可以"保存"一个 bit,需要时"加载"。但量子世界没有这种永久备份:

  • 量子纠错(ch17)只能间接保护信息——用冗余物理 qubit 编码逻辑 qubit,但物理 qubit 不是逻辑 qubit 的"备份"(而是"带冗余的编码")
  • 任何退相干都不可逆地损失相位信息(参 ch03.6)
  • 量子计算的"运行"是一次性的——一旦测量,叠加塌缩,信息不可恢复

隐喻: 经典计算像"在白纸上写字"——可以复印;量子计算像"在水面投石子"——波纹瞬时展开,测量后波纹消失,不可"重新播放"。

乐观视角: 正是这种"易碎"使得量子计算"安全"(BB84 量子密钥)——窃听者不可能复制而不破坏。但悲观视角: 也是这种"易碎"使量子计算难——任何噪声都会破坏结果。量子纠错 = 在"易碎"上建造"鲁棒"。

6.8 量子比特的"身份证"——Pauli 分解

6.8.1 单 qubit 密度矩阵的 Pauli 分解

对单 qubit,任何 $2 \times 2$ 厄米矩阵可写成 Pauli 矩阵的线性组合:

$$\hat{\rho} = \frac{1}{2}(r_0 I + r_1 \sigma_x + r_2 \sigma_y + r_3 \sigma_z) = \frac{1}{2}(I + \vec{r} \cdot \vec{\sigma})$$

其中 $r_0 = 1$(归一化), $\vec{r} = (r_1, r_2, r_3)$ 是 Bloch 向量。

Pauli 矩阵:

$$I = \begin{pmatrix}1&0\\0&1\end{pmatrix}, \sigma_x = \begin{pmatrix}0&1\\1&0\end{pmatrix}, \sigma_y = \begin{pmatrix}0&-i\\i&0\end{pmatrix}, \sigma_z = \begin{pmatrix}1&0\\0&-1\end{pmatrix}$$

性质: $\text{tr}(\sigma_i \sigma_j) = 2 \delta_{ij}$, $\{I, \sigma_x, \sigma_y, \sigma_z\}$ 构成完备基。

6.8.2 多 qubit 的泡利串(Pauli string)分解

$n$ qubit 系统的任意密度矩阵可写成泡利串 $P_1 \otimes P_2 \otimes \cdots \otimes P_n$ 的线性组合:

$$\hat{\rho} = \frac{1}{2^n} \sum_{P_1, \ldots, P_n \in \{I, X, Y, Z\}} c_{P_1 \cdots P_n} P_1 \otimes \cdots \otimes P_n$$

系数 $c_{P_1 \cdots P_n} = \text{tr}(\hat{\rho} P_1 \otimes \cdots \otimes P_n)$ —— 这就是量子态层析(QST)的数学基础(参 ch05 5.6.4)。

独立系数个数: $4^n$ 个泡利串,但归一化 $c_{I\cdots I} = 1$ 固定一个,所以独立 $4^n - 1$ 个 ✅(跟 6.6.4 一致)。

6.8.3 Pauli 分解的"物理意义"——可观测量视角

每个 Pauli 串 $P_1 \otimes \cdots \otimes P_n$ 对应一个可观测量(参 ch05)。系数 $c_{P_1 \cdots P_n}$ 就是这个观测量的期望值 $\langle P_1 \otimes \cdots \otimes P_n \rangle$。

关键观察: Pauli 分解把密度矩阵的"数学描述"直接翻译成"实验可测量"——QST 只需要测 $4^n - 1$ 个期望值(对 $n$ qubit),无需直接"读出" $2^n \times 2^n$ 矩阵。这是量子态可观测性的具体化:虽然态在指数大的 Hilbert 空间里,但可观测信息只有 $4^n - 1$ 个实数,跟 Hilbert 空间维数的平方根同阶 ✅(实际是 $4^n$ 量级,但比 $2^{2n}$ 矩阵的 $4^n$ 个数少一半)。

QST 在实验中的地位: 任何量子算法的输出验证(比如测 Bell 态保真度)都需要 QST 作为子程序。ch14 量子机器学习中,量子数据的特征提取 = 计算某些 Pauli 串的期望值(比如 VQE 算哈密顿量,QAOA 算 cost Hamiltonian)。Pauli 分解是连接"理论数学"和"实验测量"的桥梁。

6.9 章节总结与后续

6.9.1 一句话总结

量子比特(qubit) 是 2 维希尔伯特空间的归一化向量,可以用 Bloch 球做几何表示。$n$ qubit 系统的 Hilbert 空间维数指数增长($2^n$),这给量子计算形式化提供了"指数级状态空间"的承诺——但(再次)真正的"魔法"是干涉,不是"指数并行"。不可克隆定理告诉我们 qubit 不能完美复制,这既给量子纠错带来挑战,又给量子加密提供安全基础。

22.0.1 五种量子硬件平台的光量子定位

在前两章里,我们看到了超导 (ch20) 凭借速度与规模,以及离子阱 (ch21) 凭借全连接与高保真度,占据 NISQ 时代的主流。然而,这两个平台都依赖低温稀释制冷机 (10 mK 量级)、精密微波/激光控制,以及精密的电磁屏蔽。如果有一种量子计算平台完全不需要制冷机、在室温下就能运行、并且天然长距离传输,那会怎样?

这就是光量子计算 (photonic quantum computing) 的承诺。光子,作为自然界唯一的飞行量子比特,在空气中不会衰减、在光纤中可以传输数百公里、不会因为"发热"而退相干——因为光子本身根本没有温度。然而,光子之间不直接相互作用,这给"光量子计算机怎么实现两 qubit 门"出了一个根本性难题。

光量子的核心卖点 (相对 ch20/ch21):

1. 室温操作——光子自己是室温(没有温度概念),无需稀释制冷机。

2. 长距离传输——光纤 0.2 dB/km (1550 nm 窗口,电信级),单光子可以传输数十公里而不显著衰减。

3. 高速门——光子以光速传播,基本"门"操作(分束器)只是 ns 量级。

4. 天然量子互联网节点 (ch26)——光子是唯一能够长距离保持相干性的量子比特。

5. 借用成熟工艺——硅光子、氮化硅、铌酸锂等半导体工艺直接可用。

22.1 光子 qubit 编码——五个自由度

一个光子在经典电动力学里有多个独立可观测的物理自由度,每一个都可以被选为 qubit 的载体。本节比较五种主要方案。

22.1.1 偏振编码 (Polarization)——最简单

光子偏振的两个正交基:

$$\lvert 0\rangle = \lvert H\rangle = \begin{pmatrix}1\\0\end{pmatrix},\quad \lvert 1\rangle = \lvert V\rangle = \begin{pmatrix}0\\1\end{pmatrix}$$

测量只需 1 个偏振分束器 (PBS) + 2 个单光子探测器。门只需波片 (λ/2, λ/4)。优势: 简单、单光子实验成熟;劣势: 不能片上集成 (需要自由空间光学)。

22.1.2 路径编码 (Path)——可集成

N 条波导 → N 个正交态。N=2 时:

$$\lvert 0\rangle = \text{上波导},\quad \lvert 1\rangle = \text{下波导}$$

优势: 完全平面集成 (硅光、SiN);劣势: N 比特需 $2^N$ 条波导,资源指数增长。

22.1.3 时间 / 频率 / OAM 编码

- 时间编码 (time bin): 早/晚两个时间窗——光纤传输友好

- 频率编码 (frequency bin): 不同波长——波分复用 (WDM)

- 轨道角动量 (OAM): 螺旋度 $l = 0, 1, 2, \ldots$——理论上无穷维 Hilbert 空间,但不可标准化

22.1.5 单光子源——确定的 vs 概率的

光量子计算最大的工程难题之一是确定性单光子源。三类:

1. 弱相干光 (attenuated laser): 把激光衰减到平均每脉冲 < 0.1 光子——最简单, 但真空 + 多光子事件 多

2. 自发参量下转换 (SPDC): 高功率激光打 BBO/KTP 晶体, 概率性产生纠缠光子对——概率 ~$10^{-6}$

3. 量子点 (quantum dot): InAs/GaAs 异质结, 确定性产生单光子——最好的单光子源, 但仍难

对比: PsiQuantum + Quandela 押注确定性量子点;Xanadu + 九章早期用概率性 SPDC。

22.1.6 光子数的"陷阱"——真空与多光子

即使是完美单光子源,实际器件还有以下误差:

- 真空态 $p_v = $ 几十 % (源没有触发时)

- 多光子 $p_{2+} = $ 几个 % (源触发时同时出 2 个)

- 损耗 $p_\text{loss} = $ 几个 % 到几十 % (传输/探测)

结论: 光量子计算必须做光子数分辨测量 (photon-number-resolving detection), 并通过后选择 (post-selection) 滤掉错误事件。

22.2 线性光学元件——分束器、相移器、波导

22.2.1 分束器 (Beam Splitter, BS)

最简单的线性元件。50/50 分束器把入射光一半反射、一半透射,矩阵形式:

$$\hat{U}_{BS} = \frac{1}{\sqrt{2}}\begin{pmatrix}1 & i\\ i & 1\end{pmatrix}$$

这就是Hadamard 门在光学世界的类比!在路径编码下,BS 把两个模式混合成(+)和(-)叠加。注意这是酉算符——分束器不"破坏"量子信息。

22.2.2 相移器 (Phase Shifter)

加一个相位 $\phi$ 到一根路径上:

$$\hat{U}_\phi = \begin{pmatrix}e^{i\phi} & 0\\ 0 & 1\end{pmatrix}$$

物理上是一段不同长度的波导 ($\phi = k n L$, $k$ 波数, $n$ 折射率, $L$ 长度)。

22.2.3 Mach-Zehnder 干涉仪

两个 BS + 两条路径 + 一个相移器 $=$ 一个可调干涉仪:


           ┌─────phase φ─────┐
   ────────┤                  ├────────
           └──────────────────┘

输出态强度:

$$P_0 = \cos^2(\phi/2)$$

结论: 调整 $\phi$ 即调整输出概率——这是线性光学通用性的基础。

每一种半导体工艺都有优势:

22.2.5 为什么线性光学"算不出"纠缠

关键事实: 上面所有 BS、相移器、波导都是线性 + 酉 算符。光子从输入端口进来,以叠加形式出去(就像 Mach-Zehnder)。线性光学自身无法产生光子-光子之间的非线性纠缠,即:

$$|\psi\rangle_{\text{in}} = |1,1\rangle \xrightarrow{\text{线性}} \alpha|2,0\rangle + \beta|0,2\rangle + \gamma|1,1\rangle$$

没有 $\delta|1,1\rangle\langle 1,1|$-形式的两光子相互作用项。换句话说,光子在"自由空间"内不直接对话。

历史上这被认为让"光量子通用计算"不可能——直到 2001 的 KLM 定理 解决了这个问题(下一节)。

22.3 KLM 定理——单光子源 + 测量 + 后选择 = 通用量子计算

22.3.1 问题:1980 年代认为不可能

20 世纪 80 年代,一个广为流传的观点:

"光子在自由空间中不直接相互作用。线性光学网络的任何酉变换都不会产生双光子纠缠。因此,光量子不可能实现通用量子计算。"

这是 Lloyd, Milburn 等人在 1990s 初期的疑虑,也是为什么早期量子计算研究大多不押注光子(转向离子阱、超导、核磁共振)。

22.3.2 KLM 的洞见 (2001)

Knill、Laflamme、Milburn (KLM 2001) 在 Nature 上发表了一篇"惊世骇俗"的论文:

"只需单光子源 + 线性光学元件 (BS + 相移器 + PBS) + 单光子探测器 + 后选择 = 通用量子计算。"

核心思想: 即使单门操作产生不了纠缠,也可用两个辅助光子 + 概率性测量 来产生纠缠。例如:

$$|\psi\rangle_{\text{CNOT}}^{\text{目标}} = \frac{1}{\sqrt{2}}(|0\rangle_c(|00\rangle + |11\rangle)_{\text{out}} + |1\rangle_c(|01\rangle + |10\rangle)_{\text{out}})$$

概率性 CNOT 门: 输入 2 个数据 qubit + 2 个辅助光子 → 4 个分束器 + 2 个探测器 → 成功概率 1/4 → 后选择只在探测器 (D1, D2) 都触发时, 输出才是 CNOT。

22.3.3 KLM 的代价——概率性与资源

KLM 定理告诉了我们"线性光学 + 测量"能做通用量子计算,但代价不小:

项目标准量子计算KLM 线性光学
两 qubit 门确定性概率性 (1/4 ~ 1/16)
失败时不发生输出无用态,需 post-selection 丢弃
物理资源1多次重复 + 后选择 ~$1/p_{\text{success}}$
测量方式投影测量光子数分辨 + 前馈

举例: 对于一个8 qubit 算法 (如 Shor-15 因式分解, ch11), 约需 40 个 CNOT (按 Nielsen-Chuang 资源表)。纯 KLM 概率门每个成功概率 1/4, 整体 成功概率 $p = (1/4)^{40} \approx 10^{-24}$——这是为什么 KLM 不可直接工程化, 需要 MBQC + 容错码 (ch17-19) 优化。

结论: KLM 解决了"理论不可能",但实际工程上需要海量冗余光子(每个逻辑CNOT 需要数十个物理光子)。

22.3.4 后续改进

- 2004 Nielsen 用簇态MBQC 把 KLM 简化

- 2005 Browne-Rudolph 给出更简单的方案(只用 2 个辅助光子)

- 2008 玻色采样 提出——用 KLM 的"光学 + 测量"但只做 单一任务**(因玻色采样是专门问题)

22.3.5 KLM 定理的现代意义

今天几乎所有光量子计算原型都"幕后"依赖 KLM 的概率逻辑,但通过架构创新 (MBQC、容错码、冗余设计) 把代价降低到可工程化的水平。

22.4 测量诱导量子计算 (MBQC)——簇态 + 单 qubit 测量

22.4.1 一句话架构

Raussendorf-Briegel 2001: 预先制备一个巨大的簇态 (cluster state)——一个二维晶格上的纠缠资源态——然后对每一列单 qubit 测量(自适应,前后有关联),经典前馈决定下一列的测量基。结果: 单 qubit 测量 + 经典通信 = 通用量子计算。

22.4.2 簇态 (Cluster State) 是什么

2D 簇态定义:

$$|\text{cluster}\rangle = \prod_{\langle i,j\rangle} CZ_{ij} \, |+\rangle^{\otimes N}$$

- $|+\rangle = (|0\rangle+|1\rangle)/\sqrt{2}$

- $CZ_{ij}$ = 控制相位门 (ch07) 在相邻 site 之间

结构: 这是一个多体纠缠态,好像"量子数据的母液"。一旦制备好,你就可以测量各个 site,测量结果按顺序执行算法。

22.4.3 单 qubit 测量实现任意单 qubit 门

测量单个 site 在基 $\{\lvert \psi_\theta\rangle, \lvert \psi_\theta^\perp\rangle\}$ 实现了一层酉操作,角度 $\theta$ 由经典比特 + 前馈决定。这就是MBQC 的"测量即门"思想。

22.4.4 两 qubit 门:测量第二列特定 site

两 qubit 门 (CNOT, CZ) 不需要单独加——通过两列site 的特定测量模式即可。例如:对第 $i$ 列和第 $j$ 列的特定 site 做X-基测量,输出自动是 CNOT。

22.4.5 为什么光子适合 MBQC

关键洞察: 单 qubit 测量是光学的强项——PBS + 探测器天然是单光子投影测量器。所以:

1. 簇态制备: 用 SPDC 或确定性单光子源 + 线性光学网络

2. 测量: 单光子探测器 (SNSPD, 效率 >90%, 暗计数 < 10 Hz)

3. 前馈: 经典电子学(几 ns 延迟)

代价: 簇态大 (N qubit 算法需 $O(N^2)$ 个光子) + 确定性地产生簇态难——仍是工程挑战。

22.4.6 PsiQuantum 的选择

PsiQuantum 公开宣称走 MBQC 路线:

- 3D 簇态 + 架构容错 (FTQC, ch19)

- 目标是百万物理光子实现实用大规模容错量子计算

- 用 SiN 芯片 + 高速 SNSPD + 经典前馈 FPGA

22.4.7 MBQC 的真实代价

MBQC 不是"免费"的光量子计算:

- N 个逻辑 qubit 的算法需要 $O(N^2)$ 物理光子

- 每个光子必须通过无损传输 (损耗 < 1 dB/m)

- 前馈延迟限制测量深度 ~ 100 ns 量级

- 工程难度极高,但理论架构优雅

22.5 玻色采样——量子优越性

22.5.1 问题陈述 (Aaronson-Arkhipov, 2010)

问题: 给定一个 $M \times M$ 酉矩阵 $U$ (描述线性光网络), 把 $N$ 个全同光子输入到 $M \geq N^2$ 个模,采样输出光子分布在哪些模。

输入: $|\psi_{\text{in}}\rangle = |1_1, 1_2, \ldots, 1_N, 0, \ldots, 0\rangle$ ($N$ 个单光子 in $N$ 个模)

演化: $|\psi_{\text{out}}\rangle = U_{\text{linear}} |\psi_{\text{in}}\rangle$

采样: 测输出——光子出现在哪些模?

22.5.2 复杂度论猜想

结论 (假设两个未被证明的猜想):

经典量子
计算输出分布需要永久 Pfaffian计算输出分布 = 矩阵积和式
复杂度 $\sim e^{O(N \log N)}$复杂度 $\sim O(N \cdot M)$ (多项式)
实战不可行可采样

结论: 即使只做这一个问题,光量子相比经典计算机有超多项式加速。这就是量子优越性——不需要通用量子计算!

22.5.3 九章 76 光子 (USTC 2020)

2020 年 12 月,中国科学技术大学潘建伟团队用 76 个光子、100 个模的高斯玻色采样实现了量子优越性:

- 采样任务 $10^{14}$ 倍加速(对比超级计算机)

- 首次光子数 > 50 的玻色采样

- 争议: 经典新算法 (pan & zhang 2022) 把加速比降到 $10^8$——但仍远超经典

22.5.4 Borealis 216 模 (Xanadu 2022)

Xanadu Borealis 把"高斯玻色采样"升级到动态可编程 + 216 模:

- 可调延迟线 + 可重构分束器网络

- 比 2020 九章多许多自由度

- 第一次让玻色采样机完全程序化

22.5.5 玻色采样的局限

玻色采样不是通用计算:

- ✗ 不能做 Shor

- ✗ 不能做 Grover

- ✗ 不能做 VQE/QAOA

玻色采样只是展示"量子可以某些问题超越经典"——一个里程碑,不是终点。

注意: 以下"qubit"指逻辑 qubit (FTQC, ch19), 不是单个光子。1 个逻辑 qubit 背后通常需要 100-10000 个物理 qubit (取决于纠错码, ch18 表面码 ~1000)。所以"100 万逻辑 qubit" 实际对应 ~10⁸-10⁹ 物理 qubit。

22.6.2 损失如何传播

单光子(单模) 损失不改变态纯度——只是概率衰减: $P = (1-L)^N$ ($L$ 损失率)。

但多光子(纠缠) 损失破坏态——一旦丢失一个光子,纠缠完全失效。这就是为什么光量子容错难:

22.6.3 损失阈值——光量子专用容错

经典阈值 (ch18, 表面码): ~1%

光子专用阈值 (Varnava 2006, Ralph 2007, Rabin-Folmer 2023): ~10-30%

理由: 光子损失只"删除" (erasure) 一个 qubit, 而其他错误旋转 (bit/phase flip)——删除更可控。光子专用纠错码 (loss codes) 设计是删除纠正——相对更简单。

22.10.5 思考题

A1 (KLM 概率门): KLM 概率性 CNOT 门的成功概率是 1/4。如果实际用 KLM 实现一个8 qubit 算法需要 40 个 CNOT,平均需要多少次重复才能全部成功?

答案: $p = (1/4)^{40} \approx 10^{-24}$。期望次数 $1/p \approx 10^{24}$ 次——天文数字。结论: 纯 KLM 不可直接使用;MBQC + 容错码是必要的工程优化。

A2 (SiN vs 硅光子损耗): SiN 是 0.1 dB/m,硅光子是 1-3 dB/cm。10 cm 距离 SiN 损失多少 dB?硅光子损失多少 dB?

答案:

- SiN: $0.1 \times 0.1 = 0.01$ dB (几乎无损耗)

- 硅光子: $1\text{ dB/cm} \times 10\text{ cm} = 10$ dB (即损耗功率的 90%)

结论: 长路径集成必须用 SiN,这正是 PsiQuantum 的选择。

A3 (玻色采样 vs 通用算法): 玻色采样只是采样(不是函数计算)。理论上,任何特定函数计算只要被编码成玻色采样问题,也能用光量子加速——但是这种编码通常不自然。请用一句话解释为什么玻色采样不能直接做 Shor 算法?

答案: Shor 算法需要量子傅里叶变换 (ch09) 和大量条件逻辑门,无法简单编码成"高斯玻色采样"问题。光量子仍需要做通用量子计算,MBQC + 容错码是必经之路。

A4 (光子 T1 的"概念错误"修正): ch21 表格 21.9.4 中,光子的 T1 列从"长 (光子不衰)"修正为"N/A (光子飞行, 不存储)"。请解释:(a) 为什么光子没有 T1?(b) 光子的"损耗"是什么物理过程?(c) 用 Xanadu Borealis 的 216 模举例,每个模如果损耗 5%,输出正确采样的概率是多少?

答案:

(a) T1 是能级寿命 (ch05):高能态自然衰减时间。光子根本不会"留在能级"——它飞行出去就走了。

(b) 光子"损耗"包括:吸收 (被介质吸收入热) + 散射 (瑞利/拉曼散射) + 探测失败 (SNSPD 暗计数/效率<100%)。

(c) 216 模每模 5% 损耗 → 每光子 5% 概率丢失 → 200+ 光子的多光子态 → 几乎全部事件至少丢失 1 个光子 ≈ 1.0(几乎所有输出不有效)。结论: 损耗是累积的——这就是为什么低损耗材料 (SiN, 0.1 dB/m) 是 PsiQuantum 的核心选择。

22.A 附录 A:KLM 定理的严格陈述

22.A.1 定理陈述

Knill-Laflamme-Milburn (2001) 定理: 设 $\mathcal{H} = \mathcal{H}_{\ ext{data}} \otimes \mathcal{H}_{\ ext{ancilla}}$,由数据光子 (任意多模) 和 $M$ 个单光子辅助模组成。给定:

1. 一个单光子源 (确定性)

2. 被动线性光学网络 (BS + PBS + 相移器)

3. 单光子数分辨探测器

4. 经典前馈 (测量结果决定下一步操作)

则对于任意输入态和任意目标酉变换 $U$,存在一个概率性协议,使得期望经过 $O(f(n))$ 步实现 $U$ 的近似(以高概率),其中 $n$ 是 qubit 数,$f(n)$ 是多项式。

22.B 附录 B:玻色采样复杂度论证明 (Sketch)

22.B.1 问题严格化

输入: $N$ 光子 in $N$ 模, $M = O(N^2)$ 模的全连接线性网络 $U \in \mathbb{U}(M)$。

演化: 输出态

$$|\psi_{\text{out}}\rangle = \frac{1}{\sqrt{N! \cdot \mathcal{S}}} \, U \, a_1^\dagger a_2^\dagger \cdots a_N^\dagger \, |\text{vac}\rangle$$

其中 $\mathcal{S}$ 是反对称化算符(确保 $N$ 个全同玻色子的正确波函数)。

采样: 测输出态(光子出现在哪些模),$X = (x_1, x_2, \ldots, x_M)$,其中 $\sum x_i = N$, $x_i \in \{0,1\}$。

22.B.2 复杂度猜想

猜想 1 (永久近似): 在 worst case 下,矩阵积和式 (matrix permanent) 不能在多项式时间内被经典计算机精确计算,只能近似到 $n^{-O(1)}$ 误差。

猜想 2 (反采样): 给定输出 $X$,不能经典高效采样到 $\Pr[X]$ 本身——只能采样到分布的近似。

由猜想 1 + 2,经典采样复杂度是 $\sim e^{O(N \log N)}$,而量子采样是 $O(N \cdot M)$。

22.C 附录 C:光子损失码 (Loss Code) + Rabin-Folmer 阈值

22.C.1 损失码定义

损失码 (loss code, Ralph 2007) 把一个逻辑光子编码到 $N$ 个物理光子:

$$|\overline{0}\rangle_L = |\underbrace{111\cdots 1}_{N}\rangle,\quad |\overline{1}\rangle_L = |\underbrace{000\cdots 0}_{N}\rangle + |\underbrace{111\cdots 1}_{N}\rangle$$

这样,最多 $t = (N-1)/2$ 个光子丢失仍可恢复。

22.C.2 Rabin-Folmer 阈值 (2023)

Rabin-Folmer 2023 定理: 光子损失容错阈值是 $1 - \sqrt{1 - p_{\text{th}}} \approx 27\%$,只要结构化损失码 (concatenated loss code) 可用。

实际工程上,PsiQuantum 目标是$5\text{-}10\%$ 单光子损失率——远超阈值,工程上可行。

# 第 11 章 Shor 因式分解算法

本章定位: 第三部分 · 量子算法与复杂性 · 第一章(开篇)

承接: 第 9 章 QFT 给了指数加速的核心子程序,第 10 章 Grover 给了二次加速的通用搜索 —— 现在问:"QFT 能用来解决经典难题吗?"

11.0 引言:从经典密码学到 Shor 算法 —— 指数加速的"王冠"

RSA 加密是当今互联网的基石。从你的银行转账、SSL 证书,到比特币、以太坊的签名,几乎所有公钥密码系统的安全性都建立在一个数学难题上:大整数因式分解。

经典计算机分解一个 $n$ 位的整数,目前最好的算法(general number field sieve, GNFS)需要 $O(\exp(n^{1/3} \log^{2/3} n))$ 步 —— 经典意义上的"亚指数"(sub-exponential),但不是多项式。当 $n = 2048$ 时,这相当于 $2^{112}$ 步 —— 实际不可行。这就是 RSA-2048 在 2026 年仍然被认为安全的原因。

1994 年,Peter Shor 在他的开创性论文 "Algorithms for quantum computation: discrete logarithms and factoring" [S94] 中提出了一种量子算法,只需 $O(n^3)$ 步就能分解 $n$ 位整数 —— 多项式时间!这意味着 RSA 在理论上被攻破。

算法时间复杂度加速类型实际破 RSA-2048
经典 GNFS$O(\exp(n^{1/3} \log^{2/3} n))$亚指数$\sim 2^{112}$ 步,不可行
Shor 量子$O(n^3 \log n)$多项式$\sim 10^{10}$ 步,可行(在大型量子计算机上)
加速比—指数加速巨大的实用意义

Shor 算法的核心洞察: 因式分解问题可以归约为"周期发现问题"(order-finding),而周期发现又可以用 QFT 指数加速地解决。

Shor 算法的"三个核心思想":

  1. 经典归约: 因式分解 → 找 $a^x \mod N$ 的周期 $r$ → gcd 给出因子
  2. 量子周期发现: QFT 把 $f(x) = a^x \mod N$ 的求值转化为 $r$ 的提取
  3. 经典后处理: 测量后,经典计算机从 $r$ 算出 $p, q$

本章的"5 个关键问题":

  1. RSA 跟因式分解有什么关系? (11.1 RSA 与因式分解)
  2. Shor 怎么把因式分解归约到周期发现? (11.2-11.3 核心思想 + 周期发现)
  3. 量子怎么找周期? (11.4 量子周期发现 + QFT)
  4. Shor 算法的完整电路长什么样? (11.5 完整电路 + 11.6 工作例子)
  5. Shor 多快? 跟经典比快多少? (11.7 复杂度 + 11.8 后量子密码学 + 11.9 物理挑战)

本章的"5 个关键概念":

  • RSA 安全性 = 因式分解难度 = $O(\exp(n^{1/3} \log^{2/3} n))$
  • 归约(reduction) = 把未知问题转化为已知问题
  • 周期(order) = 满足 $a^r \equiv 1 \pmod{N}$ 的最小正整数 $r$
  • QFT 应用 = 把周期函数 $f(x) = a^x \mod N$ 的求值转化为 $r$ 的提取
  • 多项式时间 = $O(n^3)$ 在量子计算机上可行

本章的"5 个关键转折":

  1. 因式分解不是直接可解的,但归约到周期发现
  2. 周期发现不是经典可解的,但归约到 QFT
  3. QFT 是指数加速的(第 9 章已证明)
  4. 所以因式分解是指数加速的
  5. RSA 安全性崩塌 → 后量子密码学兴起(NIST 2022 标准化)

11.0.1 三个"指数加速"对比

Shor 跟 Grover、量子模拟一起,构成量子计算的"三大应用":

算法加速经典复杂度量子复杂度应用
Grover二次$O(N)$$O(\sqrt{N})$无结构搜索
Shor指数(多项式 vs 亚指数)$O(\exp(n^{1/3} \log^{2/3} n))$$O(n^3)$因式分解
量子模拟指数$O(\exp(n))$$O(\text{poly}(n))$量子系统模拟

Shor 跟 Grover 的关系:

  • Grover 对任何 oracle 访问的问题都有效(只要"无结构")
  • Shor 只对有代数结构的问题(数论、群论)有效
  • Shor 比 Grover 强得多: Grover 加速比 $\sqrt{N}$,Shor 加速比 $N$(指数)
  • 但 Grover 适用范围更广

Shor 跟量子模拟的关系:

  • 都是指数加速
  • 量子模拟的应用是物理/化学(分子、材料的量子性质)
  • Shor 的应用是数论/密码学

11.0.2 为什么 RSA 是"最有名"的量子算法案例

Shor 算法是量子计算的"招牌" —— 几乎所有量子计算的公众讨论都会提到它。原因:

  1. 实际影响巨大: RSA 是互联网的基础设施。Shor 直接威胁它的安全性。
  2. 戏剧性: 经典算法需要宇宙年龄的时间,Shor 只需几小时。加速比令人震撼。
  3. 可解释性: 算法的核心思想(归约、QFT、周期发现)可以用简单的数学解释,不需要深奥的物理。
  4. 激励作用: 推动了数十年的量子计算研究(NIST PQC 标准化、各国量子计划)。
  5. 历史地位: 跟"图灵机"、"P vs NP" 一样, Shor 算法是计算理论的里程碑。

历史类比: Shor 算法之于量子计算,就像 PageRank 之于搜索引擎 —— 不是"第一个"算法,但是最有影响力的算法,让整个领域进入主流视野。

11.1 RSA 与因式分解问题

11.1.1 RSA 加密速览

RSA(Rivest-Shamir-Adleman, 1977) 是第一个实用的公钥密码系统,也是最广泛使用的一个。

密钥生成:

  1. 随机选两个大素数 $p, q$(每个 $\sim n/2$ 位)
  2. 计算 $N = p \cdot q$($n$ 位)
  3. 选 $e$ 与 $(p-1)(q-1)$ 互素(常用 $e = 65537$)
  4. 算 $d = e^{-1} \mod (p-1)(q-1)$
  5. 公钥 = $(N, e)$,私钥 = $(N, d)$ 或 $(p, q)$

加密: $c = m^e \mod N$

解密: $m = c^d \mod N$

安全性: 给定 $c = m^e \mod N$ 和公钥 $(N, e)$,恢复 $m$ 等价于分解 $N$。这是因为只有知道 $p, q$ 才能算 $d = e^{-1} \mod (p-1)(q-1)$。

11.1.2 因式分解的经典难度

问题: 给定 $N = p \cdot q$($p, q$ 是大素数),求 $p, q$。

经典算法的演进:

年份算法复杂度备注
~公元前试除法$O(\sqrt{N}) = O(2^{n/2})$朴素
1643Fermat$O(\sqrt{N})$接近 $\sqrt{N}$
1770s二次筛法(QS)$O(\exp(n^{1/2} \log^{1/2} n))$比试除快
1980s-1990s数论筛法(NFS)$O(\exp(c \cdot n^{1/3} \log^{2/3} n))$目前最佳
2024经典最好$O(\exp(1.923 \cdot n^{1/3} \log^{1/3} n))$仍是亚指数

$N = 2^{2048}$(RSA-2048)的实际分解:

  • 用 GNFS 需要 $\sim 2^{112}$ 步
  • 假设 $10^{10}$ 步/秒 的经典计算机(已经很乐观): 需要 $\sim 10^{17}$ 年 = 宇宙年龄的 10 亿倍
  • 实际不可行 —— 这就是 RSA-2048 在 2026 年安全的原因

11.1.3 Shor 算法的"破坏性"

Shor 1994 [S94]: 量子计算机可以用 $O(n^3 \log n)$ 步分解 $N$ —— 多项式时间!

$N$ 的位数 $n$经典(GNFS)Shor 量子加速比
100$\sim 2^{20}$$\sim 10^{6}$$10^{9}$
1000$\sim 2^{60}$$\sim 10^{9}$$10^{18}$
2048$\sim 2^{112}$$\sim 10^{10}$$10^{33}$
10000$\sim 2^{400}$$\sim 10^{11}$$10^{120}$

加速比 = 指数级别!

直觉: Shor 找到了因式分解的"结构" —— 它能归约到周期发现,而周期发现正好是 QFT 能指数加速解决的问题。这是"用量子算法解决经典难题"的教科书案例。

11.2 Shor 算法的核心思想:经典 + 量子分工

Shor 算法的精髓: 经典部分 + 量子部分的精妙分工。

部分任务算法难度
经典选 $a$, 算 $\gcd$, 处理失败简单算术$O(n^3)$
量子找 $a^x \mod N$ 的周期 $r$Shor(QFT)$O(n^3)$
后处理从 $r$ 提取因子经典数学$O(n^3)$

整体结构:

1. 【经典】随机选 a, 2 ≤ a ≤ N-1
2. 【经典】gcd(a, N) 是否 > 1?
   - 是 → 找到了因子,完成!
   - 否 → 继续
3. 【量子】用量子电路找 a^x mod N 的周期 r
4. 【经典】根据 r 的奇偶性处理:
   - r 是奇数 → 重新选 a
   - r 是偶数 → 计算 gcd(a^(r/2) - 1, N) 和 gcd(a^(r/2) + 1, N)
5. 检查是否得到非平凡因子

Shor 算法的"概率性":

注意:Shor 算法是概率性算法 —— 它的成功依赖于:

  1. 选的 $a$ 满足特定条件($r$ 是偶数 + $a^{r/2} \not\equiv -1$)
  2. 量子测量的"幸运"性

成功的概率: 给定随机 $a$, 满足条件 1 的概率 = $1 - 1/2^{k-1}$(其中 $k$ 是 $N$ 的不同素因子数,对 $N = p \cdot q$ 是 $k = 2$)。给定 $r$ 是偶数, $a^{r/2} \equiv -1$ 的概率 = $1/2$。所以单次成功的概率 $\geq 1/2$。

期望重试次数: $O(1)$(常数),总运行时间仍 = $O(n^3)$。

关键观察:

  • 量子部分(第 3 步)是用 QFT 找周期 —— 指数加速的核心
  • 经典部分(第 1, 2, 4, 5 步)是简单的算术 —— 多项式时间

Shor 算法的"5 个步骤" 的完整流程:

                ┌─────────────┐
                │  经典前置    │
                │  1. 选 a     │
                │  2. gcd 检查 │
                └──────┬──────┘
                       │
                       v
                ┌─────────────┐
                │  量子部分    │  <-- 指数加速!
                │  3. 找周期 r │  <-- 用 QFT
                │  (Shor 电路) │
                └──────┬──────┘
                       │
                       v
                ┌─────────────┐
                │  经典后处理  │
                │  4. 算 gcd   │
                │  5. 验证因子 │
                └─────────────┘
```


注: 整个算法的期望运行时间 = 经典部分 $O(n^3)$ + 量子部分 $O(n^3)$ + 经典后处理 $O(n^3)$ = $O(n^3)$ 多项式时间。





11.3 周期发现问题


11.3.1 周期(阶)的定义


定义: 给定整数 $a$ 和 $N = p \cdot q$, $a$ 模 $N$ 的阶(order)是满足


$$a^r \equiv 1 \pmod{N}$$


的最小正整数 $r$。


例子:


    

  • $N = 15, a = 2$: $2^1 = 2, 2^2 = 4, 2^3 = 8, 2^4 = 16 \equiv 1 \pmod{15}$。所以 $r = 4$。
    • 

  • $N = 15, a = 7$: $7^1 = 7, 7^2 = 49 \equiv 4, 7^3 = 28 \equiv 13, 7^4 = 91 \equiv 1 \pmod{15}$。所以 $r = 4$。
    • 

  • $N = 15, a = 11$: $11^1 = 11, 11^2 = 121 \equiv 1 \pmod{15}$。所以 $r = 2$。
    • 

  • $N = 15, a = 13$: $13 \equiv -2$, $13^2 \equiv 4, 13^4 \equiv 16 \equiv 1 \pmod{15}$。所以 $r = 4$。
    • 



11.3.2 周期 → 因子的数学推导


关键定理: 如果 $a$ 模 $N$ 的阶 $r$ 是偶数,且 $a^{r/2} \not\equiv -1 \pmod{N}$,那么


$$\gcd(a^{r/2} - 1, N) \quad \text{和} \quad \gcd(a^{r/2} + 1, N)$$


之一是 $N$ 的非平凡因子(非 1 也非 $N$)。


证明:


    

  • $a^r \equiv 1 \pmod{N}$,所以 $a^r - 1 \equiv 0 \pmod{N}$
    • 

  • 因式分解: $a^r - 1 = (a^{r/2} - 1)(a^{r/2} + 1)$
    • 

  • 所以 $N$ 整除 $(a^{r/2} - 1)(a^{r/2} + 1)$
    • 

  • 但 $N = p \cdot q$ 是 $p, q$ 的乘积,所以至少一个 $p, q$ 整除 $(a^{r/2} - 1)$ 或 $(a^{r/2} + 1)$
    • 

  • 假设 $a^{r/2} \not\equiv -1 \pmod{N}$(即 $a^{r/2} + 1$ 不是 $N$ 的倍数)
    • 

  • 那么 $p, q$ 不可能都整除 $a^{r/2} + 1$
    • 

  • 所以至少一个 $p, q$ 整除 $a^{r/2} - 1$
    • 

  • $\gcd(a^{r/2} - 1, N)$ 给出这个因子 ✓
    • 



失败条件:


    

  1. $r$ 是奇数 —— 没法算 $a^{r/2}$ (mod $N$ 需要整数指数)
    2. 

  2. $r$ 是偶数但 $a^{r/2} \equiv -1 \pmod{N}$ —— 此时 $(a^{r/2} + 1) \equiv 0$, $\gcd$ 给出 $N$ 本身
    3. 



两种失败都有办法处理: 重新选 $a$。期望几次尝试就能成功。


11.3.3 例子:$N = 15, a = 7$


$a = 7$ 的阶: $7^4 \equiv 1 \pmod{15}$,所以 $r = 4$。


$r = 4$ 是偶数 ✓


计算 $a^{r/2} = 7^2 = 49$:


    

  • $7^2 - 1 = 48$
    • 

  • $7^2 + 1 = 50$
    • 

  • $\gcd(48, 15) = 3$ ✓ (这是 $N$ 的非平凡因子)
    • 

  • $\gcd(50, 15) = 5$ ✓ (这是另一个因子)
    • 



得到: $N = 15 = 3 \times 5$ ✓


注: 11.3 跟 11.2 的关系 —— 11.2 说"经典+量子分工",11.3 是"经典部分的关键数学"。量子部分(11.4)就是用 QFT 找 $r$。




11.4 量子周期发现:QFT + 叠加 + 干涉


11.4.1 周期发现为什么"难"


经典: 计算 $a^x \mod N$ 对 $x = 0, 1, 2, \ldots$,直到 $a^r \equiv 1$,需要 $O(r)$ 步, $r$ 可以大到 $N$(最坏情况)。


量子: 我们不直接测量 $a^x \mod N$ 的值。我们间接地让 QFT 提取 $r$。


11.4.2 量子电路的核心思想


输入: 两个寄存器


    

  • 输入寄存器 $|0\rangle^{\otimes n}$(2n 个 qubit,足够大到表示 $0$ 到 $N^2 - 1$)
    • 

  • 输出寄存器 $|0\rangle^{\otimes n}$(n 个 qubit,足够大到表示 $a^x \mod N$)
    • 



算法:


步骤 1: 在输入寄存器上叠加所有可能的 $x$:


$$|0\rangle^{\otimes n} \to \frac{1}{\sqrt{N^2}} \sum_{x=0}^{N^2 - 1} |x\rangle$$


(用 $\hat{H}^{\otimes 2n}$)


步骤 2: 应用受控模幂 $U_a$:


$$U_a |x\rangle|0\rangle = |x\rangle|a^x \mod N\rangle$$


步骤 3: 测量输出寄存器,得到某个 $y = a^x \mod N$。此时输入寄存器塌缩到所有满足 $a^x \equiv y \pmod{N}$ 的 $x$ 的均匀叠加。


如果 $r$ 是 $a$ 模 $N$ 的阶,那么满足 $a^x \equiv y \pmod{N}$ 的 $x$ 形如 $x_0, x_0 + r, x_0 + 2r, \ldots$(其中 $x_0$ 是某个最小正解)。


输入寄存器的态变为:


$$|\psi\rangle = \frac{1}{\sqrt{N^2/r}} \sum_{k=0}^{N^2/r - 1} |x_0 + kr\rangle$$


步骤 4: 对输入寄存器应用逆 QFT(QFT$^{-1}$):


QFT 的魔法: 周期 $r$ 在频率域表现为峰值!测量后,峰值位置给出 $r$。


11.4.3 周期 → QFT 的数学细节


关键公式: 量子态 $|\psi\rangle = \frac{1}{\sqrt{M}} \sum_{k=0}^{M-1} |x_0 + kr\rangle$(其中 $M \approx N^2/r$)


应用 QFT 后:


$$\text{QFT}|\psi\rangle = \frac{1}{\sqrt{M}} \sum_{k=0}^{M-1} \frac{1}{\sqrt{N^2}} \sum_{j=0}^{N^2-1} e^{2\pi i (x_0 + kr) j / N^2} |j\rangle$$


$$= \frac{1}{N\sqrt{M}} \sum_{j=0}^{N^2-1} e^{2\pi i x_0 j / N^2} \left( \sum_{k=0}^{M-1} e^{2\pi i k r j / N^2} \right) |j\rangle$$


几何级数求和:


$$\sum_{k=0}^{M-1} e^{2\pi i k r j / N^2} = \begin{cases} M & \text{if } r j / N^2 \in \mathbb{Z} \\ \frac{1 - e^{2\pi i M r j / N^2}}{1 - e^{2\pi i r j / N^2}} & \text{otherwise} \end{cases}$$


关键: 当 $j$ 是 $N^2/r$ 的整数倍时, $r j / N^2 \in \mathbb{Z}$,振幅 = $M$(峰值)。


测量得到 $j \approx c \cdot N^2 / r$(其中 $c$ 是某个整数),用连分数算法(continued fraction) 从 $j/N^2$ 恢复 $r$。


11.4.4 测量结果的"提取 $r$"算法


经典后处理(连分数算法):


    

  1. 测量得到 $j \in \{0, 1, \ldots, N^2 - 1\}$
    2. 

  2. 计算 $\phi = j / N^2$ (这是一个 $0 \leq \phi < 1$ 的有理数)
    3. 

  3. 用连分数展开 $\phi = [a_0; a_1, a_2, \ldots]$ 找 $\phi$ 的最佳有理近似 $c / r'$(其中 $r' \leq N$)
    4. 

  4. 候选 $r = r'$ —— 这就是 $a$ 模 $N$ 的阶(可能需要验证)
    5. 



连分数算法的"魔法": 用 $O(n^2)$ 步(多项式时间) 就能从 $j/N^2$ 提取 $r$。


11.4.5 失败概率


问题: 测量可能给出 $j$ 接近 $0$ 或 接近 $N^2$ 的值,这些不直接给出 $r$。


解决:


    

  1. 重复几次量子测量,取大多数
    2. 

  2. 连分数算法会过滤掉不正确的 $j$
    3. 

  3. 经典验证: 用 $a^r \equiv 1 \pmod{N}$ 验证;如果不是,重新运行
    4. 



期望运行次数: $O(1)$ 次(常数) 就能以常数概率得到正确的 $r$。


失败概率的来源:


测量得到 $j$ 接近非峰值位置的概率不为零。详细分析给出测量得到"好" $j$(允许连分数恢复 $r$)的概率 $\geq 4/\pi^2 \approx 0.4$。所以期望几次测量就能成功。


完整的 Shor 算法的成功概率:


    

  • 单次量子测量: $\geq 4/\pi^2$
    • 

  • 选好的 $a$: $\geq 1/2$
    • 

  • 整体: $\geq 2/\pi^2 \approx 0.2$
    • 

  • 期望运行次数: $O(1)$ —— 几次就够
    • 



11.4.6 量子部分 vs 经典部分:加速比来源


关键对比:

加速来源:


    

  • 不是 gcd 算法(经典就够快)
    • 

  • 不是 模幂(经典 $O(n^3)$ 也够)
    • 

  • 是 周期发现 —— QFT 唯一带来的指数加速
    • 





11.5 Shor 算法的完整电路


11.5.1 电路总览


Shor 算法的完整电路包含以下部分:


┌──────────────────────────────────────────────────────────┐
│  输入寄存器 (2n qubit)         输出寄存器 (n qubit)        │
│  |0〉^⊗2n                       |0〉^⊗n                    │
│       │                            │                      │
│       v                            │                      │
│  [H^⊗2n]  (叠加)                   │                      │
│       │                            │                      │
│       │    (受控 U_a 门)            │                      │
│       │───────────────────────────>│                      │
│       │  (x, 0) -> (x, a^x mod N)  │                      │
│       │                            │                      │
│       v                            v                      │
│  [QFT^(-1)]                    [测量]  ---> 得到 y = a^x mod N│
│       │                                                   │
│       v                                                   │
│  [测量]  ---> 得到 j                                      │
└──────────────────────────────────────────────────────────┘
                        │
                        v
                [经典后处理]
                连分数算法从 j 提取 r
                gcd 算法从 r 提取因子


11.5.2 4 个核心模块


模块 1: 初始化 + 叠加


    

  • 输入: $|0\rangle^{\otimes 2n}|0\rangle^{\otimes n}$
    • 

  • 应用 $H^{\otimes 2n}$ 在输入寄存器
    • 

  • 态变为: $\frac{1}{N} \sum_{x=0}^{N^2-1} |x\rangle|0\rangle^{\otimes n}$
    • 



模块 2: 受控模幂 $U_a$


    

  • $U_a |x\rangle|y\rangle = |x\rangle|y \oplus (a^x \mod N)\rangle$
    • 

  • 其中 $\oplus$ 表示模 $2^n$ 加法
    • 

  • 关键: $U_a$ 是酉的(可逆的),这意味着量子电路可以做"模幂"
    • 



模块 3: 测量输出寄存器


    

  • 测量输出寄存器,得到 $y = a^x \mod N$ 对某个 $x$
    • 

  • 输入寄存器塌缩到所有满足 $a^x \equiv y \pmod{N}$ 的 $x$ 的均匀叠加
    • 

  • 周期 $r$ 编码在态的"周期性"中
    • 



模块 4: QFT$^{-1}$ + 测量输入寄存器


    

  • 对输入寄存器应用逆 QFT($\approx O(n^2)$ 个门)
    • 

  • 测量,得到 $j$
    • 

  • 用连分数算法从 $j$ 提取 $r$
    • 



11.5.3 关键操作:受控模幂 $U_a$ 的实现


$U_a$ 不是原子操作,需要分解为基本量子门:


    

  • 模乘 $U_M: |x\rangle \to |x \cdot M \mod N\rangle$
    • 

  • 模平方 $U_{a^2}, U_{a^4}, \ldots, U_{a^{2^k}}$(对每个 $k$)
    • 

  • 用二进制表示 $x = \sum_k 2^k b_k$,得 $a^x = \prod_k a^{2^k b_k}$
    • 



标准实现: 通过重复平方(modular exponentiation by repeated squaring):


    

  • 先算 $a^1, a^2, a^4, \ldots, a^{2^{2n}}$ mod $N$(经典预计算)
    • 

  • 对每个 $k$, 应用受控模乘 $|x\rangle|0\rangle \to |x\rangle|x \cdot a^{2^k b_k} \mod N\rangle$
    • 

  • 总共 $O(n^3)$ 个量子门
    • 



资源估算:


    

  • qubit 数: $\sim 3n$(输入 + 输出 + 辅助)
    • 

  • 门数: $O(n^3)$
    • 

  • 电路深度: $O(n^3)$
    • 



11.5.4 完整电路的"经典-量子边界"


步骤经典 / 量子时间
1. 选 $a$经典$O(n)$
2. $\gcd(a, N)$经典$O(n^2)$
3. 量子电路(找周期)量子$O(n^3)$
4. 连分数提取 $r$经典$O(n^2)$
5. $\gcd(a^{r/2} \pm 1, N)$经典$O(n^2)$
6. 验证经典$O(n^2)$


整体: 多项式时间 $O(n^3)$,其中量子部分只占一部分。


注: Shor 算法的关键洞察 —— 量子部分只需要几小时(在大型容错量子计算机上),就能完成经典部分需要数十亿年的工作。







11.6 工作例子:$N = 15, a = 7$ 完整 7 步演示


11.6.1 第 1 步:经典前置


输入: $N = 15$。


选 $a = 7$(随机, $2 \leq a \leq 14$)。


$\gcd(7, 15) = 1$ ✓ —— 没找到因子,继续。


11.6.2 第 2-4 步:计算 $7^x \mod 15$


经典预计算:


    

  • $7^1 \mod 15 = 7$
    • 

  • $7^2 \mod 15 = 49 \mod 15 = 4$
    • 

  • $7^4 \mod 15 = 4^2 \mod 15 = 16 \mod 15 = 1$ ← 周期!
    • 

  • 所以 $7^4 \equiv 1 \pmod{15}$,阶 $r = 4$
    • 



11.6.3 第 5 步:验证 $r = 4$ 是偶数


$r = 4$ 是偶数 ✓


$7^2 \mod 15 = 4$, 而 $-1 \mod 15 = 14$。 $4 \neq 14$,所以 $7^2 \not\equiv -1 \pmod{15}$ ✓


11.6.4 第 6 步:计算 $\gcd$


    

  • $7^2 - 1 = 48$, $\gcd(48, 15) = 3$ ✓
    • 

  • $7^2 + 1 = 50$, $\gcd(50, 15) = 5$ ✓
    • 



11.6.5 第 7 步:验证


$N = 15 = 3 \times 5$ ✓ —— 分解成功!


11.6.6 量子电路的对应步骤(高级)


初始化(输入寄存器 4 qubit, $N^2 = 225$, 用 $2^8 = 256$):


$$|\psi_0\rangle = |0000\rangle|0000\rangle$$


应用 $H^{\otimes 4}$(输入寄存器):


$$|\psi_1\rangle = \frac{1}{4} \sum_{x=0}^{15} |x\rangle|0\rangle^{\otimes 4}$$


应用 $U_7$(受控模幂 $7^x \mod 15$):


$$|\psi_2\rangle = \frac{1}{4} \sum_{x=0}^{15} |x\rangle|7^x \mod 15\rangle$$


测量输出寄存器(假设得到 $y = 4$,即 $7^x \equiv 4 \pmod{15}$ ):


满足 $7^x \equiv 4$ 的 $x$ 是 $\{2, 6, 10, 14\}$(模 $r = 4$ 等价)


输入寄存器塌缩到:


$$|\psi_3\rangle = \frac{1}{2}(|0010\rangle + |0110\rangle + |1010\rangle + |1110\rangle) = \frac{1}{2} \sum_{k=0}^{3} |2 + 4k\rangle$$


应用 QFT$^{-1}$:


测量得到 $j$,用连分数提取 $r$。


对 $N^2 = 256$ 的情形: 期望的 $j$ 值在 $\sim N^2/r = 64$ 附近(即 $j = 0, 64, 128, 192$)。


测得 $j = 64$,则 $\phi = 64/256 = 1/4$,连分数 = $[0; 4]$,所以 $r = 4$ ✓

11.7.1 量子部分时间复杂度


核心: 量子电路做 $n$ 位模幂 $a^x \mod N$ 一次,需要 $O(n^3)$ 个量子门。


详细分解:


    

  • 输入寄存器: $2n$ qubit(为了足够的精度,QFT 给出 $1/N^2$ 的精度)

  • 输出寄存器: $n$ qubit
    • 

  • 辅助 qubit: $O(n)$
    • 

  • 总 qubit: $O(n)$

  • $U_a$ 分解: $O(n)$ 个模乘

    • 

  • 总 $U_a$ 门数: $O(n^3)$
    • 

  • QFT: $O(n^2)$ 个门(用第 9 章的高效实现)
    •

11.7.4 算法的"工作原理"总结


为什么 Shor 比经典快这么多? 三个层次的洞察:


层次 1: 因式分解不是"原子"问题


经典看法: 因式分解是一个"硬"问题。Shor 的洞察: 它可以归约到周期发现,这是已知结构的问题。


层次 2: 周期发现不是"原子"问题


经典看法: 找周期需要 $O(r)$ 步"扫描"。Shor 的洞察: 它可以用 QFT 一次性得到(经典 DFT 就能"看到"周期;QFT 在量子计算机上指数加速这个操作)。


层次 3: 量子并行 + 干涉 = "免费"周期发现


经典扫描: 算 $a^0, a^1, \ldots, a^r$ 然后找周期,需要 $O(r)$ 步。 量子方法: 叠加所有 $x$ → 算 $a^x \mod N$(对所有 $x$ 同时) → QFT 把 $x$ 域变换到 $r$ 域 → 测量。


QFT 的"魔法": 对叠加态 $\frac{1}{\sqrt{N}} \sum_x |x\rangle$ 应用 QFT,得到频域的叠加态;如果是周期叠加,频域会自动聚类到 $r$ 的整数倍处。


关键洞察: Shor 的天才不是发明 QFT(第 9 章)也不是发明 gcd(经典算法),而是发现因式分解可以归约到周期发现这一步。这是算法设计的胜利,不是物理的胜利。

11.X 附录:Shor 算法的历史与影响


11.X.1 1994 年的"震撼"


1994 年 4 月, Peter Shor 在 AT&T Bell Labs 提出了这个算法。当时量子计算还远未是主流研究方向。


震撼的原因:


    

  • 数学上: 第一次展示了量子计算机能解决"有用"的经典难题
    • 

  • 实际: 直接攻击 RSA,这是当时最重要的公钥密码
    • 

  • 理论上: 第一次用 QFT 解决"非 QFT 直接可解"的问题
    • 



后续影响:


    

  • 1994-2000: 多个实验演示(简化版)
    • 

  • 2000s: 量子计算成为主流研究方向
    • 

  • 2010s: 多个物理平台(超导、离子阱)展示 Shor 算法
    • 

  • 2020s: 进入"后量子密码学"时代
    • 



11.X.2 跟 QFT 的关系


Shor 算法的核心 = QFT 应用于周期函数。


为什么 QFT 能找周期?


    

  • 经典 DFT: 把信号从时域变到频域,周期变成频谱中的峰值
    • 

  • QFT: 经典 DFT 的量子版本 —— 指数加速
    • 



Shor 用了 QFT 的什么性质:


    

  • 周期 $r$ 在频域表现为整数倍频率峰值($j = c \cdot N^2/r$)
    • 

  • QFT 后,测量几乎必然落在峰值上
    • 



注: Shor 算法的"量子部分"实际上只是 QFT 应用于一个特殊的"量子态"(周期叠加态)。Shor 的天才在于: 如何构造这个周期叠加态(用模幂 $U_a$)。


11.X.3 跟 Grover 的关系


ShorGrover
问题类型有结构(数论)无结构(搜索)
加速指数(多项式 vs 亚指数)二次($\sqrt{N}$ vs $N$)
核心子程序QFT振幅放大
需要的 qubit$O(n)$$O(n)$
需要的门$O(n^3)$$O(n \cdot 2^{n/2})$
应用密码学 + 数论搜索 + 优化


结论: Shor 比 Grover 强得多 —— 指数加速 vs 二次加速。但 Shor 只对有结构的问题有效(数论/代数);Grover 适用范围更广(任何 oracle 访问的问题)。


11.X.4 Shor 算法的局限


虽然 Shor 是理论突破,但实际破解 RSA 还需要:


    

  1. 数百万 qubit 的容错量子计算机
    2. 

  2. 数小时的运行时间
    3. 

  3. 数百万美元 的硬件成本
    4. 



当前状态(2026):


    

  • 最大的量子计算机: ~1000 qubit(IBM Condor, Atom Computing)
    • 

  • 还远未达到破解 RSA-2048 所需
    • 

  • 预计: 2030-2035 达到临界规模
    • 

  • 风险: "Harvest Now, Decrypt Later"
    • 



应对:


    

  • 现在就开始部署 PQC(长期保密数据)
    • 

  • 2024-2030: 完成主流系统迁移
    • 

  • 2030s: RSA 逐步退役
    •

11.X.6 Shor 算法的"哲学意义"


Shor 算法的发现改变了计算理论:


1. "量子优势"的具体化


1994 年之前,量子计算主要是"理论好奇"。Shor 第一次展示了实际的、经济的、有影响的量子优势。这激励了数十年的量子计算研究。


2. "归约"的力量


Shor 的核心洞察是归约 —— 把未知问题(因式分解)转化为已知问题(周期发现)。这是算法设计的经典方法 —— 很多算法(经典 + 量子)都是归约的结果。


**3. "密码学的脆弱性"


RSA 的安全性建立在一个未证明的假设上(因式分解是难的)。Shor 表明这个假设不成立(在量子计算模型下)。这告诉我们:安全性的证明需要严格的复杂性理论;经验假设是不够的。


**4. "QFT 是量子计算的核心"


Shor 之后,QFT 成为了量子算法的核心子程序。后续的量子算法(Simon, QPE, 量子模拟) 都用 QFT 或其变体。QFT 是"量子计算的工具箱"里最重要的工具。


**5. "硬件 + 算法的共进化"


Shor 算法对硬件的要求(数百万 qubit)推动了容错量子计算的发展。这反过来促进了量子算法研究(VQE/QAOA 等 NISQ 算法),因为 NISQ 时代需要更"硬件友好"的算法。算法 + 硬件的共进化是量子计算的核心特征。

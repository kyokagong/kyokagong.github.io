第 2 章 量子态与狄拉克符号

从波函数到态矢量 — 一把打开量子计算大门的钥匙

📐 ~7000 字 🧮 23 个公式 📚 11 节 ⏱ 约 35 分钟

2.0 引言

第 1 章我们沿着 1900 年普朗克到 1982 年费曼的历史脉络,梳理了量子力学从"修补经典物理"到"重新定义实在"的演进。但历史只是故事——要把量子力学用在工程上(尤其是造一台量子计算机),我们必须掌握一套精确、可计算、形式上自洽的数学语言。

这套语言就是本章的主角:狄拉克符号(Dirac notation),也叫 bra-ket 符号。它是物理学家保罗·狄拉克在 1939 年的《量子力学原理》里系统引入的,目的是把希尔伯特空间里那些"又像矩阵又像函数"的对象,用一个统一、好读、可线性操作的记号表示。

🎯 学完本章,你将掌握

  • 量子态如何抽象为希尔伯特空间中的矢量
  • 右矢 $|\\psi\\rangle$ 与左矢 $\\langle\\psi|$ 的对偶关系
  • 内积、外积、张量积三件套
  • 算符与可观测量的对应
  • 密度矩阵如何描述"我们并不确知"的混合态

这些是后面所有量子算法(从 Deutsch-Jozsa 到 Shor)的语法基础。

2.1 量子态的数学抽象:从波函数到态矢量

2.1.1 薛定谔的波函数

回顾第 1 章薛定谔 1926 年给出的方程:

$$i\hbar \frac{\partial}{\partial t}|\psi(t)\rangle = \hat{H}|\psi(t)\rangle$$

我们这里直接写成 $|\\psi(t)\\rangle$,而不是常见的 $\\psi(x,t)$。两种写法等价—— $|\\psi(t)\\rangle$ 是抽象的"态矢量",而 $\\psi(x,t) = \\langle x|\\psi(t)\\rangle$ 是它在"位置本征基"上的展开系数。两者关系是:

$$|\psi(t)\rangle = \int \psi(x,t)\,|x\rangle\,dx$$

这就是本章反复会用到的核心直觉:量子态是一个矢量,波函数是它在某组基下的坐标。

2.1.2 态空间 = 希尔伯特空间

量子态的集合构成一个 复数域上的希尔伯特空间 $\\mathcal{H}$。我们这一节只需要它的三条关键性质:

  1. 线性: $\\alpha|a\\rangle + \\beta|b\\rangle$ 仍是合法态($\\alpha,\\beta\\in\\mathbb{C}$)
  2. 可加内积: $\\langle a|b\\rangle$ 是一个复数,且 $\\langle b|a\\rangle = \\langle a|b\\rangle^*$
  3. 完备性:任何态都可以用一组基矢量的线性组合来表示(展开)

最常见的希尔伯特空间是 $\\mathbb{C}^n$(n 维复向量空间),对应一个 n 能级系统。一个二能级系统(即 qubit)的态空间就是 $\\mathbb{C}^2$,以后第 6 章我们会专门讲它。

2.1.3 抽象的代价:符号必须严谨

把量子态抽象为"希尔伯特空间中的矢量",看起来数学化过度,但它带来的好处远大于代价:

  • 不依赖具体表象:同一个态 $|\\psi\\rangle$,可以在位置表象、动量表象、自旋表象下展开,而不需要修改方程
  • 算符 = 矩阵:可观测量对应希尔伯特空间上的线性算符,本质就是矩阵
  • 合成系统 = 张量积:两粒子系统是 $\\mathcal{H}_A \\otimes \\mathcal{H}_B$,自然表示纠缠

接下来逐条展开。

2.2 右矢与左矢:ket 和 bra

2.2.1 ket:右矢 $|\\psi\\rangle$

$|\\psi\\rangle$ 读作 "ket psi",代表希尔伯特空间 $\\mathcal{H}$ 中的一个矢量。它是"列向量"的推广:

$$|\psi\rangle = \begin{pmatrix}\psi_1 \\ \psi_2 \\ \vdots \\ \psi_n \end{pmatrix},\quad \psi_i \in \mathbb{C}$$

ket 的运算是线性的:

$$\alpha|\psi\rangle + \beta|\phi\rangle = \begin{pmatrix}\alpha\psi_1 + \beta\phi_1 \\ \alpha\psi_2 + \beta\phi_2 \\ \vdots \end{pmatrix}$$

物理上 ket 表达态;它不依赖于你选哪一组基来"看"它。

2.2.2 bra:左矢 $\\langle\\psi|$

$\\langle\\psi|$ 读作 "bra psi",是 ket 的对偶——技术上说是 $\\mathcal{H}$ 上的连续线性泛函,即把 $\\mathcal{H}$ 映射到 $\\mathbb{C}$ 的线性映射。它是一个行向量:

$$\langle\psi| = (\psi_1^*,\ \psi_2^*,\ \dots,\ \psi_n^*)$$

注意复共轭:ket 是 $\\psi_i$,bra 是 $\\psi_i^*$。这保证下面要讲的内积是 $\\mathbb{C}$ 域的。

2.2.3 为什么叫 bra-ket

狄拉克把这个对偶的组合 $\\langle\\phi|\\psi\\rangle$ 读作 "bra-ket"(bracket,括号)。整个物理学的内积记号因此被"切开"成了两半:

  • 左半 = bra
  • 右半 = ket
  • 合起来 = bra(c)ket = 内积

这种"切括号"的写法看似花哨,真正的好处是它允许我们把内积之外的运算也写出来——比如外积 $|\\psi\\rangle\\langle\\phi|$、算符 $\\hat{A} = \\sum_i |i\\rangle\\langle i|$,在 bra-ket 记号下都成了自然书写。

2.3 内积

2.3.1 定义

两个态 $|\\psi\\rangle$ 和 $|\\phi\\rangle$ 的内积是:

$$\langle\phi|\psi\rangle = \sum_i \phi_i^* \psi_i \quad (\text{离散基})$$ $$\langle\phi|\psi\rangle = \int \phi^*(x)\psi(x)\,dx \quad (\text{连续基})$$

它有三条最重要的性质:

  1. 共轭对称性: $\\langle\\phi|\\psi\\rangle = \\langle\\psi|\\phi\\rangle^*$
  2. 第一变元反线性: $\\langle\\phi|\\alpha\\psi_1 + \\beta\\psi_2\\rangle = \\alpha^*\\langle\\phi|\\psi_1\\rangle + \\beta^*\\langle\\phi|\\psi_2\\rangle$
  3. 第二变元线性: $\\langle\\alpha\\phi_1 + \\beta\\phi_2|\\psi\\rangle = \\alpha\\langle\\phi_1|\\psi\\rangle + \\beta\\langle\\phi_2|\\psi\\rangle$

第 2、3 条是狄拉克符号最微妙的点:bra 是反线性的,ket 是线性的。这跟我们做微积分时"左边的量先共轭再线性"一致。开始学时容易记反,务必当心。

2.3.2 范数与归一化

态 $|\\psi\\rangle$ 的范数(norm)是:

$$\||\psi\rangle\| = \sqrt{\langle\psi|\psi\rangle}$$

注意 $\\langle\\psi|\\psi\\rangle$ 一定是非负实数(从共轭对称性可以推出),所以可以开根号。

物理上的量子态总是取范数为 1——这叫归一化:

$$\langle\psi|\psi\rangle = 1$$

这背后是玻恩概率诠释: $|\\psi_i|^2$ 是在测量中得到第 $i$ 个本征值的概率,所有概率加起来必须等于 1,于是:

$$\sum_i |\psi_i|^2 = \sum_i \psi_i^*\psi_i = \langle\psi|\psi\rangle = 1$$

2.3.3 正交性

两个态 $|\\psi\\rangle$ 和 $|\\phi\\rangle$ 正交当且仅当:

$$\langle\phi|\psi\rangle = 0$$

正交是量子计算里非常常用的概念——一组两两正交 + 各自归一的矢量叫正交归一基(orthonormal basis),记作 $\\{|i\\rangle\\}$。以后所有的"基底展开""量子傅里叶变换"都建立在正交归一基上。

2.4 外积

2.4.1 定义

ket 乘 bra: $|\\psi\\rangle\\langle\\phi|$ 是一个算符(矩阵),它作用在任意态 $|\\chi\\rangle$ 上:

$$(|\psi\rangle\langle\phi|)|\chi\rangle = |\psi\rangle(\langle\phi|\chi\rangle) = \langle\phi|\chi\rangle\cdot|\psi\rangle$$

中间 $\\langle\\phi|\\chi\\rangle$ 是一个复数,所以整个作用的结果是把 $|\\chi\\rangle$ 投影到 $|\\psi\\rangle$ 方向上的标量倍。

2.4.2 投影算符

特别地,当 $|\\psi\\rangle$ 是归一态时:

$$P_\psi = |\psi\rangle\langle\psi|$$

是一个投影算符——它把任意态投影到 $|\\psi\\rangle$ 上:

$$P_\psi|\chi\rangle = \langle\psi|\chi\rangle |\psi\rangle$$

验证它是投影的: $P_\\psi^2 = |\\psi\\rangle\\langle\\psi|\\psi\\rangle\\langle\\psi| = |\\psi\\rangle\\langle\\psi| = P_\\psi$(用了归一性 $\\langle\\psi|\\psi\\rangle=1$)。

2.4.3 完备性关系

最常用也最重要的恒等式之一——完备性关系:

$$\sum_i |i\rangle\langle i| = \hat{I}$$

其中 $\\{|i\\rangle\\}$ 是 $\\mathcal{H}$ 的一组正交归一基, $\\hat{I}$ 是单位算符。

为什么叫"完备"?把任意态插进这个恒等式:

$$|\psi\rangle = \hat{I}|\psi\rangle = \sum_i |i\rangle\langle i|\psi\rangle = \sum_i \psi_i |i\rangle$$

其中 $\\psi_i = \\langle i|\\psi\\rangle$ 是展开系数。这正是"任何态都能用基展开"的正式写法。

完备性关系是后面推导量子门、量子线路、Shor 算法时几乎每一步都要用的工具。读者请把它记在脑子里。

2.5 张量积

2.5.1 复合系统的态

物理上,当两个量子系统 $A$ 和 $B$ 组合时,合成系统的态空间是各自态空间的张量积:

$$\mathcal{H}_{AB} = \mathcal{H}_A \otimes \mathcal{H}_B$$

如果 $A$ 的态是 $|\\psi\\rangle_A$, $B$ 的态是 $|\\phi\\rangle_B$,合成态写作:

$$|\psi\rangle_A \otimes |\phi\rangle_B$$

2.5.2 矩阵表示

在选定基下,张量积的矩阵表示是克罗内克积(Kronecker product):

$$A \otimes B = \begin{pmatrix}a_{11}B & a_{12}B \\ a_{21}B & a_{22}B \end{pmatrix}$$

如果 $A$ 是 $m\\times m$ 矩阵, $B$ 是 $n\\times n$ 矩阵, $A\\otimes B$ 是 $mn\\times mn$ 矩阵。

2.5.3 算符的张量积

两个算符 $\\hat{A}$(作用在 $A$ 上)和 $\\hat{B}$(作用在 $B$ 上)可以自然地提升到合成系统上:

$$(\hat{A}\otimes\hat{B})(|\psi\rangle_A \otimes |\phi\rangle_B) = (\hat{A}|\psi\rangle_A) \otimes (\hat{B}|\phi\rangle_B)$$

2.5.4 可分态与纠缠态

合成态不一定能写成两个子系统态的张量积。能写出来的叫可分态(separable state):

$$|\psi\rangle_{AB} = |\psi\rangle_A \otimes |\phi\rangle_B$$

写不出来的——即不能用任何方式拆成两个子系统态的乘积——叫纠缠态(entangled state)。最著名的贝尔态就是:

$$|\Phi^+\rangle = \frac{1}{\sqrt{2}}(|00\rangle + |11\rangle)$$

这是两个 qubit 的最大纠缠态。

纠缠是量子信息处理的核心资源——量子隐形传态、超密编码、Shor 算法,本质上都在利用纠缠。我们会在第 4 章详细展开。

2.6 算符与可观测量

2.6.1 算符作为线性映射

量子力学里,一个可观测量(observable)对应一个厄米特算符(hermitian operator) $\\hat{A}$,满足:

$$\hat{A}^\dagger = \hat{A}$$

其中 $\\hat{A}^\\dagger$ 是 $\\hat{A}$ 的伴随(adjoint):矩阵的复共轭转置。ket 上的伴随是 bra: $\\hat{A}|\\psi\\rangle$ 的对偶是 $\\langle\\psi|\\hat{A}^\\dagger$。

2.6.2 厄米特 = 实数本征值

厄米特算符的本征值一定是实数。验证:设 $\\hat{A}|a\\rangle = a|a\\rangle$,则

$$a\langle a|a\rangle = \langle a|\hat{A}|a\rangle = \langle a|\hat{A}^\dagger|a\rangle = \langle a|\hat{A}|a\rangle^* = a^*\langle a|a\rangle$$

所以 $a = a^*$。这与"可观测量测量结果必须是实数"的物理要求一致。

2.6.3 例:泡利矩阵

最常用的厄米特算符是 2×2 泡利矩阵,它们就是 qubit 的自旋算符:

$$\sigma_x = \begin{pmatrix}0 & 1 \\ 1 & 0\end{pmatrix},\quad \sigma_y = \begin{pmatrix}0 & -i \\ i & 0\end{pmatrix},\quad \sigma_z = \begin{pmatrix}1 & 0 \\ 0 & -1\end{pmatrix}$$

加上单位矩阵 $\\sigma_0 = I$,它们一起构成 2 维希尔伯特空间上所有 2×2 厄米特矩阵的基——任何一个 qubit 的可观测量都可以写成 $\\hat{A} = a_0 I + a_x\\sigma_x + a_y\\sigma_y + a_z\\sigma_z$ 的形式。

2.6.4 算符的函数:从矩阵到对易

在量子力学里,我们经常需要对算符取函数——比如哈密顿量出现在 $e^{-i\\hat{H}t/\\hbar}$ 里。算符函数的定义是:先做谱分解,再把函数作用到本征值上(见下一节)。这种"先分解再组合"的逻辑贯穿整个量子计算。

2.6.5 对易子与海森堡方程

两个算符 $\\hat{A}$ 和 $\\hat{B}$ 的对易子是:

$$[\hat{A},\hat{B}] = \hat{A}\hat{B} - \hat{B}\hat{A}$$

如果 $[\\hat{A},\\hat{B}]=0$,我们说 $\\hat{A}$ 和 $\\hat{B}$ 对易;否则不对易。不对易的可观测量不能同时确定——这正是海森堡不确定性原理的算符版本(第 5 章我们会讲)。

算符随时间的演化满足海森堡方程:

$$i\hbar \frac{d\hat{A}}{dt} = [\hat{A}, \hat{H}] + i\hbar\frac{\partial \hat{A}}{\partial t}\Big|_{\text{显式}}$$

当 $\\hat{A}$ 不显含时间,简化为 $i\\hbar \\dot{\\hat{A}} = [\\hat{A}, \\hat{H}]$。

2.7 本征值、本征矢、谱分解

2.7.1 本征方程

算符 $\\hat{A}$ 的本征矢 $|a\\rangle$ 和本征值 $a$ 满足:

$$\hat{A}|a\rangle = a|a\rangle$$

物理上,本征值 $a$ 是测量可观测量 $\\hat{A}$ 时的可能结果,本征矢 $|a\\rangle$ 是测量后系统塌缩到的态。

2.7.2 谱分解

如果 $\\hat{A}$ 有完备的本征矢集合 $\\{|a_i\\rangle\\}$,对应的本征值 $\\{a_i\\}$,那么 $\\hat{A}$ 可以写成:

$$\hat{A} = \sum_i a_i |a_i\rangle\langle a_i|$$

这就是谱分解(spectral decomposition)——任何厄米特算符都可以"对角化"成这种形式。

验证: $\\hat{A}|a_j\\rangle = \\sum_i a_i |a_i\\rangle\\langle a_i|a_j\\rangle = \\sum_i a_i |a_i\\rangle \\delta_{ij} = a_j|a_j\\rangle$。

2.7.3 函数 f(Â)

利用谱分解,可以定义算符的任意函数:

$$f(\hat{A}) = \sum_i f(a_i) |a_i\rangle\langle a_i|$$

比如:

  • $e^{\\hat{A}} = \\sum_i e^{a_i}|a_i\\rangle\\langle a_i|$
  • $\\sqrt{\\hat{A}} = \\sum_i \\sqrt{a_i}|a_i\\rangle\\langle a_i|$ (在 $a_i \\ge 0$ 时)
  • $\\hat{A}^{-1} = \\sum_i \\frac{1}{a_i}|a_i\\rangle\\langle a_i|$ (在 $a_i \\ne 0$ 时)

这一招是后面量子相位估计、Shor 算法里 $e^{i\\hat{H}t}$ 形式出现的关键技术。

2.8 投影测量与玻恩规则

2.8.1 投影测量

一组正交归一基 $\\{|m_i\\rangle\\}$ 给出一个投影测量(projective measurement)。对态 $|\\psi\\rangle$ 进行该测量:

  • 结果: 出现指标 $i$ 的概率为 $p_i = |\\langle m_i|\\psi\\rangle|^2 = \\langle\\psi| m_i\\rangle\\langle m_i|\\psi\\rangle$
  • 塌缩: 测量后系统塌缩到 $\\frac{|m_i\\rangle}{\\sqrt{p_i}}$(因为要重新归一化)

这就是玻恩概率规则的正式形式: 测量结果是随机的,概率由内积模平方给出。

2.8.2 期望值

可观测量 $\\hat{A}$ 的期望值是:

$$\langle \hat{A} \rangle_\psi = \langle\psi|\hat{A}|\psi\rangle$$

把谱分解 $\\hat{A} = \\sum_i a_i|a_i\\rangle\\langle a_i|$ 代入:

$$\langle \hat{A} \rangle_\psi = \sum_i a_i |\langle a_i|\psi\rangle|^2 = \sum_i a_i p_i$$

正是"各本征值按其测量概率加权平均"。

2.8.3 投影测量算符的"塌缩"是不是必须的?

物理上,投影测量是破坏性的——一旦测得 $i$,态就从 $|\\psi\\rangle$ 塌缩到 $|m_i\\rangle$,原来的相位信息彻底丢失。这是量子计算里反复要规避的灾难(为什么我们要设计 Grover、Shor 这种"相干演化 + 末态才测量"的算法),也是第 5 章测量问题、量子芝诺效应等开放问题的入口。

2.9 密度矩阵与混合态

2.9.1 为什么需要密度矩阵?

到目前为止,我们假设"我们确知系统处于 $|\\psi\\rangle$"。但实际中常常不是这样——比如:

  • 系统是从大量样本里随机挑的,我们只知"70% 在 $|0\\rangle$,30% 在 $|1\\rangle$"
  • 系统是更大的、我们无法访问的子系统(纠缠的副产品)
  • 测量后我们只知道统计结果,不知道具体某次测量对应的态

纯态(pure state)用 $|\\psi\\rangle$ 描述就够;混合态(mixed state) 必须用密度矩阵 $\\hat{\\rho}$ 描述。

2.9.2 密度矩阵定义

如果系统以概率 $p_i$ 处于纯态 $|\\psi_i\\rangle$,密度矩阵定义为:

$$\hat{\rho} = \sum_i p_i |\psi_i\rangle\langle\psi_i|$$

其中 $p_i \\ge 0$, $\\sum_i p_i = 1$。

特别地,纯态对应 $\\hat{\\rho} = |\\psi\\rangle\\langle\\psi|$——只有一项, $p_1 = 1$。

2.9.3 密度矩阵的性质

  1. 厄米特: $\\hat{\\rho}^\\dagger = \\hat{\\rho}$
  2. 正定: 对任何 $|\\phi\\rangle$, $\\langle\\phi|\\hat{\\rho}|\\phi\\rangle \\ge 0$
  3. 迹为 1: $\\text{tr}(\\hat{\\rho}) = 1$ (因为 $\\sum_i p_i = 1$)
  4. 纯态判据: $\\text{tr}(\\hat{\\rho}^2) = 1$ (对纯态); $< 1$ (对混合态)

2.9.4 约化密度矩阵与纠缠的"看见"

最有洞察力的应用——部分求迹。如果合成态 $\\hat{\\rho}_{AB}$ 在 $\\mathcal{H}_A \\otimes \\mathcal{H}_B$ 上,我们可以"丢掉"B 子系统:

$$\hat{\rho}_A = \text{tr}_B(\hat{\rho}_{AB}) = \sum_i \langle b_i|\hat{\rho}_{AB}|b_i\rangle$$

其中 $\\{|b_i\\rangle\\}$ 是 $\\mathcal{H}_B$ 的任意一组基。

惊人的事实: 即使合成态 $|\\psi\\rangle_{AB}$ 是纯态,如果它纠缠, $\\hat{\\rho}_A$ 也会是混合态( $\\text{tr}(\\hat{\\rho}_A^2) < 1$)。纯态+部分求迹=混合态,这是纠缠的算符表达。

例:贝尔态 $|\\Phi^+\\rangle = \\frac{1}{\\sqrt{2}}(|00\\rangle + |11\\rangle)$。它的密度矩阵是:

$$\hat{\rho}_{AB} = \frac{1}{2}(|00\rangle + |11\rangle)(\langle 00| + \langle 11|) = \frac{1}{2}(|00\rangle\langle 00| + |00\rangle\langle 11| + |11\rangle\langle 00| + |11\rangle\langle 11|)$$

对 B 求迹后:

$$\hat{\rho}_A = \text{tr}_B(\hat{\rho}_{AB}) = \frac{1}{2}|0\rangle\langle 0| + \frac{1}{2}|1\rangle\langle 1| = \frac{I}{2}$$

这是完全混合态——你完全不知道 A 的状态,但 AB 合起来是纯态。这就是"纠缠"在密度矩阵语言下的精确含义。

2.9.5 混合态的演化

混合态的演化满足刘维尔方程:

$$i\hbar \frac{d\hat{\rho}}{dt} = [\hat{H}, \hat{\rho}]$$

形式上跟纯态的薛定谔方程一致,只不过换成密度矩阵。开放系统的演化(有耗散、退相干)需要 Lindblad 主方程来描述,我们会在第 16 章展开。

张量积$|\\psi\\rangle_A \\otimes |\\phi\\rangle_B$复合系统的态
厄米特算符$\\hat{A}^\\dagger = \\hat{A}$可观测量
谱分解$\\hat{A} = \\sum_i a_i |a_i\\rangle\\langle a_i|$把算符对角化
投影测量$p_i = |\\langle m_i|\\psi\\rangle|^2$玻恩规则
密度矩阵$\\hat{\\rho} = \\sum_i p_i |\\psi_i\\rangle\\langle\\psi_i|$描述纯态+混合态
部分求迹$\\hat{\\rho}_A = \\text{tr}_B(\\hat{\\rho}_{AB})$看见纠缠的工具

为后续章节铺的路

  • 第 3 章 叠加原理与量子干涉: $|\\psi\\rangle = \\alpha|0\\rangle + \\beta|1\\rangle$——这正是两能级系统的最简形式,本章定义的内积、外积、测量会立即派上用场
  • 第 4 章 量子纠缠与贝尔不等式: 张量积和密度矩阵会全程出镜
  • 第 5 章 量子测量与不确定性原理: $[\\hat{A}, \\hat{B}] \\ne 0$ 的后果
  • 第 6 章 量子比特: 本章所有抽象都聚焦到 $\\mathcal{H} = \\mathbb{C}^2$ 的二维特例——也就是 qubit
  • 第 8 章 量子电路的数学模型: 用本章语言写"对 qubit 的酉演化 + 测量"

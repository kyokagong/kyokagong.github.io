9.0 引言:从经典 DFT 到 QFT

傅里叶变换(Fourier Transform)是 19 世纪以来最重要的数学工具之一。从信号处理到偏微分方程,从密码学到量子物理,傅里叶变换无处不在。经典计算机上,快速傅里叶变换(FFT)(Cooley-Tukey, 1965)把 $N$ 点离散傅里叶变换(DFT)的复杂度从 $O(N^2)$ 降到 $O(N \log N)$ —— 这是20 世纪算法界最重要的加速之一。

但量子版本可以更进一步:量子傅里叶变换(QFT) 只需要 $O(n^2)$ 个门(其中 $N = 2^n$),而经典 FFT 需要 $O(N \log N) = O(n \cdot 2^n)$ 个操作。指数加速!

但这里有一个至关重要的微妙之处:QFT 输出的不是一个"频谱",而是一个量子态。直接测量只能得到 $n$ 比特,丢失全部"中间信息"。

这就是 QFT 教学中的核心谜团: 1. QFT 本身是指数加速的(从 $O(N \log N)$ 到 $O(n^2)$) 2. 但 测量 QFT 输出不能直接得到频谱(只得到 $n$ 比特) 3. 那么 QFT 到底有什么用?

答案: QFT 必须嵌入到"量子相位估计(QPE)"框架中才能发挥作用。QPE 是 QFT 的"应用场景"——它精心准备输入态使得测量 QFT 输出恰好给出想要的信息。这个精巧的设计正是 Shor 算法 和许多量子机器学习算法的核心。

9.1 经典 DFT 回顾

经典离散傅里叶变换(DFT) 把一个长度为 $N$ 的复向量 $(x_0, x_1, \ldots, x_{N-1})$ 映射为另一个 $(y_0, y_1, \ldots, y_{N-1})$:

$$y_k = \frac{1}{\sqrt{N}} \sum_{j=0}^{N-1} x_j \cdot e^{2\pi i j k / N}, \quad k = 0, 1, \ldots, N-1$$

矩阵形式: $\mathbf{y} = \hat{F}_N \mathbf{x}$,其中 $\hat{F}_N$ 是一个 $N \times N$ 酉矩阵($\hat{F}_N^\dagger \hat{F}_N = \hat{I}$)。

关键性质:

  • 酉性: $\hat{F}_N^\dagger \hat{F}_N = \hat{I}$(行向量是正交的)
  • 对称性: $\hat{F}_N^4 = \hat{I}$(4 次应用回到原向量)
  • 可逆性: $\hat{F}_N^{-1} = \hat{F}_N^\dagger = \hat{F}_N^3$

FFT (Cooley-Tukey 1965):

  • 直接 DFT: $O(N^2)$ 操作
  • FFT: $O(N \log N)$ 操作(分治 + 蝶形运算)
  • 当 $N = 2^n$ 时,FFT 是最优的(就常数因子而言)

应用:

  • 信号处理(频谱分析)
  • 卷积(快速多项式乘法)
  • 偏微分方程求解
  • 密码学(数论变换)

9.2 QFT 的定义

量子傅里叶变换(QFT) 是 DFT 在量子态空间中的自然推广:

$$\hat{F}_N |j\rangle = \frac{1}{\sqrt{N}} \sum_{k=0}^{N-1} e^{2\pi i j k / N} |k\rangle$$

其中 $|j\rangle$ 和 $|k\rangle$ 是 $n$ qubit 计算基态($N = 2^n$)。

关键点:

  • 输入: 一个量子态 $|j\rangle$(基态)或叠加态 $\sum_j x_j |j\rangle$
  • 输出: 频域量子态 $\sum_k y_k |k\rangle$(其中 $y_k$ 是 DFT 系数)
  • 酉性: $\hat{F}_N$ 是一个酉算符(因为 DFT 矩阵是酉的)
  • 可逆: $\hat{F}_N^\dagger = \hat{F}_N^{-1} = \hat{F}_N^3$

线性作用: 由于 $\hat{F}_N$ 是线性的,

$$\hat{F}_N \left(\sum_{j=0}^{N-1} x_j |j\rangle\right) = \sum_{k=0}^{N-1} y_k |k\rangle, \quad y_k = \frac{1}{\sqrt{N}} \sum_{j=0}^{N-1} x_j e^{2\pi i j k/N}$$

即 QFT 把一个量子态的"概率幅"当作经典向量做 DFT。

二进制形式(对 $N = 2^n$): 设 $j = j_1 j_2 \cdots j_n$(二进制表示,$j_1$ 是最高位),则:

$$\hat{F}_{2^n} |j_1 j_2 \cdots j_n\rangle = \frac{1}{2^{n/2}} \bigotimes_{l=1}^{n} \left(|0\rangle + e^{2\pi i (0.j_{l} j_{l+1} \cdots j_n)} |1\rangle\right)$$

其中 $0.j_l j_{l+1} \cdots j_n = \sum_{m=l}^{n} j_m / 2^{m-l+1}$ 是二进制小数。

这是关键: 输出的每一个 qubit 只依赖于输入的一个子集,这让 QFT 可以用局部门实现。

9.3 QFT 是酉算符

定理: $\hat{F}_N$ 是酉的,即 $\hat{F}_N^\dagger \hat{F}_N = \hat{I}$。

证明: 计算 $\hat{F}_N^\dagger \hat{F}_N$ 的矩阵元:

$$(\hat{F}_N^\dagger \hat{F}_N)_{j, j'} = \sum_{k=0}^{N-1} (\hat{F}_N^\dagger)_{j,k} (\hat{F}_N)_{k, j'} = \sum_{k=0}^{N-1} \overline{(\hat{F}_N)_{k,j}} (\hat{F}_N)_{k, j'}$$

代入 $\hat{F}_N$ 定义:

$$= \sum_{k=0}^{N-1} \frac{1}{\sqrt{N}} e^{-2\pi i k j / N} \cdot \frac{1}{\sqrt{N}} e^{2\pi i k j' / N} = \frac{1}{N} \sum_{k=0}^{N-1} e^{2\pi i k (j' - j) / N}$$

这是几何级数求和:

  • 当 $j = j'$: $\sum_{k=0}^{N-1} 1 = N$,所以 $(\hat{F}_N^\dagger \hat{F}_N)_{j, j} = 1$
  • 当 $j \neq j'$: $\frac{1}{N} \cdot \frac{1 - e^{2\pi i (j' - j)}}{1 - e^{2\pi i (j' - j)/N}} = 0$(因为 $j' - j$ 是非零整数)

所以 $\hat{F}_N^\dagger \hat{F}_N = \hat{I}$。$\blacksquare$

推论:

  • $\hat{F}_N^{-1} = \hat{F}_N^\dagger = \hat{F}_N^3$
  • QFT 是可逆的(没有信息丢失)
  • QFT 可以实现为量子电路(可逆)

9.4 QFT 的电路实现

QFT 的电路实现是本章的核心。关键思想:利用 9.2 的二进制分解形式,把 QFT 分解为Hadamard + 受控相位旋转 + SWAP。

9.4.1 三个基本门

Hadamard 门(ch07 7.3): $$\hat{H}|j\rangle = \frac{1}{\sqrt{2}}(|0\rangle + (-1)^j |1\rangle) = \frac{1}{\sqrt{2}} \sum_{k=0}^{1} (-1)^{jk} |k\rangle$$

受控相位旋转 $\hat{R}_k$(ch07 7.5): $$\hat{R}_k = \begin{pmatrix} 1 & 0 \\ 0 & e^{2\pi i/2^k} \end{pmatrix}$$

注意 $\hat{R}_k$ 是对角的(不改变基态概率幅),只引入相位。

SWAP 门(ch07 7.7): 交换两个 qubit 的状态,用于反转 qubit 顺序。

9.4.2 QFT 电路的递归结构

设 $n$ qubit 输入 $|j_1 j_2 \cdots j_n\rangle$。QFT 电路按如下层次作用:

第 1 步: 对 qubit 1 作用 Hadamard + 受控相位(从 qubit 2 到 qubit $n$):

$$\hat{H}_1 \cdot (\hat{R}_2)_{12} \cdot (\hat{R}_3)_{13} \cdots (\hat{R}_n)_{1n} |j_1 j_2 \cdots j_n\rangle$$

把 qubit 1 变成:

$$\frac{1}{\sqrt{2}} \left(|0\rangle + e^{2\pi i (0.j_1 j_2 \cdots j_n)} |1\rangle\right)$$

第 2 步: 对 qubit 2 作用 Hadamard + 受控相位(从 qubit 3 到 qubit $n$):

$$\frac{1}{\sqrt{2}} \left(|0\rangle + e^{2\pi i (0.j_1 j_2 \cdots j_n)} |1\rangle\right) \otimes \frac{1}{\sqrt{2}} \left(|0\rangle + e^{2\pi i (0.j_2 \cdots j_n)} |1\rangle\right) \otimes \cdots$$

第 $k$ 步: 对 qubit $k$ 作用 Hadamard + 受控相位(从 qubit $k+1$ 到 qubit $n$)。

最后: 交换 qubit 顺序(SWAP 层),得到最终输出:

$$\frac{1}{2^{n/2}} \bigotimes_{l=1}^{n} \left(|0\rangle + e^{2\pi i (0.j_l \cdots j_n)} |1\rangle\right)$$

9.4.3 完整电路图(n=4)

q1: ──H───R_2────────R_3────────R_4─────────────────────────×──
              │           │           │                       │
q2: ─────────H───R_2────────R_3─────────────────×──SWAP──────×──
                            │                     │       │
q3: ────────────────────────H───R_2───────×──SWAP─────────────
                                          │           │
q4: ─────────────────────────────────────H───×──SWAP──────────

门数统计(n=4):

  • Hadamard: $n = 4$
  • 受控相位 $\hat{R}_k$: $\sum_{k=2}^{n} (k-1) = n(n-1)/2 = 6$
  • SWAP: $n/2 = 2$
  • 总计: $n + n(n-1)/2 + n/2 \approx n^2/2$ 个门

一般公式: QFT 在 $n$ qubit 上需要 $O(n^2)$ 个门(具体是 $n^2/2$ 量级)。

9.5 QFT 的"层次"展开

9.5.1 单 qubit QFT (n=1)

特例: 当 $n=1$ 时,QFT 退化为 Hadamard 门:

$$\hat{F}_2 |0\rangle = \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle) = \hat{H}|0\rangle$$ $$\hat{F}_2 |1\rangle = \frac{1}{\sqrt{2}}(|0\rangle - |1\rangle) = \hat{H}|1\rangle$$

所以 $\hat{F}_2 = \hat{H}$。这告诉我们: QFT 不是"新东西",而是 Hadamard 在高维的自然推广。

9.5.2 两 qubit QFT (n=2)

电路:

q1: ──H───R_2────────×──
              │       │
q2: ─────────H──×──SWAP

门数: $2 + 1 + 1 = 4$ 个门

作用: $\hat{F}_4 |j_1 j_2\rangle = \frac{1}{2}(|0\rangle + e^{i\pi j_1}|1\rangle)(|0\rangle + e^{i\pi(0.j_2)}|1\rangle)$(公式 9.2)

验证: $\hat{F}_4 |00\rangle = \frac{1}{2}(|0\rangle + |1\rangle)(|0\rangle + |1\rangle) = \frac{1}{2}(|00\rangle + |01\rangle + |10\rangle + |11\rangle)$ ✓

9.5.3 三 qubit QFT (n=3)

电路:

q1: ──H───R_2───R_3────────×──
              │    │        │
q2: ─────────H───R_2──×──SWAP──
                   │     │  │
q3: ───────────────H───×──────

门数: $3 + 3 + 1.5 \approx 7$ 个门

总公式: QFT 电路门数 = $n + \binom{n}{2} + \lfloor n/2 \rfloor \approx n^2/2$

9.5.4 n qubit QFT 通用电路模式

通用模板(n=5):

q1: ──H───R_2───R_3───R_4───R_5─────────────────────────────×──
              │     │     │     │                              │
q2: ─────────H───R_2───R_3───R_4──────×──────────────×──SWAP─────
                            │          │              │       │
q3: ───────────────────────H───R_2───R_3────×────────────SWAP──
                                      │      │              │
q4: ─────────────────────────────────H───R_2──×────────SWAP──────
                                              │              │
q5: ─────────────────────────────────────────H────────────────

层结构: 1. 第 1 层(q1): 1 个 H + 4 个 R_2/R_3/R_4/R_5 = 5 个门 2. 第 2 层(q2): 1 个 H + 3 个 R_2/R_3/R_4 = 4 个门 3. 第 3 层(q3): 1 个 H + 2 个 R_2/R_3 = 3 个门 4. 第 4 层(q4): 1 个 H + 1 个 R_2 = 2 个门 5. 第 5 层(q5): 1 个 H = 1 个门 6. SWAP 层: ⌊5/2⌋ = 2 个 SWAP = 2 个门 7. 总计: 5+4+3+2+1+2 = 17 个门

公式: $n + \binom{n}{2} + \lfloor n/2 \rfloor = 5 + 10 + 2 = 17$ ✓

9.5.5 复杂度函数详解

门数公式的直觉:

  • Hadamard: 每个 qubit 1 个 → $n$
  • 受控 $\hat{R}_k$: 第 $i$ 个 qubit 受后面 $(n-i)$ 个 qubit 控制 → $\sum_{i=1}^{n}(n-i) = \binom{n}{2}$
  • SWAP: 翻转 qubit 顺序需要 $\lfloor n/2 \rfloor$ 个 SWAP

总门数: $$N_{\text{gates}} = n + \binom{n}{2} + \lfloor n/2 \rfloor = n + \frac{n(n-1)}{2} + \left\lfloor \frac{n}{2} \right\rfloor \approx \frac{n^2}{2}$$

渐进复杂度: $O(n^2)$(因为 $n^2/2$ 是主导项)。

对比经典 FFT:

  • 经典 FFT: $O(N \log N) = O(n \cdot 2^n)$
  • 量子 QFT: $O(n^2)$
  • 加速比: $\frac{n \cdot 2^n}{n^2} = \frac{2^n}{n}$ —— 指数

9.5.6 错误率分析

前提: 每个门错误率 $p$,总门数 $G$ 个,电路成功率 $\approx (1 - p)^G \approx e^{-pG}$。

QFT 电路(n qubit):

  • 门数 $G = n^2/2$ 量级
  • 当 $p = 10^{-3}$(现代超导硬件水平):

- $n = 10$: $G \approx 50$,错误率 $1 - e^{-0.05} \approx 5\%$ - $n = 50$: $G \approx 1250$,错误率 $1 - e^{-1.25} \approx 71\%$ - $n = 100$: $G \approx 5000$,错误率 $1 - e^{-5} \approx 99\%$

结论: 大 $n$ QFT 在 NISQ 时代很难直接运行,需要容错量子计算(第五部分 ch19)。

优化: 通过早期测量 + 经典反馈(PE-style 算法),可以降低错误率。ch17-19 详细讨论容错。

9.6 QFT vs FFT 复杂度对比

这是本章最重要的洞察:

操作 经典 DFT 经典 FFT 量子 QFT
门数 / 操作数 $O(N^2)$ $O(N \log N)$ $O(n^2) = O(\log^2 N)$
存储 $N$ 个复数 $N$ 个复数 $n$ 个 qubit ($\log N$ 比特)
输出形式 完整频谱 $y_0, \ldots, y_{N-1}$ 完整频谱 量子态 $\sum y_k k\rangle$

当 $N = 2^{20} \approx 10^6$:

  • FFT: $N \log N \approx 2 \times 10^7$ 操作
  • QFT: $n^2 = 400$ 个门

加速比: $\frac{N \log N}{n^2} = \frac{2^n \cdot n}{n^2} = 2^n / n$ —— 指数加速!

为何指数加速?

  • 经典:必须逐个计算 $N$ 个 DFT 系数
  • 量子:用 $n$ qubit 叠加表示全部 $N$ 个系数,一次性全部计算

关键警告:加速是"输入已经是量子态"前提下的。如果要从经典数据构造 QFT 输入,需要 $O(N)$ 的"状态准备"代价,抵消 QFT 的加速。

9.6.1 经典 FFT 的历史

前 FFT 时代(1805-1965):

  • 高斯 1805 年就描述了类似 FFT 的算法,但不广为人知
  • DFT 直接计算:$O(N^2)$(每次 DFT 系数 $y_k$ 是 $N$ 项求和)

Cooley-Tukey FFT(1965):

  • 论文: J. W. Cooley, J. W. Tukey,《An Algorithm for the Machine Calculation of Complex Fourier Series》,Math. Comp. 19:297-301 (1965)
  • 思想: 分治 —— $N$ 点 DFT 分解为 2 个 $N/2$ 点 DFT
  • 复杂度: $O(N \log N)$
  • 影响: 使 DFT 在数字信号处理、图像处理、密码学等领域真正实用

FFT 的"奇遇记": Cooley-Tukey 1965 的论文是20 世纪被引用最多的数学论文之一(超过 50,000 次引用)。它的实用价值怎么强调都不过分。

9.6.2 经典 FFT 的算法核心

蝶形运算(butterfly operation):FFT 的"基本单元"。

设输入 $(a, b)$,蝶形输出 $(a + W \cdot b, a - W \cdot b)$ 其中 $W = e^{2\pi i/N}$ 是旋转因子。

FFT 算法(递归):

function FFT(x, N):
  if N == 1: return x
  even = FFT(x[0:N:2], N/2)
  odd  = FFT(x[1:N:2], N/2)
  for k = 0 to N/2 - 1:
    t = odd[k] * exp(-2πi k / N)
    output[k]       = even[k] + t
    output[k + N/2] = even[k] - t
  return output

总操作数: $T(N) = 2 T(N/2) + O(N) = O(N \log N)$

9.6.3 量子 QFT 的"指数加速"根本原因

经典: 算 $N$ 个 DFT 系数 $y_0, y_1, \ldots, y_{N-1}$ 逐个计算,每个 $y_k$ 是 $N$ 项求和 → $O(N^2)$,FFT 优化到 $O(N \log N)$。

量子: $n$ qubit 量子态 $\sum_j x_j |j\rangle$ 已经编码全部 $N$ 个输入系数。QFT 一次性把所有 $N$ 个 DFT 系数同时写入输出态的振幅中。

关键的量子优势: 1. 叠加: $n$ qubit 同时表示 $2^n$ 个复数 2. 干涉: QFT 的相位旋转在振幅上累积 $N$ 个输入 3. 并行: 量子算法本质上是"全 $N$ 维空间"的并行操作

但是: 量子加速仅在"输入已经是量子态"时才有意义。如果要把 $N$ 个经典数加载到 $n$ qubit 量子态,需要 $O(N)$ 操作,抵消 QFT 的 $O(n^2)$ 加速。

9.6.4 "条件性加速"的精确表述

定理(informal): QFT 提供从 $N \log N$ 到 $\log^2 N$ 的加速,前提是:

  • 输入数据已经编码为量子态
  • 输出只读 1 个采样(不是全部 $N$ 个系数)
  • 整体算法嵌入到 QPE / Shor / HHL 等框架中

违反任一前提:

  • 输入不是量子态:状态准备 $O(N)$ 抵消加速
  • 想读全部系数:需要 $O(N)$ 测量抵消加速
  • 直接用 QFT:得不到有意义的结果(9.8 输出问题)

结论: QFT 是"条件性"加速,不是通用加速。

9.6.5 QFT 的"门代价"vs FFT 的"操作代价"

QFT 门代价(实际硬件需要跑的"指令数"):

  • $n$ 个 Hadamard + $\binom{n}{2}$ 个受控相位 + $\lfloor n/2 \rfloor$ 个 SWAP
  • $O(n^2)$ 门

FFT 操作代价(经典 CPU 需要跑的"指令数"):

  • $N$ 个复数运算(加 + 乘),每个 $O(1)$
  • FFT 优化到 $N \log N$ 操作

门 vs 操作 的对应: 1 个量子门 ≈ 1 个经典操作(粗略)。所以 $O(n^2)$ 门 vs $O(N \log N)$ 操作 = 指数加速。

硬件时钟因素(典型值):

9.7 QFT 的逆变换

QFT 的逆 = DFT 的逆 = DFT 的共轭转置:

$$\hat{F}_N^\dagger |k\rangle = \frac{1}{\sqrt{N}} \sum_{j=0}^{N-1} e^{-2\pi i j k / N} |j\rangle$$

几何上: 经典 FFT 的"逆"是把频域信号转回时域。在量子版本中:

$$\hat{F}_N^\dagger = \hat{F}_N^{-1} = \hat{F}_N^3$$

(QFT 4 次回到单位算符。)

电路实现: 逆 QFT 的电路 = QFT 电路的反向 + 每个门的逆。

具体来说:

  • Hadamard 是自逆的: $\hat{H}^\dagger = \hat{H}$
  • 受控相位 $\hat{R}_k^\dagger = \hat{R}_k^{-1} = \hat{R}_{2\pi - 2\pi/2^k}$(取负相位)
  • SWAP 是自逆的: $\text{SWAP}^\dagger = \text{SWAP}$

所以: 逆 QFT 电路 = QFT 电路反向,且把所有 $R_k$ 替换为 $R_k^\dagger$。门数不变,仍是 $O(n^2)$。

9.8 QFT 的"输出精度"问题

这是本章最微妙也最重要的部分。

问题: QFT 输出量子态 $\sum_k y_k |k\rangle$。当我们测量这个态,只能得到一个 $k$ 值(以概率 $|y_k|^2$)。全部其他 $N-1$ 个系数都丢失!

这跟经典 FFT 完全相反:经典 FFT 输出全部 $N$ 个系数 $y_0, y_1, \ldots, y_{N-1}$ —— 我们可以任意查询。

结论: QFT 单独无法替代经典 FFT(无法读出全部系数)。

那 QFT 有用吗?: 有,但必须嵌入到"相位估计"或"周期发现"框架中:

  1. 量子相位估计(QPE, 9.9):精心构造输入态,使得 $|y_k|^2$ 在某个特定 $k$ 上集中 —— 测量得到想要的相位
  2. Shor 算法周期发现(9.10):输入态是"周期函数的叠加",QFT 输出在周期的倍数上集中 —— 测量得到周期

关键洞察: QFT 的"有用性"在于把时域信息(函数值)转化为频域信息(频率),但频域信息必须本来就稀疏(只有少数频率分量有显著概率幅)。如果频谱是密集的,QFT 输出是均匀叠加,测量得不到有用信息。

物理类比: 经典 FFT 就像"录音机的频谱分析仪"——可以看到全部频率分量。QFT 就像"听到一个和弦"——能感知整体音高,但无法分解出每个泛音。只有在和弦本身就是稀疏(纯音 + 谐波)时,才有用。

9.8.1 "输出问题"的精确数学

经典 FFT:

  • 输入: $\mathbf{x} = (x_0, x_1, \ldots, x_{N-1}) \in \mathbb{C}^N$
  • 输出: $\mathbf{y} = \hat{F}_N \mathbf{x} \in \mathbb{C}^N$
  • 访问: 输出 $\mathbf{y}$ 的每个 $y_k$ 都可以直接读取

量子 QFT:

  • 输入: $|\psi\rangle = \sum_j x_j |j\rangle$(基态上的叠加)
  • 输出: $\hat{F}_N |\psi\rangle = \sum_k y_k |k\rangle$
  • 访问: 只能通过测量采样一个 $k$ 值

测量的限制(量子力学的核心):

  • 测量 $\sum_k y_k |k\rangle$ 给出一个 $k$ 值
  • 测量不可逆: 一旦测量,态塌缩到 $|k\rangle$,失去其他信息
  • 重复测量给出相同 $k$(因为态已塌缩)
  • 想得到全部 $|y_k|^2$ 需要重新准备态然后测量,共需 $O(N)$ 次

这就是"量子测量限制" —— 直接读出 $n$ qubit 量子态的全部振幅需要 $O(2^n)$ 次测量(无加速)。

9.8.2 "输出问题"的两种缓解方案

方案 1: 相位估计框架 (QPE)

把"读出频谱"问题转化为"估计一个具体相位"问题:

  • 输入: $\hat{U}$, $|\psi\rangle$($\hat{U}$ 本征态),$n$ bit 估计寄存器
  • 输出: $n$ bit 估计 $\tilde{\varphi}$,使得 $|e^{2\pi i \tilde{\varphi}} - e^{2\pi i \varphi}| \leq 1/2^n$
  • 关键: QPE 的输入态精心准备,使得 QFT 输出集中在一个 $\tilde{\varphi}$ 上
  • 优势: 测量得到有意义的 $\tilde{\varphi}$(直接对应 $\hat{U}$ 的相位)

方案 2: 周期发现框架 (Shor)

把"频谱分析"问题转化为"周期性分析"问题:

  • 输入: 周期函数 $f(x) = a^x \mod N$ 的"叠加态" $\sum_x |x\rangle |f(x)\rangle$
  • 输出: 测量给出 $j/N \approx k/r$,通过连分数得到周期 $r$
  • 关键: 周期函数的频谱天然是稀疏的(只在 $j/N = k/r$ 处有尖峰)
  • 优势: 测量得到有意义的 $r$(直接对应 Shor 算法的"周期")

两种方案的共同点: 精心构造输入态,使得 QFT 输出自然集中,测量给出有意义的信息。

📌 关键架构澄清:QPE 和 Shor 不是并列的——Shor 算法内部使用 QPE(9.10 详述)。QPE 是更基础的"相位信息提取"工具,Shor / HHL / 量子化学等都是 QPE 的应用场景。

严格的依赖关系:

QFT (基础算符) → QPE (提取相位) → Shor / HHL / 量子化学 (具体应用)

9.9 详细讲 QPE,9.10 讲 Shor,9.V 简述 HHL,9.W 简述量子化学——都是 QPE 的应用。

9.8.3 何时 QFT 单独有用?

几乎从不。QFT 单独使用是无意义的 —— 你不能读出结果。

例外: 当你本来就需要"采样频谱"(比如蒙特卡洛),QFT 的"采样"可能恰好是你需要的。但这种情况极少。

结论: QFT 总是作为子程序嵌入到 QPE / Shor / HHL 等"上层算法"中。

9.9 QFT 的应用 1:量子相位估计 (QPE)

量子相位估计(Quantum Phase Estimation, QPE)是 QFT 的最重要应用。

9.9.1 QPE 的问题

输入:

  • 一个酉算符 $\hat{U}$
  • 一个量子态 $|\psi\rangle$,它是 $\hat{U}$ 的本征态: $\hat{U}|\psi\rangle = e^{2\pi i \varphi}|\psi\rangle$
  • 目标是估计相位 $\varphi \in [0, 1)$

输出:

  • 一个 $n$ bit 估计 $\tilde{\varphi}$,使得 $|\tilde{\varphi} - \varphi| \leq 1/2^n$

经典这个问题没有比"对角化 $\hat{U}$"更快的算法(对一般酉算符)。

量子 QPE 用 QFT 在 $O(\text{poly}(n))$ 步内精确求解。

9.9.2 QPE 的电路结构

量子比特组 (n bit, "估计寄存器"):

e_q1: ──H───U^(2^0)─────────×──
                              │
e_q2: ──H───U^(2^1)─────────│────×──
                              │     │
e_q3: ──H───U^(2^2)─────────│────│────×──
                              │     │     │
 ...                           │     │     │
e_qn: ──H───U^(2^(n-1))──────│─────│─────│──
                              │     │     │  │
目标 qubit (1 bit, "本征态"):     │     │     │  │
                              │     │     │  │
                              │     │     │  │
y_q: ─────|ψ⟩────────────────┴─────┴─────┴──
                              (受控 U^(2^k))
                              
                              ↓ (QFT^†)
                              
e_q1..n: ──QFT^†───测量───> 估计 φ (n bit)

关键步骤: 1. 在"估计寄存器"上作用 Hadamard → 形成叠加态 2. 受控 $\hat{U}^{2^k}$ 把相位 $e^{2\pi i \varphi 2^k}$ "写入" 估计寄存器的振幅 3. 逆 QFT 把"振幅相位"转化为"基态标签" 4. 测量 得到 $n$ bit 估计

详细数学(ch12 深入):

  • 受控 $\hat{U}^{2^k}$: $\hat{U}^{2^k}|\psi\rangle = e^{2\pi i \varphi 2^k}|\psi\rangle$
  • 估计寄存器状态: $\frac{1}{\sqrt{N}} \sum_{x=0}^{N-1} e^{2\pi i \varphi x} |x\rangle$
  • 逆 QFT: $\hat{F}_N^\dagger$ 把这变成"接近" $|\tilde{\varphi}\rangle$ 的态
  • 测量: 以高概率得到 $\tilde{\varphi} = \varphi$ 的 $n$ bit 表示

复杂度: $O(n^2)$ 个门 + $O(n)$ 个受控 $\hat{U}$ 应用。

9.9.3 QPE 是**精确**的还是**近似**的?

精确(ideal case): 当 $\varphi$ 恰好是 $k/2^n$ 形式(可被 $n$ bit 精确表示),QPE 精确给出 $\varphi$。

近似(general case): 当 $\varphi$ 不能被 $n$ bit 精确表示,QPE 给出最接近的 $n$ bit 估计,误差 $\leq 1/2^n$。

概率保证: 当误差用 $|e^{2\pi i \tilde{\varphi}} - e^{2\pi i \varphi}|$ 度量,QPE 成功(误差 $\leq 1/2^n$)的概率 $\geq 4/\pi^2 \approx 40.5\%$。

改进: 用更多测量 bit 或重复算法,可以把成功率提升到任意高(代价: 更多 qubit + 时间)。

9.9.4 QPE 的应用

  • Shor 算法(ch11): 估计"模幂算符"的相位 → 分解大整数
  • HHL 线性方程组算法(ch14): 估计"矩阵指数"的相位 → 解 $A\mathbf{x} = \mathbf{b}$
  • 量子化学(ch13): 估计"哈密顿量"的相位 → 计算分子基态能量
  • 量子机器学习: 估计"核矩阵"的特征值

QPE 是量子算法的"瑞士军刀"。

9.9.5 QPE 的详细数学推导

步骤 1: 设估计寄存器为 $|0\rangle^{\otimes n}$,目标 qubit 为 $|\psi\rangle$($\hat{U}$ 的本征态)。整体初态: $$|\Psi_0\rangle = |0\rangle^{\otimes n} |\psi\rangle$$

步骤 2: 对估计寄存器作用 $\hat{H}^{\otimes n}$: $$|\Psi_1\rangle = \frac{1}{\sqrt{N}} \sum_{x=0}^{N-1} |x\rangle |\psi\rangle$$

步骤 3: 受控 $\hat{U}^{2^k}$(对每个估计 qubit $k$):

  • 估计 qubit $k$ 处于 $|1\rangle$ 时,目标态获得相位 $e^{2\pi i \varphi \cdot 2^k}$
  • 由于 $|\psi\rangle$ 是本征态,$\hat{U}^{2^k}|\psi\rangle = e^{2\pi i \varphi 2^k}|\psi\rangle$

$$|\Psi_2\rangle = \frac{1}{\sqrt{N}} \sum_{x=0}^{N-1} |x\rangle \cdot e^{2\pi i \varphi x} |\psi\rangle = \frac{1}{\sqrt{N}} \sum_x e^{2\pi i \varphi x} |x\rangle \otimes |\psi\rangle$$

步骤 4: 对估计寄存器作用 $\hat{F}_N^\dagger$:

设 $\varphi = b/2^n$(精确情况)。代入 $|\Psi_2\rangle$ 的估计寄存器部分: $$\frac{1}{\sqrt{N}} \sum_x e^{2\pi i b x / 2^n} |x\rangle = \frac{1}{\sqrt{N}} \sum_x e^{2\pi i b x / N} |x\rangle = \hat{F}_N |b\rangle$$

应用 $\hat{F}_N^\dagger$: $$\hat{F}_N^\dagger \hat{F}_N |b\rangle = |b\rangle$$

所以测量估计寄存器必然得到 $|b\rangle$,即 $\varphi = b/2^n$ ✓

步骤 5: 当 $\varphi$ 不是精确 $b/2^n$ 形式时:

设 $\varphi = b/2^n + \delta$ 其中 $0 < \delta < 1/2^n$。

经过类似的推导,QPE 输出 $|\Psi_3\rangle$ 在 $|b\rangle$ 或 $|b+1\rangle$ 上的概率最大($\geq 4/\pi^2$),误差 $|\tilde{\varphi} - \varphi| \leq 1/2^n$。

这就是 QPE 的"精确/近似"区分 —— 取决于 $\varphi$ 能否用 $n$ bit 精确表示。

9.9.6 QPE 的"反直觉"之处

为什么需要 QFT?: 因为 $|x\rangle$ 的"相位信息"$e^{2\pi i \varphi x}$ 是编码在叠加态中,不能直接测量。必须用 QFT 把"相位信息"转化为"基态标签",才能通过测量提取。

直觉类比: 想象一个振动频率为 $\varphi$ 的音叉。把它的声音录音得到时域信号 $f(t) = e^{2\pi i \varphi t}$。要做频率分析,需要傅里叶变换。量子情况完全类似:相位编码在振幅里,提取需要 QFT。

9.9.7 QPE vs 经典相位估计

维度 经典 量子 (QPE)
算法 矩阵对角化 QPE 电路
复杂度 $O(N^2)$ 对角化 $O(n^2 + n \cdot T_U)$
存储 $N$ 个数 $n$ 个 qubit
输出 全部特征值 1 个特征值(每次)
加速比 (基线) $O(N/n)$ 指数

关键: QPE 的指数加速来自量子叠加和干涉,不是更快的对角化算法。

📌 复杂度组成: $O(n^2 + n \cdot T_U)$ 中, $n^2$ 来自逆 QFT 的门数(9.7), $n \cdot T_U$ 来自受控 $\hat{U}^{2^k}$ 序列($k = 0, 1, \ldots, n-1$ 共 $n$ 个)。

$T_U$ 的定义:实现受控 $\hat{U}^{2^k}$ 的代价。如果 $\hat{U}$ 本身需要 $T$ 个门实现,那么"直接重复"实现 $\hat{U}^{2^k}$ 需要 $2^k \cdot T$ 个门——这会爆炸!

实际做法:用平方技巧(classical modular exponentiation 思路), $\hat{U}^{2^k}$ 用 $O(\text{poly}(\log T, k))$ 个门实现(因为可以"复用"前一步结果,只多做一个乘法)。所以总 $T_U = O(\text{poly}(\log T) \cdot n)$。

综合: $O(n^2 + n \cdot \text{poly}(\log T) \cdot n) = O(n^2 \cdot \text{poly}(\log T))$ ——输入 $n$ 多项式, $T$ 多项式对数。

9.10 QFT 的应用 2:Shor 算法核心(周期发现)

Shor 算法(ch11 详细)是最著名的量子算法——它把大整数分解从亚指数降到多项式时间。

核心思想: 大整数 $N$ 的分解可以归约为"寻找一个周期函数的周期"。

9.10.1 周期函数

设 $a$ 跟 $N$ 互质。考虑函数 $f(x) = a^x \mod N$。

周期: $f(x + r) = f(x)$,其中 $r$ 是满足 $a^r \equiv 1 \pmod N$ 的最小正整数。

例子: $N = 15, a = 7$:

  • $f(0) = 1, f(1) = 7, f(2) = 4, f(3) = 13, f(4) = 1, f(5) = 7, \ldots$
  • 周期 $r = 4$。

9.10.2 Shor 的三步

  1. 构造叠加: $\frac{1}{\sqrt{N}} \sum_{x=0}^{N-1} |x\rangle |\text{anc}\rangle \xrightarrow{\text{oracle}} \frac{1}{\sqrt{N}} \sum_x |x\rangle |a^x \mod N\rangle$
  2. 测量第二个寄存器: 得到某个值 $y = a^{x_0} \mod N$,第一寄存器塌缩到周期叠加态 $\frac{1}{\sqrt{M}} \sum_{k=0}^{M-1} |x_0 + kr\rangle$
  3. 对第一寄存器做 QFT: QFT 把周期叠加态转化为在 $j/N \approx k/r$ 处的尖峰
  4. 测量第一寄存器: 得到 $j$ 满足 $j/N \approx k/r$,通过连分数提取 $r$

QFT 在第 3 步的关键作用: 把时域的周期信号(规则间隔的尖峰)转化为频域的离散频率($k/r$ 处的尖峰)。经典这个转换需要 $O(N)$ 操作(DFT),量子 QFT 只需要 $O(n^2)$。

9.10.3 Shor 算法的复杂度

  • 经典最佳: $e^{O(\sqrt[3]{(\log N)^{2/3}})}$(一般数域筛)
  • 量子 Shor: $O(n^3)$ 其中 $N$ 有 $n$ bit

当 $n = 2048$ bit (RSA-2048):

  • 经典: ~$10^{25}$ 操作(宇宙年龄都跑不完)
  • 量子: ~$10^{10}$ 个门操作(几小时到几天)

这是 QFT 应用的"王冠上的明珠" —— QFT 的指数加速直接转化为 Shor 算法的指数加速。

本章只给"预告" —— Shor 的完整算法、连分数提取、错误率分析在 ch11 详细给出。

9.10.4 Shor 算法的"详细三步"(数学展开)

设我们要分解 $N = 15$,选 $a = 7$。

步骤 1: 构造叠加 + 应用 oracle $$\frac{1}{4}(|0\rangle + |1\rangle + |2\rangle + |3\rangle)|0\rangle \xrightarrow{U_f} \frac{1}{4}(|0\rangle|1\rangle + |1\rangle|7\rangle + |2\rangle|4\rangle + |3\rangle|13\rangle)$$

其中 $U_f |x\rangle|0\rangle = |x\rangle |7^x \mod 15\rangle$。

步骤 2: 测量第二个寄存器 设测量第二个寄存器得到 $|4\rangle$($= 7^2 \mod 15$)。那么第一寄存器塌缩到所有满足 $7^x \equiv 4 \pmod{15}$ 的 $x$ 的叠加: $$|\psi_1\rangle = \frac{1}{\sqrt{4}}(|2\rangle + |6\rangle + |10\rangle + |14\rangle)$$

这是一串以周期 4 排列的状态: $|2\rangle, |2+4\rangle, |2+8\rangle, |2+12\rangle$。

步骤 3: 对第一寄存器做 QFT 把 $|\psi_1\rangle = \frac{1}{2}(|2\rangle + |6\rangle + |10\rangle + |14\rangle)$ 写成 $|\psi_1\rangle = \frac{1}{2}\sum_{k=0}^{3}|2 + 4k\rangle$。

应用 $\hat{F}_{16}$: $$\hat{F}_{16}|\psi_1\rangle = \frac{1}{2} \cdot \frac{1}{4} \sum_{k=0}^{3} \sum_{j=0}^{15} e^{2\pi i (2+4k) j / 16} |j\rangle$$

整理: $$= \frac{1}{8} \sum_{j=0}^{15} \left[\sum_{k=0}^{3} e^{2\pi i (4k) j / 16}\right] e^{2\pi i \cdot 2j / 16} |j\rangle = \frac{1}{8} \sum_{j=0}^{15} \left[\sum_{k=0}^{3} e^{2\pi i k j / 4}\right] e^{i\pi j / 4} |j\rangle$$

关键: 几何级数 $\sum_{k=0}^{3} e^{2\pi i k j / 4}$ 在 $j/4$ 是整数(即 $j = 0, 4, 8, 12$)时等于 4,其他时候为 0。

所以: $$\hat{F}_{16}|\psi_1\rangle = \frac{1}{2}(|0\rangle + |4\rangle + |8\rangle + |12\rangle)$$

测量: 概率 $1/4$ 给出 $j \in \{0, 4, 8, 12\}$。

步骤 4: 连分数提取周期 对每个测得的 $j$,计算 $j/N$ 的连分数展开,提取候选周期 $r$。

  • $j = 0$: $0/16 = 0$, $r$ 不确定
  • $j = 4$: $4/16 = 1/4$, $r = 4$ ✓
  • $j = 8$: $8/16 = 1/2$, $r = 2$(但 $7^2 \mod 15 = 4 \neq 1$,所以不是周期)
  • $j = 12$: $12/16 = 3/4$, $r = 4$ ✓

得 $r = 4$。然后计算 $\gcd(a^{r/2} \pm 1, N) = \gcd(7^2 \pm 1, 15) = \gcd(48, 15) = 3$ 和 $\gcd(50, 15) = 5$。所以 $15 = 3 \times 5$ ✓

9.10.5 Shor 算法的失败概率

关键: 步骤 2 测量第二寄存器可能得到"非典型"值(比如 $7^x \mod 15 = 7$ 而不是 4)。这时第一寄存器的叠加不是严格的周期叠加,QFT 输出不集中,测量可能给出错误 $r$。

缓解: Shor 算法是概率的(成功的概率 $\geq 1 - 1/2^{n-1}$ 通过选 $a$ 和重复),但不是确定的。重复运行 + GCD 检验 是必要的。

复杂度: Shor 实际需要 $O(n^3 (\log n)^2 \log(1/\epsilon))$ 个门,其中 $\epsilon$ 是错误率。容错实现需要 ~$10^6 \sim 10^9$ 个物理 qubit(NSA 估算),远超 NISQ 时代能力。

9.10.6 Shor 算法的"物理意义"

QFT 在 Shor 中的角色:频率分析。Shor 把"分解整数"问题精巧地转化为"分析周期性"问题,然后用 QFT 指数加速地做频率分析。这是 QFT 应用的最高典范 —— 不是"直接做 FFT",而是把一个完全不相关的问题(分解整数)变换成"QFT 能加速"的问题。

📌 为什么"周期"能用来"分解"?

关键定理:设 $N$ 待分解, $a$ 是 $[2, N-1]$ 随机选的数, $\gcd(a, N) = 1$。如果能找到 $a^r \equiv 1 \pmod N$ 的最小周期 $r$,并且 $r$ 是偶数, $a^{r/2} \not\equiv -1 \pmod N$,那么

$$\gcd(a^{r/2} - 1, N) \text{ 和 } \gcd(a^{r/2} + 1, N)$$

都是 $N$ 的非平凡因子(可能等于 1 或 $N$ 本身,需重试)。

完整例子 $N = 15$, $a = 7$:

  1. $7^1 = 7, 7^2 = 49 \equiv 4, 7^3 = 343 \equiv 13, 7^4 = 2401 \equiv 1 \pmod{15}$
  2. 所以 $r = 4$ (偶数 ✓)
  3. $7^{r/2} = 7^2 = 49 \equiv 4 \pmod{15}$
  4. $4 \not\equiv -1 \pmod{15}$(因为 $-1 \equiv 14 \pmod{15}$) ✓
  5. $\gcd(49 - 1, 15) = \gcd(48, 15) = 3$
  6. $\gcd(49 + 1, 15) = \gcd(50, 15) = 5$
  7. $15 = 3 \times 5$ ✓ 分解成功!

所以"分解"完全归约为"找周期"。经典找周期需要 $O(N)$ 次 oracle 调用(逐一计算 $a^x \mod N$ 直到重复);量子 Shor 用 QPE 把 oracle 调用降到 $O(1)$(叠加 + 干涉后一步找到 $r$)。这就是 QFT 指数加速的来源。

失败情形:

  • $r$ 是奇数 → 重选 $a$
  • $a^{r/2} \equiv -1 \pmod N$ → 重选 $a$
  • $\gcd = 1$ 或 $N$ → 重选 $a$

成功概率 $\geq 1 - 1/2^{n-1}$,只需重试几次。

9.11 QFT 的局限

虽然 QFT 是指数加速的,但它有局限:

  1. 输出问题(9.8 已述): 直接测量 QFT 输出只能得到 $n$ bit,不能读出全部 $N$ 个系数
  2. 输入问题: 经典数据 $\to$ 量子态需要 $O(N)$ "状态准备"代价,抵消 QFT 的加速
  3. 酉性限制: QFT 是酉算符,不能"就地"修改输入(必须保持可逆)
  4. 无随机访问: 不能像经典 FFT 那样"查询第 $k$ 个系数"
  5. 无信号处理灵活性: 经典 FFT 有"滤波器""卷积"等丰富操作,QFT 的"量子版本"需要重新设计

结论: QFT 不是经典 FFT 的"直接替代",而是一个不同范式的算法组件。

QFT 的"用武之地": 当问题自然有"频域稀疏性"(周期、对称性、本征值等)时,QFT 是关键工具。

9.X.1 QFT 的二进制展开推导

设 $N = 2^n$, $j = j_1 j_2 \cdots j_n$($j_1$ 是最高位)。则:

$$j = j_1 2^{n-1} + j_2 2^{n-2} + \cdots + j_n 2^0$$

$$\frac{j}{N} = \frac{j_1}{2} + \frac{j_2}{4} + \cdots + \frac{j_n}{2^n}$$

定义 $0.j_l j_{l+1} \cdots j_n = \sum_{m=l}^{n} j_m / 2^{m-l+1}$(二进制小数)。

关键恒等式: $$e^{2\pi i j k / N} = e^{2\pi i k (j_1/2 + j_2/4 + \cdots + j_n/2^n)} = \prod_{l=1}^{n} e^{2\pi i k j_l / 2^l}$$

代入 QFT 定义: $$\hat{F}_N |j\rangle = \frac{1}{\sqrt{N}} \sum_{k=0}^{N-1} \prod_{l=1}^{n} e^{2\pi i k j_l / 2^l} |k\rangle$$

关键: 把 $k$ 也写成二进制 $k = k_1 k_2 \cdots k_n$,则: $$e^{2\pi i k j_l / 2^l} = \prod_{m=1}^{l} e^{2\pi i k_m j_l / 2^{l-m+1}}$$

整理: $|k\rangle$ 的张量积结构允许"分离变量",得到:

$$\hat{F}_N |j\rangle = \frac{1}{2^{n/2}} \bigotimes_{l=1}^{n} \left(|0\rangle + e^{2\pi i (0.j_l j_{l+1} \cdots j_n)} |1\rangle\right)$$

这就是 9.2 的"二进制形式",关键的电路实现公式。

9.X.2 QFT 电路推导(详细)

目标: 用基本门实现 $\hat{F}_N$。

思路: 利用 9.4.1 的 Hadamard + 受控相位,逐步构造输出张量积结构。

第一步: 对 qubit 1 作用 Hadamard: $$\hat{H}_1 |j_1\rangle = \frac{1}{\sqrt{2}} \left(|0\rangle + (-1)^{j_1} |1\rangle\right) = \frac{1}{\sqrt{2}} \left(|0\rangle + e^{2\pi i j_1/2} |1\rangle\right)$$

第二步: 对 qubit 1 作用受控 $\hat{R}_2$(qubit 2 控制): $$(\hat{R}_2)_{12} \hat{H}_1 |j_1\rangle |j_2\rangle = \frac{1}{\sqrt{2}} \left(|0\rangle + e^{2\pi i j_1/2} e^{2\pi i j_2/4} |1\rangle\right) |j_2\rangle$$

第三步: 继续受控 $\hat{R}_3$(qubit 3 控制 qubit 1): $$\cdots = \frac{1}{\sqrt{2}} \left(|0\rangle + e^{2\pi i (0.j_1 j_2 \cdots j_n)} |1\rangle\right) |j_2 \cdots j_n\rangle$$

第四步: 对 qubit 2 作用 Hadamard + 受控 $\hat{R}_k$: $$\cdots = \frac{1}{\sqrt{2}} \left(|0\rangle + e^{2\pi i (0.j_1 \cdots j_n)} |1\rangle\right) \otimes \frac{1}{\sqrt{2}} \left(|0\rangle + e^{2\pi i (0.j_2 \cdots j_n)} |1\rangle\right) \otimes |j_3 \cdots j_n\rangle$$

继续: 直到所有 qubit 都"展开"为叠加态。

最后: 交换 qubit 顺序(SWAP 层),得到"标准输出": $$\hat{F}_N |j\rangle = \frac{1}{2^{n/2}} \bigotimes_{l=1}^{n} \left(|0\rangle + e^{2\pi i (0.j_l \cdots j_n)} |1\rangle\right)$$

门数统计:

  • Hadamard: $n$ 个(每个 qubit 1 个)
  • 受控 $\hat{R}_k$: $\sum_{k=2}^{n} (n - k + 1) = \binom{n}{2} = n(n-1)/2$ 个
  • SWAP: $\lfloor n/2 \rfloor$ 个
  • 总计: $n + n(n-1)/2 + \lfloor n/2 \rfloor = O(n^2)$

9.Y.1 输入态

设输入态是计算基态 $|j\rangle = |5\rangle = |0101\rangle$(即 $j = 0 \cdot 2^3 + 1 \cdot 2^2 + 0 \cdot 2^1 + 1 \cdot 2^0 = 5$,对应二进制 $0101$)。

QFT 应该输出: $$\hat{F}_{16} |0101\rangle = \frac{1}{4} (|0\rangle + e^{i\pi \cdot 5/8}|1\rangle)(|0\rangle + e^{i\pi \cdot 5/4}|1\rangle)(|0\rangle + e^{i\pi \cdot 5/2}|1\rangle)(|0\rangle + e^{i\pi \cdot 5/1}|1\rangle)$$

化简相位($e^{i\pi \cdot 5/8} = e^{i \cdot 5\pi/8}$, $e^{i\pi \cdot 5/4} = e^{i \cdot 5\pi/4} = e^{-i \cdot 3\pi/4}$, $e^{i\pi \cdot 5/2} = e^{i\pi/2} = i$, $e^{i\pi \cdot 5/1} = e^{i 5\pi} = -1$):

$$\hat{F}_{16} |0101\rangle = \frac{1}{4} (|0\rangle + e^{i 5\pi/8}|1\rangle)(|0\rangle - e^{-i \pi/4}|1\rangle)(|0\rangle + i|1\rangle)(|0\rangle - |1\rangle)$$

9.Y.2 电路逐步作用

完整 n=4 电路:

q1: ──H───R_2──────────R_3─────────────R_4────────────────────────×──
              │             │                  │                        │
q2: ─────────H───R_2────────────R_3──────────×───────────────×──SWAP──────
                                │                       │              │
q3: ───────────────────────────H───R_2─────────×───────────────SWAP────────
                                                │                    │
q4: ─────────────────────────────────────────H──────────────────────────

作用步骤:

  1. 第一轮(q1): $\hat{H}_1 \hat{R}_2^{(2)} \hat{R}_3^{(3)} \hat{R}_4^{(4)}$

- $\hat{H}_1 |0\rangle = \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle)$ - 加上 $\hat{R}_2^{(2)}$(q2 控制, $\theta = \pi/2$): 因为 $j_2 = 1$,相位加 $\pi/2$ - 加上 $\hat{R}_3^{(3)}$(q3 控制, $\theta = \pi/4$): 因为 $j_3 = 0$,无相位 - 加上 $\hat{R}_4^{(4)}$(q4 控制, $\theta = \pi/8$): 因为 $j_4 = 1$,相位加 $\pi/8$ - q1 状态: $\frac{1}{\sqrt{2}}(|0\rangle + e^{i(0 + \pi/2 + 0 + \pi/8)}|1\rangle) = \frac{1}{\sqrt{2}}(|0\rangle + e^{i 5\pi/8}|1\rangle)$ ✓

  1. 第二轮(q2): $\hat{H}_2 \hat{R}_2^{(3)} \hat{R}_3^{(4)}$(q2 的受控相位从 q3, q4)

- $\hat{H}_2 |1\rangle = \frac{1}{\sqrt{2}}(|0\rangle - |1\rangle)$ - 加上 $\hat{R}_2^{(3)}$(q3 控制): $j_3 = 0$,无相位 - 加上 $\hat{R}_3^{(4)}$(q4 控制): $j_4 = 1$,相位加 $\pi/4$ - q2 状态: $\frac{1}{\sqrt{2}}(|0\rangle - e^{i \pi/4}|1\rangle) = \frac{1}{\sqrt{2}}(|0\rangle + e^{i 5\pi/4}|1\rangle)$(相位 $\pi$ 移到 $5\pi/4$ ✓)

  1. 第三轮(q3): $\hat{H}_3 \hat{R}_2^{(4)}$

- $\hat{H}_3 |0\rangle = \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle)$ - 加上 $\hat{R}_2^{(4)}$(q4 控制): $j_4 = 1$,相位加 $\pi/2$ - q3 状态: $\frac{1}{\sqrt{2}}(|0\rangle + i|1\rangle)$ ✓

  1. 第四轮(q4): $\hat{H}_4$

- $\hat{H}_4 |1\rangle = \frac{1}{\sqrt{2}}(|0\rangle - |1\rangle)$ - q4 状态: $\frac{1}{\sqrt{2}}(|0\rangle - |1\rangle)$ ✓

  1. SWAP 层: 交换 q1↔q4, q2↔q3,把"自然顺序" $j_1 j_2 j_3 j_4$ 转为"标准顺序" $j_n j_{n-1} \cdots j_1$

最终输出: 跟 9.Y.1 公式完全一致 ✓

9.W 补充:QFT 在量子化学中的应用(简述)

QFT 在量子化学中有重要应用,虽然这里只给"预告":

问题: 计算分子哈密顿量 $\hat{H}$ 的基态能量 $E_0$。

经典:

  • Full CI(全组态相互作用):$O(e^n)$ 其中 $n$ 是电子数(指数!)
  • CCSD(T):$O(n^7)$,近似但精确
  • DFT:$O(n^3)$,但有系统误差

现实: QPE 需要很深的电路和很低的错误率,目前(2024-2025)还不能大规模实用化。但理论上,QFT 是量子化学模拟的核心。

展望: 等到容错量子计算实现(第五部分,ch19),QPE + VQE + QFT 将真正带来化学精度的分子模拟 —— 这是量子计算最有希望短期实用化的应用之一。

9.V 补充:用 QFT 求解"线性方程组"(简述)

HHL 算法(Harrow-Hassidim-Lloyd 2009)用 QFT 求解稀疏线性方程组 $A\mathbf{x} = \mathbf{b}$:

经典: 对 $N \times N$ 矩阵 $A$,求解需要 $O(N)$ 时间(对角化 + 代入)。

量子 HHL: 1. 把 $\mathbf{b}$ 编码为量子态 $|b\rangle$ 2. 用 QPE 估计 $A$ 的特征值 $\lambda_i$ 在 $A|b\rangle$ 上的作用 3. 在振幅上做"反演" $1/\lambda_i$ 4. 用逆 QPE 转回"基态标签" 5. 测量得到 $|x\rangle$

复杂度: $O(\log N)$ —— 指数加速!

但有限制:

  • 只对稀疏 $A$ 有效(经典: $A$ 必须是稀疏的)
  • 输出是 $|x\rangle$(量子态),不是经典向量 $\mathbf{x}$
  • 读取 $|x\rangle$ 需要 $O(N)$ 测量,抵消加速

结论: HHL 是"条件性"加速:对"读出量子态本身"的应用(如量子机器学习),HHL 是真正有用的;对"读出经典向量"的应用,没有优势。

应用: HHL 是 ch14 量子机器学习的关键子程序。

9.U 补充:QFT 的物理实现

📌 数据时效性说明: 以下实验时间为 2024-2025 快照。物理原理(QFT 电路结构)不变,但实验数据(qubit 数、保真度、错误率)会快速更新。读者查询最新进展请参考:

  • arXiv quant-ph(每日新论文)
  • Quantum Computing Report(q-computing.com)
  • 各硬件厂商的官方公告(IBM Quantum, IonQ, Quantinuum, Xanadu, QuEra, PsiQuantum)
  • 量子计算基准测试(Quantum Benchmarking, QED-C benchmarks)

QFT 已经在多种量子硬件上实验性实现:

9.U.1 超导 qubit (IBM, Google)

实验: IBM 2017 在 5 qubit 设备上实现 n=3 QFT。

  • 结果: 用 H + 受控相位 + SWAP 的组合
  • 精度: 由于 NISQ 噪声,保真度 ~80-90%
  • 意义: 第一次"小规模"QFT 演示

Google 2019: 在 Sycamore 53 qubit 设备上做"随机电路采样",QFT 作为子程序之一。

9.U.2 离子阱 (IonQ, Quantinuum)

优势: 离子阱的全连接使得受控相位很容易实现(任意两个 qubit 之间都能直接 CNOT)。 劣势: 门速度慢(~μs),qubit 数较少。

IonQ 2022: 实现 n=4 QFT,验证 $O(n^2)$ 复杂度。

9.U.3 光量子 (Xanadu, PsiQuantum)

优势: 光子的"飞行量子比特"很自然地实现 SWAP(光子在路径间传播)。 劣势: 确定性双 qubit 门难以实现。

Xanadu 2023: 用"连续变量"光学实现"类 QFT"算法。

9.U.4 中性原子 (QuEra, Atom Computing)

实验: QuEra 2024 在 256+ 中性原子阵列上演示 QFT 的子程序。 结果: 量子门保真度 ~99.5%,足够做中等规模 QFT。

9.U.5 QFT 的"困难"现实

关键挑战: 1. 错误率: QFT 的 n=20 需要 ~200 个门,即使每个门 0.1% 错误,总错误率 ~18% 不可接受 2. 连接性: 受控相位需要 qubit 相连,但超导 qubit 仅最近邻连接 3. SWAP 代价: 在受限连接性下,SWAP 可能比 QFT 本身还贵 4. 测量精度: 测量误差在 QFT 输出上放大

容错解决方案(第五部分):

  • 表面码(ch18):把 1 个"逻辑 qubit"用 ~$1000$ 个物理 qubit 编码
  • 阈值定理(ch19):物理错误率 < $10^{-3}$ 时,逻辑错误率指数下降
  • 代价: Shor-2048 需要 ~$10^6$ 物理 qubit(NSA 估算),远超当前硬件

9.U.6 现实时间表

乐观估计(容错量子计算实现):

  • 2030 年前:小规模 QFT (n=10) 在容错硬件上可靠运行
  • 2035 年前:中等规模 QFT (n=30-50) + 实用 Shor-1024
  • 2040 年前:大规模 QFT (n=100+) + 实用 Shor-2048 + 量子化学模拟

悲观估计:

  • 容错量子计算的"工程奇迹"远比预期难
  • QFT 可能要等到 2050 年才能"广泛实用"

实际可能:介于乐观和悲观之间。Shor 算法可能首先在特定硬件(如 Majorana 拓扑量子比特)上早期实现。

9.T 补充:QFT 的"替代方案"

虽然 QFT 是最常用的量子傅里叶变换,但还有几种变体:

9.T.1 半 QFT (Semi-classical QFT)

思想: 只用 1 个"估计 qubit",反复测量 + 经典条件操作。

优点:

  • 大幅减少 qubit 数($n$ 个 → 1 个)
  • 适合"短相干时间"硬件(可以早期测量 + 重置)

缺点:

  • 增加经典后处理
  • 总操作数可能比标准 QFT 多(因为反复重置)

应用: 现代 NISQ 时代的 QPE 实验常用 semi-classical QFT。

9.T.2 哈密顿模拟版本 (Hamiltonian Simulation QFT)

思想: 把 QFT 看作"哈密顿量 $\hat{H} = \sum_i \hat{Z}_i$ 的时间演化"。

实现: Trotter 分解 + 短时间演化步。

优点: 在某些硬件上(如冷原子)更自然。

缺点: 复杂度通常比标准 QFT 差一个常数因子。

9.T.3 近似 QFT (Approximate QFT)

思想: 忽略远距离的受控相位($\hat{R}_k$ 中 $k$ 大的门)。

具体: 只保留 $k \leq k_{\max}$ 的受控相位,其他丢弃。

优点:

  • 门数从 $O(n^2)$ 降到 $O(n \log n)$
  • 精度损失 $\leq 1/2^{k_{\max}}$(可控)

缺点:

  • 精度有限
  • 适用场景:早期测量 + 经典处理

应用: 现代 QPE 算法常用"近似 QFT" 来减小电路深度。

9.T.4 QFT 的"反 QFT" (Adjoint QFT)

思想: 直接构建 $\hat{F}^\dagger$ 的电路(而不是反向 QFT 电路)。

优点: 在某些硬件上可能稍微优化(避免中间测量)。

缺点: $\hat{F}^\dagger$ 的电路就是反向的 $\hat{F}$ 电路,没有本质区别。

9.S 补充:QFT 与经典信号处理的"对比视角"

信号处理任务 经典 (FFT) 量子 (QFT)
频谱分析 $\mathbf{y} = \hat{F}_N \mathbf{x}$ $\hat{F}_N \psi\rangle$
卷积 $f * g = \hat{F}^{-1}(\hat{F} f \cdot \hat{F} g)$ 需要"量子卷积"算法
滤波 $\hat{F}^{-1}(H \cdot \hat{F} \mathbf{x})$ 需要"量子滤波"算法
相关性 $f \star g = \hat{F}^{-1}(\overline{\hat{F} f} \cdot \hat{F} g)$ 需要"量子相关性"算法
模式识别 模板匹配 量子相位估计 + Grover 加速
压缩感知 $\ell_1$ 最小化 量子 $\ell_1$ 算法(研究阶段)

关键洞察: 经典信号处理的丰富操作(滤波、卷积、相关性等)在量子版本中都需要重新设计,没有简单的"量子化"。

现状: 量子信号处理(QSP)是一个活跃研究领域,目标是构建"量子版的 DSP"。

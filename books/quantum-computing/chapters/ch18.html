18.0 引言:从"小规模"到"工业级"QEC

一句话总结: ch17 的三个奠基码 (5-9 qubit) 适合"教学"和"原理证明", 但实用必须用表面码——2D 网格 + 局部 stabilizer + 高阈值, 是当前 IBM/Google/Amazon 等所有大厂的 QEC 路径。

核心问题:

  1. 规模天花板: Shor/Steane 编码 1 逻辑 qubit 用 7-9 物理, 想 $d = 7$ 就需要 $7^2 + (7-1)^2 = 85$ qubit (ch17 几何延伸)——码率 $k/n$ 越来越低
  2. 阈值严苛: $\sim 10^{-4}$ 阈值要求硬件错误率 $p < 10^{-4}$, 当前最好的超导 qubit $p \sim 10^{-3}$, 不满足

    4. 结论: 三个奠基码原理上可行, 工程上不能 scale——需要新码。

    18.0.2 表面码的"破局"思路

    Bravyi-Kitaev 1998 + Dennis-Kitaev-Landahl-Preskill (DKLP) 2002 给出三个破局点:

    1. 2D 网格: 数据 qubit 排在 2D 网格上, 物理上近邻——避免长程连接
    2. 局部 stabilizer: X/Z stabilizer 只跟4 个最近邻数据 qubit 作用——避免长程测量
    3. 高阈值: $p_{th} \approx 1\%$, 比 Shor/Steane 的 $10^{-4}$ 高两个数量级——容忍当前硬件

      4. 工业意义: 表面码是所有大厂的 QEC 路径——IBM 2021, Google 2023-2024, Amazon 2024, IonQ 2024 都在用。

      18.0.3.2 三个"规模扩展"的根本障碍

      从 ch17 到 ch18 之前, 三个根本障碍阻止 QEC 的规模扩展:

      障碍 1: 长程连接

      • Shor 9-qubit 编码需要非局部 CNOT 门 (e.g. qubit 1 控制 qubit 9)
      • 在物理硬件上, 长程门错误率比近邻门高 10-100 倍
      • 表面码只要求最近邻 4 体连接——避免长程

      障碍 2: 测量复杂度

      • Shor 测 8 个 stabilizer, 每个需多个 ancilla + 深度电路
      • 表面码所有 stabilizer 都是 4 体——电路深度常数, 与 $d$ 无关

      障碍 3: 码率衰减

      • Shor/Steane 码率 $k/n = 1/9$ 或 $1/7$
      • 想要 $d = 5$? Shor 几何延伸需要 $5^2 + (5-1)^2 = 41$ 物理 qubit (码率 1/41)
      • 表面码旋转版本: $d = 5$ → $25$ 物理 (码率 1/25, 比 Shor 几何延伸省 39%)

        18.1 拓扑学基础:为什么叫"表面"码

        核心问题: 表面码的"表面"是什么? 跟拓扑学有什么关系?

        18.1.1 拓扑不变量:洞、把手、亏格

      拓扑学研究"在连续形变下不变"的性质。

      概念含义量子计算角色
      同伦 (homotopy)"路径的等价类"任意子的世界线 (worldline)
      同调 (homology)"闭链/边界"syndrome 模式的空间分布
      亏格 (genus)"把手"的数量环面 (torus) 亏格 = 1, 球面亏格 = 0
      环面 (torus)亏格 1 的紧致曲面周期性边界 (早期表面码)

      关键观察: 表面码用平面 (亏格 0) 边界+ 开口边界 (open boundary) 编码——比环面更实用。

      18.1.2 同伦 (Homotopy): 任意子的"运动"

      任意子 (anyons) 是二维拓扑序的准粒子, 世界线 (worldline) 是 1D 曲线。

      同伦类: 两条世界线等价当且仅当可以连续形变相互转换 (不允许穿过其他任意子)。

      关键事实: 在二维空间里, 世界线可以互相绕 (braiding)——三维空间里不行 (因为绕过 + 穿过是等价的)。

      应用: 任意子的编织 (braiding) = 拓扑保护的量子门——错误率 $\sim e^{-L/\xi}$ (随距离指数下降)。

      18.1.3 同调 (Homology): syndrome 的几何

      同调类: 闭链 (cycle) 的等价类——两个闭链等价当且仅当差是某边界 (boundary)。

      表面码的 syndrome: 是一组比特串——可看作闭链。

      • $X$ 错误 (bit-flip) 的 syndrome = X-stabilizer 触发的链 (1-chain)
      • $Z$ 错误 (phase-flip) 的 syndrome = Z-stabilizer 触发的链 (1-chain)

      关键事实: syndrome = 0 当且仅当错误是纯边界 (boundary)——即"无错" (因为 $V$ 是辛子空间)。

      应用: 解码 (decoding) = 找最短闭链 解释 syndrome——这是最小权重完美匹配 (MWPM) 算法的数学背景。

      18.1.4 亏格 (Genus): "把手" 的数量

      环面 (torus) 亏格 = 1 (1 个"把手")。 球面 (sphere) 亏格 = 0 (无把手)。 双环面 (double torus) 亏格 = 2 (2 个把手)。

      欧拉示性数 (Euler characteristic): $\chi = 2 - 2g$ (亏格 $g$ 的紧致曲面)。

      应用: 表面码的"洞"的数量 = 逻辑 qubit 数 (1 个洞 = 1 个独立的世界线类)。

      18.1.5 任意子 (Anyons): 二维的礼物

      任意子 = 出现在二维拓扑序中的准粒子, 跟三维的玻色子/费米子不同。

      维度粒子交换统计
      3D玻色子$\psi \to \psi$ (不变)
      3D费米子$\psi \to -\psi$ (变号)
      2D任意子$\psi \to e^{i\theta} \psi$ (任意相位 $\theta$)

      关键: 2D 拓扑序中, 交换任意子产生复相位——是量子门的来源。

      18.1.6 编织 (Braiding): 拓扑保护

      编织 = 任意子在 2D 平面上互相环绕。

      关键定理: 编织产生的相位 $e^{i\theta}$ 只依赖于同伦类 (路径的拓扑等价类)——不依赖于具体路径细节。

      应用: 用任意子编织做量子门, 错误率 $\sim e^{-L/\xi}$, 其中 $L$ = 任意子距离, $\xi$ = 相关长度——指数小错误率, 是拓扑保护的核心。

      18.6 节会深入展开任意子和编织。

      18.2 平面码 vs 旋转码 vs 补丁码 (Bravyi-Kitaev 1998)

      核心问题: 表面码的"家族"有几种? 各自的资源开销如何?

      18.2.1 平面码 (Planar Code)

      Bravyi-Kitaev 1998 提出的最简版本:

      • 数据 qubit 排列在 $d \times d$ 2D 网格顶点 (vertices)
      • X-stabilizer 在星形 (star) 顶点 = 4 个最近邻数据 qubit 的 $X$ 积
      • Z-stabilizer 在面形 (plaquette) 中心 = 4 个最近邻数据 qubit的 $Z$ 积
      • 边界: 4 个开口边界 (粗糙 + 平滑), 2 对边界定义 1 个逻辑 qubit

      资源:

      • 数据 qubit: $n = d^2 + (d-1)^2$

      - 例: $d = 3$ → $9 + 4 = 13$ 数据 qubit - 例: $d = 5$ → $25 + 16 = 41$ 数据 qubit

      • 测量 qubit (ancilla): $d^2 - 1$ (X) + $d^2 - 1$ (Z) ≈ $2d^2$ 个
      • 总 (数据 + 测量): $\sim 3d^2$ qubit

        • 18.2.2 旋转码 (Rotated Code)

      Horsman 2012 提出旋转 45° + 压缩 边界, 资源更紧凑。

      关键思想: 旋转后 X/Z stabilizer 分布更密集——用更少的 qubit 实现同样 $d$。

      资源:

      • 数据 qubit: $n = d^2$
      • 测量 qubit: $\sim 2d^2 - 2d + 1$
      • 总: $\sim 2d^2$ qubit (比平面码省 33%)

      例: $d = 5$ → $25$ 数据 qubit (vs 平面码 41)

      当前工业实践: Google Willow 2024 用旋转码——$d = 5, 7$ 各 25/49 数据 qubit。

      18.2.3 补丁码 (Patch Code)

      Horsman 2012 + Fowler 2012 进一步任意形状的码——补丁 (patch)。

      关键思想: 把多个逻辑 qubit 编码在任意形状的 2D 表面上, 满足"X 边界 vs Z 边界"的特定分布。

      资源: 取决于具体形状——常用于多逻辑 qubit 的逻辑门实现。

      应用: 表面码的逻辑门 (CNOT, T 门) 通常用多补丁实现——补丁码是工程实践的常见形式。

      18.2.4 三种码的物理 qubit 数对比

      码型数据 qubit测量 qubit总$d=3$$d=5$$d=7$
      平面码$d^2 + (d-1)^2$$\sim 2d^2$$\sim 3d^2$174173
      旋转码$d^2$$\sim 2d^2 - 2d + 1$$\sim 2d^2$92549

      当前主流: 旋转码——Google, IBM, Amazon 都用旋转码。

      18.3 2D 网格 + X/Z Stabilizer 几何

      核心问题: 表面码的"棋盘" 几何长什么样? 数据 qubit 和 stabilizer 怎么分布?

      18.3.1 数据 qubit 在格点 (Vertices)

      最常见布局: 旋转码的 2D 网格:

      • 数据 qubit 位于 $d \times d$ 的格点 (vertices)
      • $d = 3$ 时: 9 个数据 qubit
      • $d = 5$ 时: 25 个数据 qubit
      • $d = 7$ 时: 49 个数据 qubit

      例 ($d = 3$) 9 个数据 qubit 编号 (行优先):

      q_0  q_1  q_2
q_3  q_4  q_5
q_6  q_7  q_8

      18.3.2 X-stabilizer (星形) + Z-stabilizer (面形) 交替

      棋盘分布: X 和 Z stabilizer 交替排布, 像国际象棋的"棋盘"——黑格/白格对应 X/Z。

      X-stabilizer (4 体):

      • 测 $X$ 在 4 个最近邻数据 qubit 上的积
      • 棋盘"白格"
      • 检测 Z 错误 (反 X 错误)

      Z-stabilizer (4 体):

      • 测 $Z$ 在 4 个最近邻数据 qubit 上的积
      • 棋盘"黑格"
      • 检测 X 错误 (反 Z 错误)

      关键性质: 每个数据 qubit 参与 2 个 X-stab + 2 个 Z-stab (4 个 stabilizer)——ch17.1.3 的"对偶"性质。

        • 18.3.4 距离 $d$ 的几何含义

      关键事实: 表面码的距离 $d$ = 物理上分离的两个同伦类任意子的最短路径长度。

      直观: 错误需要产生长度 $\ge d$ 的错误链 (error chain) 才能从粗糙边界绕到平滑边界 (变成逻辑错误)——长度 $< d$ 的链可检测+纠正。

      数学:

      • 物理错误率 $p$
      • 单错误 = 1 步
      • 长度 $d$ 链需要 $\ge d$ 错误, 概率 $\sim p^d$
      • 逻辑错误率 $p_L \sim p^d$ (短 $d$ 情形) → 实际更复杂, 见 18.5

      例: $d = 5$ 表面码, $p = 10^{-3}$ → $p_L \sim (10^{-3})^5 = 10^{-15}$ (太乐观, 实际有常数因子, 见 18.5)

      18.3.5 边界条件:粗糙 vs 平滑

      粗糙 (Rough) 边界:

      • 暴露数据 qubit 的 $X$ 边
      • 用作逻辑 $\bar{Z}$ 算子端点
      • 测 $\bar{Z}$ 时, 把 2 个粗糙边界的端点 $X$ 一起测

      平滑 (Smooth) 边界:

      • 暴露数据 qubit 的 $Z$ 边
      • 用作逻辑 $\bar{X}$ 算子端点

      两对边界 (rough + smooth) = 1 个逻辑 qubit。

      18.4 Syndrome 提取 + 解码 (Decoding)

      核心问题: 测 stabilizer → syndrome → 怎么反推错误?

      18.4.1 Syndrome 提取电路

      流程:

      1. 4 个 CNOT: 数据 qubit → ancilla (X-stab 时用 CNOT, Z-stab 时用 CZ)
      2. 测 ancilla → syndrome bit (0 = 无错, 1 = 有错)

        3. 总开销: $d^2$ 个 X-stab + $d^2$ 个 Z-stab = $2d^2$ 个 ancilla + $2 \times 2d^2$ 个 CNOT 门

        频率: 周期性 (每 $\sim 1 \mu s$)——比错误时间常数 (典型 $\sim 100 \mu s$) 快 100 倍

        18.4.2 解码:从 Syndrome 反推错误

        问题: 已知 syndrome, 找最可能的错误 $E$——是 NP-hard 问题的一般形式。

        约束: 错误稀疏 (typical $p \ll 1$ per step) + syndrome 来自 stabilizer 测量。

        3 种算法:

        18.4.2.1 最小权重完美匹配 (MWPM)

        经典算法 (Edmonds 1965), 1980s 引入 QEC。

        思路: 把 syndrome 看作图顶点, 错误看作图边——找连接所有 syndrome 点的最小权重完美匹配。

        时间复杂度: $O(n^3)$ (经典)

        精度: 最优 (找最小权重)

        实际: Google, IBM 都在用——经典计算硬件即可, 实时性满足 (1 μs 内).

        18.4.2.2 Union-Find 解码

        近似算法 (Delfosse 2017)。

        思路: 用并查集 (Union-Find) 数据结构, 增量地合并 syndrome 簇——线性时间 $O(n \alpha(n))$。

        精度: 接近 MWPM, 稍差 ($\sim 10-20\%$ 错误率高)

        优势: 极快, 适合硬件实时解码 (FPGA 实现)。

        18.4.2.3 神经网络解码

        新方向 (2018+):

        • Torlai 2018: RNN 解码器, 深度学习反推错误
        • Varsamopoulos 2019: CNN 解码
        • 优势: 可学习 + 可结合特定硬件特征
        • 劣势: 训练数据需求 + 黑盒难验证

        当前: 仍在研究, 工业实践未广泛采用。

        18.4.3 实时性要求

        硬约束: syndrome → 错误反推 → 纠正门 必须 在下一个错误发生前完成。

        时间尺度:

        • 物理错误间隔 $\sim 100 \mu s$ (典型 $T_1, T_2$)
        • syndrome 测量周期 $\sim 1 \mu s$
        • 预算: 必须在 1 $\mu s$ 内完成完整一轮

        架构选择: 经典 CPU/GPU/FPGA 实现解码, 不用量子硬件。

        未来: 同位 (collocated) 经典控制器, 直接在量子芯片附近——减少延迟。

        18.4.4 解码失败模式

        主要失败:

        1. 纠正错误: 假设单错, 实际多个 (2 个错误) 错对 — 罕见 ($p^2$)
        2. 逻辑错误: 错误太长 超过 $d$ 步 — 概率 $\sim p^d$
        3. 测量错误: syndrome 本身错 — 经典测量错率 $\sim 10^{-2}$ 是瓶颈

          4. 关键事实: syndrome 测量也会错——通常重复 测量 (e.g. $d$ 次) 来降低 syndrome 错误率到 $\sim p^d$——代价是 $d$ 倍测量时间。

          18.4.5 工程上的解码挑战

          实时性 = 真正的瓶颈:

          • 表面码 decoder 不能延迟——下一个错误马上来
          • 经典 CPU ($O(n^3)$) 对 $n = 10000$ qubit 太慢 (毫秒级)
          • 必须用并行硬件: GPU, FPGA, ASIC

          Google 的方案 (Acharya 2024):

          • 专用 FPGA 板 (e.g. Xilinx VU9P)
          • 1 μs 内完成 MWPM 解码
          • 直接在量子芯片附近 (低温)
          • 避免经典-量子通信延迟

          未来:

          • ASIC 解码器 (10× 快)
          • 量子 解码 (用量子算法, 理论)
          • 模拟 神经形态 (Intel Loihi 实验)

            • 18.5 阈值定理

            核心问题: 表面码为什么"工业级"? 阈值定理说了什么?

            18.5.1 阈值定理陈述

          阈值定理 (Aharonov-Ben-Or 1997, Knill-Laflamme-Kitaev-Preskill 1998, DKLP 2002):

          对任意 stabilizer 码, 存在阈值 $p_{th} > 0$ 使得:

          当 物理错误率 $p < p_{th}$ 时, 只要 距离 $d$ 足够大, 逻辑错误率 $p_L$ 任意小:

          $$p_L \sim C \cdot \left(\frac{p}{p_{th}}\right)^{(d+1)/2}$$

          关键: $p < p_{th}$ 是充分条件——只要满足, 错误指数下降。

          直觉: 错误需要形成长度 $\ge (d+1)/2$ 的链 才能造成未纠正的逻辑错——概率 $\sim p^{(d+1)/2}$。

          18.5.2 表面码阈值: $p_{th} \approx 1\%$

          DKLP 2002 给出表面码阈值的最优估计:

          • 独立去极化 (depolarizing) 错误: $p_{th} \approx 0.75\%$ (最严苛)
          • 实际非均匀错误 (T1, T2, 测量错): $p_{th} \approx 1-2\%$
          • 当前最好的超导 qubit: $p \sim 0.1-1\%$ (跨阈值)

          关键事实: 表面码阈值比 Shor/Steane/5-qubit 的 $10^{-4}$ 高两个数量级——实用!

          阈值 $1\%$ 的物理来源 — 表面码为什么"特别宽容"?

          1. 局部 4 体 stabilizer + 棋盘分布的"几何": 单错只影响 4 个 stabilizer (2 个 X-stab + 2 个 Z-stab), syndrome 模式唯一——可精确定位。
          2. 错误是"空间"传播的,不是"时间": 增加电路深度 (更多层 stabilizer 测量) 不会显著降低阈值——错误是横向扩散,不累积。
          3. 任意子"超选择"保护: 错误 → 任意子对 ($e$ 和 $m$) → 任何操作必须整体移动→ 自然抑制。
          4. 2D 局部连接: 每个 qubit 只与最近邻耦合——硬件易实现, 串扰 (crosstalk) 局限于局部。

          对比: Shor 9-qubit 阈值 $\sim 10^{-4}$ 小 100 倍——9 qubit 空间小, 单错可能多个 stabilizer 触发, syndrome 模式重叠, 解码歧义大, 阈值低 2 个量级。

          直觉总结: 表面码的"宽容"= 大码距 + 棋盘分布 + 局部连接 + 几何错抑制 的综合——这是它成为工业实践首选的根本原因。

          18.5.4 阈值定理的"代价"

          指数下降 $p_L \sim p^{(d+1)/2}$ 听起来很棒, 但代价是:

          • $p_L = 10^{-15}$ 需 $d \approx 10$ (条件: $p = 10^{-3}$)
          • $d = 10$ 表面码 = 100 数据 qubit + 200 ancilla = 300 qubit 编码 1 逻辑 qubit
          • 1 logical qubit ≈ 300-1000 物理 qubit (含测量)

          Shor RSA-2048 估算 (ch19 详细):

          • 约需 4000 逻辑 qubit × 3000 物理/逻辑 ≈ 20 百万 物理 qubit
          • 当前最大量子硬件: $\sim 1000$ qubit (IBM Condor 2023, 但无纠错)
          • 距离: 3-4 个数量级——20-30 年工程努力

          18.5.6 子阈值 vs 阈值之上: 关键工程边界

          子阈值 ($p < p_{th}$): 错误指数下降——加距离有收益。

          阈值之上 ($p > p_{th}$): 错误不降反升——加距离反而更糟 (因为更多 qubit = 更多错误)。

          工程意义:

          • 阈值是真正的分水岭
          • Google Willow 2024 跨阈值是里程碑——证明 QEC 实用
          • 当前 IBM Heron 还在阈值附近 ($\sim 0.1\%$)——再降 10× 才安全

          具体数字 (Google Willow 2024):

          • 物理错误率 $p \approx 0.143\%$
          • 阈值 $p_{th} \approx 1\%$
          • 比例 $p / p_{th} \approx 0.14$
          • $(d+1)/2 = 4$ (for $d = 7$)
          • $p_L \sim 0.14^4 \times C \approx 0.0004 \times C$, $C \sim 0.1$ → $p_L \approx 4 \times 10^{-5}$
          • 实验测得: $p_L \approx 0.143\% / 2.4 \approx 0.06\%$ (对 $d = 7$)

          观察: 实验比理论稍好——因为额外 的技术 (如 magic state 等) 在 $d = 5$ 还没起作用。

          18.6 任意子与拓扑保护

          核心问题: 任意子到底是什么? 怎么用任意子做量子计算?

          18.6.1 Abelian 任意子

          交换统计: $\psi \to e^{i\theta} \psi$, $\theta$ = 任意相位。

          最简单的 Abelian 任意子: toric code 的 $e$ (电荷) + $m$ (磁荷) + $\varepsilon = e \times m$ (费米子).

          性质:

          • $e$ 跟 $m$ 反对易
          • $\varepsilon$ 跟 $e$ 反, 跟 $m$ 反 → 费米子行为
          • 3 种基本任意子 (真空 1 + e + m + ε = 4 种, 但 $e \times \varepsilon = m$ 等关系)

          编织:

          • $e$ 绕 $m$ 一周: 相位 $\theta = \pi$ (半交换, 类似费米子)
          • $e$ 绕 $e$: $\theta = 0$ (玻色子)
          • $m$ 绕 $m$: $\theta = 0$

          问题: Abelian 编织只给出对角门 (相位门)——不能通用计算。

          18.6.2 非 Abelian 任意子

          关键: 交换非 Abelian 任意子改变 Hilbert 空间基——非平凡矩阵作用。

          例 1: Ising 任意子

          • 编织产生 Clifford 群 门 (H, S, CNOT 等)
          • 不包括 T 门——不通用
          • 物理实现: Majorana 零模 (ch23 详述)
          • 微软 Majorana 1 (2025) 用 Ising 任意子

          例 2: Fibonacci 任意子

          • 编织产生通用量子门——理论上最优
          • 只有 2 种任意子: $1$ (真空) + $\tau$ (Fibonacci)
          • $\tau \times \tau = 1 + \tau$ (fusion rule)
          • 物理实现: 候选系统包括分数量子霍尔 ($\nu = 12/5$ Moore-Read 态)——尚未实验确认

          对比:

          任意子类型通用?实验?物理实现
          Abelian (toric code)❌ (只相位门)✅ (超导)toric code 工程
          Ising❌ (只 Clifford)✅ (Majorana 1 2025)半导体纳米线
          Fibonacci✅ (通用)❌ (无)候选: FQH

          18.6.3 编织 = 量子门

          关键洞察: 任意子编织是拓扑保护的——错误率 $\sim e^{-L/\xi}$ (指数小)。

          数学: 编织 = braid group $B_n$ 作用在 Hilbert 空间——每个编织对应一个酉矩阵。

          例 (Ising):

          • 交换 2 个 Ising 任意子: $R$ 矩阵 (相位 $\pi/4$)
          • 多次编织 = Clifford 门
          • 缺点: 不通用

          例 (Fibonacci):

          • 编织 1 步 = $F$ 矩阵
          • $F$ 矩阵 + 单 qubit 相位 = 通用门集
          • 缺点: 实验未确认

              • 距离: 4-5 个数量级 (×10000)

              工程现实: 30 年内可能实现——需要 (1) 错误率 $p$ 继续降 10×, (2) qubit 数增 10000×, (3) 经典控制器 1 μs 解码。

              18.8.6 表面码实验的"三件难" (Three Hard Things)

              实现表面码 3 个最难的工程问题:

              1. 实时解码 (Real-time decoding)

              • 1 μs 内完成 syndrome → 错误反推 → 纠正门
              • 经典硬件 (FPGA/GPU) 必须紧贴量子芯片
              • Google 用专用 FPGA 板 (Syu 2024)

              2. 测量保真度 (Measurement fidelity)

              • 表面码假设完美 syndrome 测量
              • 实际测量错误率 $\sim 1\%$
              • 必须重复 测量 $d$ 次 → 测量时间 × $d$
              • 新的困难: 测量错误本身是 syndrome 错误

              3. 长程连接 (Long-range connectivity)

              • 表面码理想是 2D 平面 (近邻)
              • 实际超导芯片3D 封装, 长程门难
              • 解决方案: 移动 qubit (lattice surgery, ch19 详述)

              • 测量保真度: 99.85% 在 $d=5$ 时可接受 (测量错误不主导), 但 $d \to 11$ 时成为瓶颈
              • 长程门: 仍是最大挑战, lattice surgery 仍未完全实用化
              • qubit 数: 增 100× 是最大鸿沟——制造工艺+控制电子+制冷机全需升级

              18.9 拓扑量子计算

              核心问题: 拓扑量子计算跟表面码纠错什么关系? 是不是"竞争"?

              18.9.1 两种容错路径

              路径保护机制通用?实用?
              表面码纠错 (ch18)主动 + 高阈值✅ (通用门)✅ (Willow 2024)
              拓扑保护 (ch23)被动 + 编织✅ (Fibonacci)❌ (实验阶段)

              关键事实: 两种 路径互不冲突——可组合 (Hybrid)。

              例: 用表面码保护逻辑 qubit, 内部用 Fibonacci 编织做逻辑门——理论最优。

              18.9.2 Majorana 零模 + Ising 任意子

              Majorana 零模 (Majorana zero mode, MZM):

              • 半导体纳米线 + 超导邻近效应
              • 2008 Fu-Kane 理论, 2012+ 实验
              • 微软 Majorana 1 (2025) 声称 8 拓扑 qubit

              Ising 任意子:

              • MZM 的非局域态
              • 编织 = Clifford 门 (H, S, CNOT)
              • 不通用——需 magic state 补 T 门

              争议: MZM 的实验证据仍有质疑 (零偏压电导 0.5 $2e^2/h$ 是否真正 MZM, 还是其他效应)。

              18.9.3 微软 Majorana 1 (2025)

              Microsoft 2025-02 公布:

              • Majorana 1 芯片: 8 拓扑 qubit
              • 拓扑保护 (声称) ——不用表面码纠错
              • 走"Topological qubit"路径

              质疑 (学界, 2024-2025):

              • 多个实验组重复 Majorana 实验失败
              • 学界共识 (2025): Majorana 零模的明确证据尚缺
              • 微软承认需要更多实验

              ch23 详细展开 Majorana 实验细节 + 当前争议。

              18.9.4 Fibonacci 任意子 (候选)

              候选系统:

              • 分数量子霍尔 $\nu = 12/5$ (Moore-Read 态) — Willett 2013 暗示性实验
              • 冷原子 (光晶格 + Rydberg 原子) — 理论提议
              • 拓扑超导 (Kitaev 链 + Fibonacci 编码) — 理论

              实验状态 (2026): 无确定 Fibonacci 任意子实验。

              意义: 理论上最优雅的容错方案——编织做通用门, 错误率指数小。

              18.9.5 拓扑量子计算 vs 表面码纠错

              争论焦点:

              • 乐观派 (Microsoft): 拓扑最终胜过表面码——被动保护更优雅
              • 工程派 (Google, IBM): 表面码现在实用——主动纠错 + 高阈值

              共识 (2026):

              • 表面码是近期 QEC 主流 (10 年)
              • 拓扑是远期 路径 (20-30 年)
              • 可能组合: 表面码 (FTQC) + 拓扑 (量子门)

              18.10.3 3 个关键洞察

              1. 从原理到工业的转折: ch17 三个奠基码是原理 (5-9 qubit, $d=3$); ch18 表面码是工业 (25-10000+ qubit, $d=5-30$)。这一转折的核心是阈值从 $10^{-4}$ 到 $10^{-2}$——两个数量级的进步。

                18.B.1 任意子的数学描述

                Braid group $B_n$ (n 个粒子的所有编织): 由生成元 $\sigma_1, \dots, \sigma_{n-1}$ 生成, 关系:

                i - j
                • $\sigma_i \sigma_{i+1} \sigma_i = \sigma_{i+1} \sigma_i \sigma_{i+1}$ (Yang-Baxter)

                酉表示: $B_n$ 的 $d$-维酉表示给 $d$-维 Hilbert 空间 + 编织 = 量子门。

                18.B.2 Fusion rules

                Fusion: 2 个任意子合并成 1 个——是直和 (Abelian) 或多结果 (非 Abelian)。

                Abelian: $a \times b = c$ (单结果) Non-Abelian: $a \times b = \bigoplus_i c_i$ (多结果, Hilbert 空间维数增加)

                例 (Fibonacci): $\tau \times \tau = 1 + \tau$ (2 结果) 例 (Ising): $\sigma \times \sigma = 1 + \psi$ (2 结果, 但只 Clifford)

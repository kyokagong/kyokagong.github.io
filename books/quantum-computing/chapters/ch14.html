14.1 量子机器学习的三种范式

14.1.1 范式分类

QML 的三种范式(Biamonte 2017, 经典分类):

范式数据处理量子优势潜力现状
CC(Classical-Classical)经典经典不直接(QAE/Grover 加速)已有量子加速算法
CQ(Classical-Quantum)经典量子中等(量子特征映射)实验探索
QQ(Quantum-Quantum)量子量子高(天然)起步

详细解释:

14.1.2 CC 范式:经典数据 + 经典处理 + 量子加速

定义: 数据是经典的, 处理也是经典的, 但用量子子程序加速其中部分计算。

代表算法:

  • <
strong>HHL 加速 SVM: HHL 求解线性方程组 → SVM 的核心是矩阵求逆 → 指数加速(条件数小)
  • <
strong>Grover 加速 K-means: K-means 的中心搜索 → Grover 加速 → 二次加速
  • <
strong>QAE 加速蒙特卡洛: 量子幅度估计 → 蒙特卡洛积分 → 二次加速

量子优势条件: 子程序确实是经典瓶颈。

局限: 大多数经典 ML 算法的"瓶颈"是 I/O 或优化, 不是矩阵求逆。

14.1.3 CQ 范式:经典数据 + 量子处理

定义: 数据是经典的(图像/文本/表格), 用量子电路处理。

代表算法:

  • <
strong>量子核 SVM(QSVM)
  • <
strong>量子神经网络(QNN)
  • <
strong>变分量子分类器(VQC)

流程:

  1. <
strong>数据加载: 经典数据 $x$ → 量子态 $|\phi(x)\rangle$(数据编码)
  • <
strong>量子处理: 参数化电路 $U(\theta)$ → 量子态 $U(\theta)|\phi(x)\rangle$
  • <
strong>测量: 期望值 $\langle O \rangle$ → 经典输出
  • <
strong>经典后处理: 分类 / 回归

量子优势条件:

  • 量
子特征映射 $\phi(x) \mapsto |\phi(x)\rangle$ 经典难以模拟
  • 量
子电路浅 + 硬件兼容

局限: 数据加载成本可能超过加速(见 14.2 节 QRAM 困境)。

14.1.4 QQ 范式:量子数据 + 量子处理

定义: 数据是量子态(实验测量), 用量子电路处理。

代表场景:

  • <
strong>量子化学: 分子 Hamilton 的本征态
  • <
strong>量子传感: 量子传感器的输出态
  • <
strong>量子模拟: 多体系统的态

量子优势条件: 天然 —— 量子电路就是处理量子态的"原生"工具。

现状: 最具潜力的范式, 但最不成熟(量子数据生成困难)。

14.1.5 三种范式的实用现状(2026)

范式学术实验工业量子优势证明
CC成熟有探索中部分(二次加速)
CQ活跃大量早期极少(理论上)
QQ起步极少极早概念性

本章重点: CQ 范式 —— 量子 SVM / QNN / VQC(最热门, 也是最具争议)。

14.2 数据编码(Quantum Data Encoding)

14.2.1 为什么数据编码重要?

经典数据是 $x \in \mathbb{R}^d$ 或 $\mathbb{C}^d$, 量子态是 $|\psi\rangle \in \mathbb{C}^{2^n}$。如何把 $x$ 装进 $|\psi\rangle$?

这是 CQ 范式的第一关 —— 数据加载成本** 决定量子优势的"净加速"。

14.2.2 三种基本编码方式

编码公式信息容量电路深度适用
基编码$\|x\rangle = \|x_1 x_2 \cdots x_n\rangle, x_i \in \{0, 1\}$$n$ 比特 → $n$ qubit$O(1)$二进制数据
振幅编码$\|\psi\rangle = \frac{1}{\|x\|}\sum_{i=1}^{2^n} x_i \|i\rangle$$2^n$ 维 → $n$ qubit$O(n)$稠密向量
角度编码$R_x(x_i)\|0\rangle$1 标量 → 1 qubit$O(1)$单变量

14.2.3 基编码(Basis Encoding)

最简单: 把 $n$ 位二进制串 $x \in \{0, 1\}^n$ 直接映射到 $|x\rangle$。

例子: $x = (1, 0, 1, 1) \to |1011\rangle$

电路: $X$ 门(在 1 比特位置)

优势:

  • <
strong>简单: $O(n)$ X 门
  • <
strong>快速: 单次电路运行即可

劣势:

  • <
strong>二进制: 不能表示连续值
  • <
strong>浪费: $n$ qubit 只编码 $n$ 比特(信息密度低)

14.2.4 振幅编码(Amplitude Encoding)

最"量子": 把 $d$ 维向量 $x$ 编码成 $n = \log_2 d$ qubit 的振幅。

$$|\psi(x)\rangle = \frac{1}{\|x\|}\sum_{i=1}^{2^n} x_i |i\rangle$$

信息密度: $n$ qubit 编码 $2^n$ 个复数(指数信息密度!)

优势:

  • <
strong>指数信息密度: $n$ qubit 编码 $2^n$ 维向量
  • <
strong>天然量子: 利用 Hilbert 空间的指数维数

劣势:

  • <
strong>电路深度: $O(n)$ 的状态制备(要构造任意态)
  • <
strong>状态制备复杂: 通用算法需要 $O(2^n)$ 操作

关键问题: 怎么高效制备? —— QRAM 假设

14.2.5 角度编码(Angle Encoding)

最务实: 把每个标量 $x_i$ 编码成 qubit 的旋转角。

$$|\phi(x)\rangle = \bigotimes_{i=1}^{n} R_x(x_i) |0\rangle = \bigotimes_{i=1}^{n} (\cos(x_i/2)|0\rangle + \sin(x_i/2)|1\rangle)$$

信息密度: $n$ qubit 编码 $n$ 标量(线性)

优势:

  • <
strong>简单: $O(n)$ 单 qubit 门
  • <
strong>快速: 一次电路运行即可
  • <
strong>实用: 硬件兼容

劣势:

  • <
strong>信息密度低: 跟经典一样(没有量子优势)
  • <
strong>不利用纠缠: 简单直积态

14.2.6 QRAM 困境

关键问题: 经典数据 $x$ 如何进入量子电路?

QRAM(Quantum Random Access Memory): 经典地址 $i$ → 量子态 $|i\rangle$ → 量子数据 $x_i$。

理论: QRAM 在 $O(\log N)$ 时间内返回 $x_i$($N$ 是数据大小)。

现实:

  • <
strong>没有实用的 QRAM 硬件(2026 年)
  • <
strong>经典 I/O 限制: 把 $N$ 维向量装入 $n = \log N$ qubit 需要 $O(N)$ 时间
  • <
strong>"Quantum RAM 假设"是 QML 最大的隐含假设

对 QML 的影响:

  • 如
果 QRAM 不存在, 数据加载就是 $O(N)$(经典!)
  • 即
使量子电路 $O(\text{poly}(n))$, 总代价仍然是 $O(N)$ —— 没有量子优势
  • 这
是 QML 没有明确量子优势 的主要原因之一

总结:

  • <
strong>角度编码: 实用(无 QRAM 假设), 但信息密度低
  • <
strong>振幅编码: 信息密度高, 但需要 QRAM
  • <
strong>QML 现状: 大多数实验用角度编码(务实)

14.3 量子核方法(Quantum Kernel Methods)

14.3.1 经典核方法回顾

核方法(SVM, GP, etc.) 的核心: 找一个函数 $K(x, x')$ 衡量两个数据点的"相似度"。

经典 RBF 核:

$$K(x, x') = e^{-\gamma \|x - x'\|^2}$$

几何直觉: 把 $x$ 映射到高维空间 $\phi(x)$, 在高维空间找超平面。核函数等价于内积: $K(x, x') = \langle \phi(x), \phi(x') \rangle$。

量子核的自然推广:

$$K_Q(x, x') = |\langle \phi(x) | \phi(x') \rangle|^2$$

其中 $|\phi(x)\rangle$ 是量子特征映射(把 $x$ 编码成量子态)。

14.3.2 量子特征映射

定义: $\phi: \mathcal{X} \to \mathcal{H}$(经典数据 → 量子态)

简单例子(角度编码):

$$|\phi(x)\rangle = \bigotimes_{i=1}^{n} R_x(x_i) |0\rangle$$

复杂例子(纠缠编码):

$$|\phi(x)\rangle = U_{\text{enc}}(x) |0\rangle^{\otimes n}$$

其中 $U_{\text{enc}}(x)$ 是含参的编码电路。

量子核 = 编码态的内积(模方):

$$K_Q(x, x') = |\langle \phi(x) | \phi(x') \rangle|^2 = |\langle 0 | U_{\text{enc}}(x)^\dagger U_{\text{enc}}(x') | 0 \rangle|^2$$

14.3.3 量子核的计算: 交换测试

问题: 给定 $|\phi(x)\rangle$ 和 $|\phi(x')\rangle$, 如何算 $|\langle \phi(x) | \phi(x')\rangle|^2$?

答案: 交换测试(Swap Test)!

`

量子电路:

┌──────────────────┐

│ ancilla ──H────●────────H─measure──→ |+⟩ 或 |-⟩

│ │

│ reg(x) ───────SWAP───────────────── |\phi(x)⟩

│ reg(x') ────────●────────────────── |\phi(x')⟩

└──────────────────┘

`

P(ancilla = 0) $= \frac{1 + |\langle \phi(x) | \phi(x')\rangle|^2}{2}$

所以: $|\langle \phi(x) | \phi(x')\rangle|^2 = 2 P(0) - 1$

代价: $O(1)$ 量子电路 + $O(1/\epsilon^2)$ 测量。

14.3.4 量子支持向量机(QSVM)

流程:

  1. <
strong>数据编码: 经典 $x_i$ → 量子态 $|\phi(x_i)\rangle$
  • <
strong>核矩阵计算: 用交换测试算 $K_Q(x_i, x_j)$ 对所有 $i, j$(经典)
  • <
strong>经典 SVM: 用量子核训练经典 SVM

复杂度:

  • 训
练: $O(N^2 \cdot 1/\epsilon^2)$(量子核)
  • 经
典 SVM: $O(N^3)$(二次规划)

量子优势条件:

  • 量
子核 $K_Q$ 经典难以计算
  • 量
子特征映射 $|\phi(x)\rangle$ 经典难以模拟

14.3.5 量子优势的边界

关键问题: 量子核真的比经典好吗?

答案: 取决于特征映射。

特征映射经典模拟量子优势
角度编码(单 qubit 旋转)容易❌ 无
浅层纠缠编码困难(但理论上可能)⚠️ 争议
深层纠缠编码极困难✅ 潜在

理论结果:

  • <
strong>Liu 2021: 量子核在某些数据上不比经典核好
  • <
strong>Huang 2021: 量子电路的特征映射在某些数据集可被经典模拟
  • <
strong>结论: 量子核的"量子优势"是条件性的, 不是普遍性的

现实:

  • 截
至 2026 年, 没有明确的量子核实验展示量子优势
  • 大
多数实验是"小型演示"(MNIST 二分类)
  • <
strong>量子核是 QML 中"最具争议"的部分

具体分析:为什么量子核"可能"有优势:

经典核方法有一个根本限制:特征映射 $\phi: x \mapsto \phi(x)$ 必须预先固定(如 RBF, 多项式核)。

量子核打破这个限制:

  • 量
子态 $|\phi(x)\rangle$ 是 $2^n$ 维 Hilbert 空间的向量
  • 这
个空间比经典 RBF 映射的空间指数大
  • 理
论上, 任何经典核都可以被量子核"包含"(在某些参数化下)

但:

  • <
strong>量子核的"指数大"空间 大部分是空的(没有结构化数据)
  • <
strong>没有免费午餐: 量子核的优势只在数据有特定结构时体现
  • 经
典 RBF + 足够数据往往够用

几何直觉:

`

经典核:

数据 → φ(x) ∈ ℝ^d (固定 d)

量子核:

数据 → |φ(x)⟩ ∈ ℂ^(2^n) (n qubit, 指数 d)

↓

经典核: d = O(几百) (受计算限制)

量子核: d = 2^n = O(∞) (理论上)

↓

如果数据真的有 2^n 维结构, 量子核可以找到它

如果数据没有这种结构, 量子核没有优势

`

量子核可能"赢"的场景:

  1. <
strong>物理数据: 来自量子系统的实验数据(天然 2^n 维结构)
  • <
strong>高维稀疏数据: 基因 / 蛋白质 / 网络(指数维数但稀疏)
  • <
strong>带量子结构的数据: 化学分子图 / 量子多体态

量子核"输"的场景:

  1. <
strong>图像数据: 经典 CNN 已经很好, 量子核无明显优势
  • <
strong>低维结构化数据: MNIST / CIFAR-10, 经典 SVM/RF 足够
  • <
strong>时序数据: 经典 LSTM/Transformer 主导

结论:

  • 量
子核不是"ML 的圣杯"
  • 量
子核可能对特定数据集有优势
  • <
strong>关键问题: 找到量子核能赢的数据集(目前没有)
  • <
strong>这是 QML 最具争议的开放问题

14.4 变分量子分类器(VQC)

14.4.1 跟 ch13 VQE 的同构

VQC 是 ch13 VQE 的"分类版":

维度VQE(ch13)VQC(本章)
目标$\min_\theta \langle H \rangle$(基态能量)$\min_\theta L(\hat{y}, y)$(分类损失)
ansatz$U(\theta)$$U(\theta)$(完全相同!)
测量$\langle H \rangle$$\langle O \rangle$(分类可观测量)
优化经典经典(完全相同!)

唯一区别: 把"Hamilton 期望"换成"分类损失"。

14.4.2 VQC 流程

`

┌──────────────────────────────────────────────────────┐

│ VQC 流程: │

│ │

│ 1. 编码: |0⟩^n ──U_enc(x)──→ |φ(x)⟩ │

│ 2. 处理: |φ(x)⟩ ──U(θ)──────→ U(θ)|φ(x)⟩ │

│ 3. 测量: U(θ)|φ(x)⟩ ──M(O)──→ ⟨O⟩ ∈ ℝ │

│ 4. 后处理: ⟨O⟩ ──σ(·)──→ ŷ(预测) │

│ 5. 损失: L(ŷ, y) │

│ 6. 优化: θ ← θ - α∇L (经典反向传播) │

└──────────────────────────────────────────────────────┘

`

前向: 量子电路 → 经典损失

反向: parameter-shift rule → 经典梯度

14.4.3 二分类例子

目标: 区分两类 $y \in \{+1, -1\}$。

可观测量: $O = Z$(单 qubit)

预测:

$$\hat{y} = \text{sign}(\langle \phi(x) | U(\theta)^\dagger Z U(\theta) | \phi(x) \rangle)$$

损失: Hinge loss $L = \max(0, 1 - y \cdot \langle Z \rangle)$

14.5 量子梯度下降与训练

14.5.1 Parameter-Shift Rule(回顾 ch13)

量子梯度计算不需要数值微分!

$$\frac{\partial \langle O \rangle_\theta}{\partial \theta} = \frac{\langle O \rangle_{\theta + s/2} - \langle O \rangle_{\theta - s/2}}{\sin(s)}$$

其中 $s = \pi/2$ 是移位参数(对单 qubit 旋转)。

代价: 2 次量子电路运行(而不是 1 次)。

优势: 精确梯度(不是数值近似), 跟经典反向传播类比。

14.5.2 量子随机梯度下降(QSGD)

SGD 在 QML 的类比:

  1. 取
小批数据 $\mathcal{B} \subset \mathcal{D}$
  • 计
算梯度 $\nabla_\theta L(\mathcal{B}; \theta)$(用 parameter-shift)
  • 更
新 $\theta \leftarrow \theta - \alpha \nabla L$

量子梯度:

$$\frac{\partial L}{\partial \theta_k} = \frac{1}{|\mathcal{B}|}\sum_{x \in \mathcal{B}} \frac{\langle O \rangle_{\theta_k + s/2}(x) - \langle O \rangle_{\theta_k - s/2}(x)}{\sin(s)}$$

代价: 每个梯度方向需要 2 次电路运行 → $2D$ 次($D$ = 参数维度)。

14.5.3 自然梯度(Quantum Natural Gradient)

问题: 经典 SGD 忽略参数空间的几何。

自然梯度: 用量子 Fisher 信息矩阵(QFIM) 修正梯度方向。

QNG 更新:

$$\theta \leftarrow \theta - \alpha \cdot F^{-1} \nabla_\theta L$$

其中 $F_{ij} = \text{Re}(\langle \partial_i \psi | \partial_j \psi \rangle - \langle \partial_i \psi | \psi \rangle \langle \psi | \partial_j \psi \rangle)$。

优势: 收敛更快(尤其在 barren plateau 附近)。

代价: 计算 QFIM 需要 $O(D^2)$ 电路运行(昂贵)。

14.5.4 Barren Plateau 跟 QML 的关系

ch13 的结论完全适用:

  • 深
度 ansatz + 大系统 → 梯度 $\sim 2^{-n}$
  • Q

  • <
strong>解决: 浅电路 + 结构化 ansatz + 局部测量(见 13.6)

QML 特有问题:

  • 数
据维度 $d$ 增大 → qubit 数 $n$ 增大 → 更容易 barren plateau
  • <
strong>QML 的"数据扩展性"差于经典 ML

14.11.3 三层洞察

第一层(技术): QML 在 NISQ 时代已经跑通 —— QSVM, QNN, qGAN 都有实验。但没有明确的量子优势。

第二层(应用): QML 的最大瓶颈是数据加载(QRAM 假设) —— 量子优势被抵消。

第三层(战略): QML 是"未来可能改变 AI"的方向, 但不是 NISQ 时代的实用方案。真正的优势需要 QRAM 或容错量子计算。

14.X.4 QML 失败的常见原因

1. 数据加载瓶颈: QRAM 不存在 → 数据装入量子态慢

2. Barren plateau: 深度 ansatz + 大数据 → 梯度消失

3. 浅电路限制: NISQ 噪声 → 表达力受限

4. 优化器不好: 局部极小, 收敛慢

5. 没有量子优势: 经典 ML 也能做

应对:

  1. 角
度编码(避免 QRAM)
  • 浅
ansatz + 结构化(避免 barren plateau)
  • 错
误缓解(增加有效深度)
  • 经
典预训练(给出好初值)
  • <
strong>接受现实: QML 在某些任务不会超经典

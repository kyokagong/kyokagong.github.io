23.1 拓扑学与量子信息的桥梁

23.1.1 拓扑不变量的概念——甜甜圈 ≡ 咖啡杯

拓扑学 (topology) 研究的是连续形变下保持不变的性质。最经典的例子:

一个甜甜圈 ☕ 和一个咖啡杯——表面看不同, 但拓扑等价: 它们都有 1 个洞 (handle / 亏格 genus = 1)。你可以连续地把一个变形成另一个, 只要不撕裂或粘合。

核心概念:

- 亏格 (genus) $g$: 表面洞的数量。球面 $g=0$, 甜甜圈 $g=1$, 双洞 $g=2$。

- 同伦群 (homotopy group) $\pi_n$: 描述"在表面上画圈有多少种本质不同的方式"——这个抽象数学概念直接对应到"任意子的种类"。

23.1.2 拓扑保护——为什么"局部噪声不能翻转"

物理类比: 一只手表扔到泥里, 只要不深过一定深度 (1 厘米), 还在走。

为什么? 经典手表有能隙——指针必须积累足够能量才能"转一格"。"局部"泥水扰动不够能量。

量子对应:

- 经典超导有超导能隙 $\Delta$ ~ meV: 局部热涨落 < $\Delta$, 不能破坏库珀对 → 超流持续。

- 拓扑超导有更特殊的能隙: 不只保护超流, 还保护量子信息——量子态的"特征"(拓扑不变量)不能被局部扰动翻转。

这是拓扑量子计算的"承诺"的物理基础: 错误率 $p \sim e^{-\Delta/k_BT}$ 是指数抑制的。

23.1.3 数学工具——同伦群与辫群

同伦群 $\pi_n$: 描述"在 $n$ 维空间里画圈有多少种本质不同的方式"。在 3D 我们的"圈"总能收缩到一个点——所以 3D 没有非平凡的圈, 没有任意子。但在 2D, 圈可以缠绕不可收缩——这是任意子存在的数学原因。

辫群 (braid group) $B_n$: 描述"$n$ 条世界线互相缠绕的方式"。在 2D 任意子的世界里, 两条世界线交换 (braiding) 不等同于"不交换 + 整体旋转"——这是非阿贝尔任意子编码量子信息的数学基础。

关键: 编织 = $B_n$ 的非阿贝尔表示 (non-abelian representation) → 量子门!

23.2 任意子 (Anyons)——二维世界的奇特粒子

23.2.1 3D vs 2D 统计——为什么任意子是 2D 特产

在 3D 世界里, 粒子只有两类:

- 玻色子 (bosons): 交换后波函数不变 ($\psi \to +\psi$)。光子、胶子、氦-4。

- 费米子 (fermions): 交换后波函数变号 ($\psi \to -\psi$)。电子、质子、中子。

为什么只有这两类? 3D 空间里, "交换两个粒子" = "把一条路径变形到另一条" + "整体旋转"。整体旋转对波函数没影响 (标量场), 所以只有 "不变 / 变号" 两种选择。

在 2D 世界里, "交换两个粒子" = "把世界线绕在一起"——可以不通过"撕裂" + 整体旋转来交换。这意味着:

- 交换可以累积任意相位 $\psi \to e^{i\theta}\psi$。

- $\theta$ 可以是任意值——不只是 0 或 $\pi$!

这就是任意子 (anyons)——2D 世界的奇特粒子。

23.2.2 阿贝尔 vs 非阿贝尔任意子

阿贝尔任意子 (Abelian anyons): 交换只累积相位, 不改变内部量子态。

- 例: 分数量子霍尔态 $\nu = 1/3$ 的 Laughlin 准粒子 (实验已确认)。

- 用途: 容错拓扑码 (ch18 的同伦版本)——不直接做量子门, 但保护量子信息。

非阿贝尔任意子 (Non-abelian anyons): 交换改变内部量子态, 且交换顺序不同 → 末态不同!

- 例: $\nu = 5/2$ 量子霍尔态的 Moore-Read 准粒子 (实验争议中); Fibonacci 任意子 (理论, 未实现)。

- 用途: 量子门的天然载体——本章重点!

23.2.3 Fibonacci 任意子——通用量子计算

Fibonacci 任意子 (理论上, 2003 Freedman-Larsen-Wang 证明) 有最简单的非阿贝尔表示:

- 2 个 Fibonacci 任意子的融合空间是 2 维 → 编码 1 个 qubit

- 编织可以实现任意单 qubit 旋转 + 两 qubit 门 → 通用量子计算

- 跟 Ising 任意子不同: Fibonacci 不需要辅助 π/8 门——真正通用

问题: Fibonacci 任意子至今没有实验实现。理论很美, 工程仍是梦。

23.2.4 Ising 任意子——准通用, 工程上更现实

Ising 任意子 ($\nu = 5/2$ 量子霍尔态中的准粒子) 有较弱的非阿贝尔表示:

- 交换 = 1 qubit 旋转 (例如 $R_x(\pi/4)$)

- 编织只能生成 Clifford 群 (ch07) → 配合辅助 π/8 门才通用 (Solovay-Kitaev 定理 ch07)

实验状态:

- 2012 Kouwenhoven 零偏压电导峰——被解读为 Ising Majorana 证据, 后争议 (2018 撤稿)

- 2024 Microsoft Majorana 1——新证据 + 仍存争议

23.2.5 编织 (Braiding)——任意子的量子门

编织 (braiding): 把任意子沿世界线移动, 互相缠绕/解缠, 产生量子门。

为什么? 非阿贝尔任意子的内部态取决于编织的拓扑 (homotopy class)——只跟世界线互相缠绕的方式有关, 不依赖具体路径!

类比: 系鞋带——鞋带最终怎么缠绕只跟"我绕了几次"有关, 跟"我绕得快还是慢"无关。这是几何相位的拓扑版本。

23.3 Majorana 费米子——自己的反粒子

23.3.1 Majorana 方程 (1937)——反粒子 = 自己

意大利物理学家 Ettore Majorana 1937 年提出: 费米子可以是自己的反粒子。

方程:

$$\gamma = \gamma^\dagger$$

这意味着费米子没有独立的反粒子——粒子和反粒子是同一个。

粒子物理候选:

- 中微子——可能是 Majorana 粒子, 由 $\beta\beta$ 无中微子双衰变 (NLDBD) 实验测试 (KamLAND-Zen, CUORE, nEXO)

- 至今未确认

凝聚态对应——准粒子 (quasiparticle) 可以是 Majorana:

- 固体中的集体激发, 行为像 Majorana 费米子

- 不受泡利不相容原理约束 (因为是"准粒子")

- 可实验操控——这是拓扑量子计算走通的物理基础

23.3.2 Kitaev 链 (2001)——1D 拓扑超导

Kitaev 2001 思想: 把一维自旋极化超导链调谐到拓扑相。

数学模型:

- $N$ 个格点的紧束缚哈密顿量: $H = \sum_i [t c_i^\dagger c_{i+1} + \Delta c_i^\dagger c_{i+1}^\dagger + \mu c_i^\dagger c_i] + \text{h.c.}$

- 当 $|\mu| < 2t$ 时 (链中化学势 vs 跳跃): 系统进入拓扑相。

- 拓扑不变量: 链两端各一个 Majorana 零模 (zero-mode) $\gamma_1, \gamma_2$。

- 两个端点 Majorana 组合成 1 个普通费米子 $f = (\gamma_1 + i\gamma_2)/2$——这个费米子没有能量 (零能)。

拓扑保护: 局部扰动 (杂质、磁场涨落) 不能翻转 $\gamma_1, \gamma_2$ 的缠绕方式——这是抗错的物理基础。

23.3.3 半导体-超导异质结 (2010)——可实验方案

Lutchyn-Sau-Das Sarma 2010 提出实际可造的方案:

组件材料作用
半导体纳米线InSb 或 InAs自旋-轨道耦合强 + g 因子大

2012 年 Kouwenhoven 团队 (Delft) 第一次报告零偏压电导峰 (zero-bias conductance peak) — 被解读为 Majorana 证据。

23.4 编织 (Braiding)——Majorana 的量子门

23.4.1 T-junction + 时间控制——移动 Majorana

实验方案: 用T 型结纳米线, 通过电压门控制 Majorana 位置。

- Majorana 不能真正"移动"——它们是拓扑保护的零模。

- 但系统可以连续形变 → 携带 Majorana 沿纳米线移动 → 等价于编织。

类比: 你不能"移动"一个旋涡的中心, 但你可以带着流体的速度场移动它——最终效果是"世界线缠绕"。

23.4.2 交换 = 1 qubit 旋转

2 个 Majorana 交换:

- $\gamma_1 \leftrightarrow \gamma_2$ (T-junction 控制)

- 量子门: $R_x(\pi/2)$ 或 $R_y(\pi/2)$ (1/4 周期的旋转)

4 个 Majorana (2 个 qubit 编码):

- 多种编织 = 不同单 qubit 门

- 编织 + 测量 = 通用

23.4.3 3 Majorana 编织 = Clifford 群

3 Majorana 编织 (2 次交换) = 单 qubit Clifford 群全集 (ch07 复习)。

4 Majorana 编织 (3-4 次交换) = CNOT 等价——两 qubit Clifford 门全集。

结论: Majorana 编织 = Clifford 群的拓扑实现——配合辅助 π/8 门 (非拓扑) 才是通用 (Solovay-Kitaev 定理)。

23.4.4 Fibonacci 编织——通用性

Fibonacci 任意子 (理论上):

- 2 个 Fibonacci 任意子 = 1 qubit

- 任意编织序列 = 任意量子门

- 不需要辅助 π/8——真正通用

现实: Fibonacci 任意子至今未实验实现——可能是未来 10-20 年的梦想。

23.5 拓扑保护——抗错的物理学

23.5.1 能隙保护——核心机制

核心命题: 拓扑相有能隙 $\Delta$, 局部扰动 < $\Delta$ 不能翻转宏观态。

错误率公式:

$$p \sim e^{-\Delta / k_B T}$$

代入实际参数:

- 超导能隙 $\Delta$ ~ 0.1-1 meV

- 温度 $T$ = 10 mK → $k_B T$ ~ 0.86 μeV

- $\Delta / k_B T$ ~ 100-1000

- $p \sim e^{-100} \sim 10^{-44}$ — 天文数字!

对比超导 (ch20):

- 门错误率 $p$ ~ $10^{-3}$ (受 1/f 噪声 + TLS 限制)

- 比拓扑差 40 个数量级!

注: 实际 $p$ 受非相干噪声 (如准粒子) 限制, 不会真到 $10^{-44}$。但理论上可以到 $10^{-9}$ 以下, 比超导 $10^{-3}$ 好 100 万倍。

23.5.2 相干长度与操作时间

相干长度:

$$\xi = \hbar v_F / \Delta \sim 1-10 \text{ μm}$$

意味着 Majorana 模空间上必须隔离 (典型 1-10 μm) 才能保持拓扑性质。

操作时间 (编织速度):

$$T_{\text{op}} \sim \hbar / \Delta \sim 1-10 \text{ ns (GHz)}$$

跟超导门 (10-100 ns) 相当。

23.5.3 几何相位保护——只跟拓扑有关

核心: 编织末态只取决于世界线缠绕的拓扑 (homotopy class), 不取决于具体路径——这是几何相位 (Berry phase) 的拓扑版本。

意义:

- 不需要精确控制 Majorana 移动路径——慢一点快一点一样

- 不需要精确校准门参数——拓扑保证正确

- 只要拓扑缠绕正确, 量子门就正确!

23.5.4 准粒子毒性——隐藏的杀手

问题: 拓扑保护的"假设"是"系统只有低能激发"。

现实: 实际材料有准粒子 (quasiparticle) 激发:

- 能量 $E > \Delta$ (超过能隙)

- 局部不可控, 引起退相位

- 破坏拓扑保护

解决: 提高能隙 $\Delta$ (材料工程) + 操作时间 $T_{\text{op}} \ll \tau_{\text{quasi}}$ (避免准粒子干扰)。

当前状态: 准粒子毒性仍是未完全解决的理论+工程问题。

23.7 拓扑量子计算的挑战

23.7.1 Majorana 制备困难

问题 1: 半导体-超导界面无序敏感

- InAs/Al 界面必须原子级平整

- 杂质 → 破坏拓扑相

- 当前工艺仍不完美

问题 2: 磁场必须精确

- Zeeman 能 > 超导能, 但 < 临界磁场

- 100 mT 量级, 精度 ~0.1 mT

- 多个 qubit 独立磁场控制难

问题 3: 量子点必须精确调谐

- 每个 Majorana 必须在特定位置

- 电压门 ~mV 精度

- 多 qubit 调谐指数难

23.7.2 编织控制——nm 级精度

问题: T-junction 必须在nm 级精度

- Majorana 模典型尺寸 ~100 nm

- T-junction 分叉必须 Majorana 能清晰分辨两条路径

- 当前光刻精度 ~10 nm (足够), 但多 qubit 协同难

另一个问题: 编织时间 vs 退相干

- $T_{\text{op}} \sim 1$ ns (GHz)

- 退相干时间 $\tau \sim 1$ μs (在 10 mK)

- 比值 ~$10^3$ — 安全

23.7.3 测量退相干

问题: Majorana 测量破坏拓扑态

- 测量必须只探测"整体" (电荷), 不是"局部" (自旋)

- 任何局部测量 → 退相位

- 设计挑战: 全局测量 vs 局部信息读取

23.7.4 未实现通用

当前现实:

- Ising Majorana: 实验部分演示 (Majorana 1 8 qubit), 但 编织 = 量子门仍未完整演示

- Fibonacci 任意子: 完全未实验实现

- Universal QC: 仍未达到

预计时间表 (乐观):

- 2026-2028: Majorana 1 8-64 qubit + 1 logical qubit

- 2028-2030: Ising 编织完整演示

- 2030+: 表面码 + 拓扑混合 → 百万 qubit

- 2035+: Fibonacci 任意子 (如果实现) → 真正通用

23.7.5 产业链不成熟

现状: 拓扑量子计算几乎只有 Microsoft 押重注

- 学术: Kitaev, Nayak, Kouwenhoven 等少数团队

23.9.5 4 道思考题

A1 (编织 = 1 qubit 旋转): 用 2 个 Majorana 实现单 qubit 旋转 $R_x(\pi/2)$ 需要几次交换? 解释为什么"Majorana 编织本质上是几何门"。

答案: 1 次交换 $= R_x(\pi/2)$ (或 $R_y(\pi/2)$, 取决于约定)。"几何门" = 门效果只取决于 Majorana 互相缠绕的拓扑 (谁在谁前), 不取决于路径细节——这是 Berry 相位的拓扑版本, 也是抗参数漂移的物理基础。

A2 (错误率 $e^{-\Delta/k_BT}$): 如果 $\Delta = 0.5$ meV, $T = 10$ mK, 理论上 $p$ 是多少? 对比超导 $p = 10^{-3}$。

答案: $k_B T = 0.086$ μeV × 10 = 0.86 μeV (in 10 mK)。 $\Delta / k_B T = 500$ μeV / 0.86 μeV ≈ 580。$p \sim e^{-580} \sim 10^{-252}$ — 天文数字。注: 实际 $p$ 受准粒子等非相干效应限制, 不会真到 $10^{-252}$, 但理论仍 $10^{-9}$ 以下, 比超导 $10^{-3}$ 好 100 万倍。

A3 (为什么 Majorana 1 争议): Google / IBM / Quantinuum 公开质疑 Microsoft Majorana 1 的核心论点是什么?

答案: 未完整演示非阿贝尔统计。Majorana 1 只演示了"零偏压电导峰"——这是 Majorana 存在的必要条件, 不是充分条件。充分条件是演示编织产生量子门——这需要 T-junction 控制 + 多 qubit 协同, Majorana 1 仍未做到。类比: 超导"transmon" 演示了"能级分裂"≠ 演示了 "CNOT 门"。

A4 (拓扑 vs 表面码 5 年判断): 你认为 5 年后 (2030) 拓扑量子计算会 (a) 跟表面码并驾齐驱, (b) 落后 5 年以上, (c) 完全失败? 给出理由。

答案 (合理预期): (b) 落后 5 年以上。理由: (1) 表面码 2024 已演示阈值, 工程成熟; (2) 拓扑需要 8 qubit 完整演示 → 2030 约 64-100 qubit, 仍远小于表面码 1000+ 物理 qubit; (3) Fibonacci 任意子 5 年内几乎不可能实现; (4) Microsoft 单一押注风险。但长期 (2035+) 拓扑有可能成为补充。

23.A 附录 A: Kitaev 链严格推导

23.A.1 哈密顿量

考虑 $N$ 格点的自旋极化 1D 链 (无自旋自由度, 类似 Kitaev 2001):

$$H = \sum_{i=1}^{N-1} [-t (c_i^\dagger c_{i+1} + \Delta c_i^\dagger c_{i+1}^\dagger + \text{h.c.}) - \mu c_i^\dagger c_i]$$

其中 $t$ 是跳跃, $\Delta$ 是超导配对, $\mu$ 是化学势。

23.A.2 Majorana 表示

关键技巧: 把复费米子算符 $c_j$ 拆成两个实 Majorana 算符:

$$c_j = \frac{1}{2}(\gamma_{j, A} + i \gamma_{j, B})$$

$$\gamma_{j, A} = c_j + c_j^\dagger, \quad \gamma_{j, B} = i(c_j^\dagger - c_j)$$

这两个 Majorana 算符反对易 ($\{\gamma_A, \gamma_B\} = 2\delta_{AB}$), 且自共轭 ($\gamma^\dagger = \gamma$)。

23.A.3 拓扑相与端点态

代入 Majorana 表示, 哈密顿量变成 Majorana 间的"弹簧"耦合。当 $|\mu| < 2t$, 系统进入拓扑相:

- 链内的 Majorana 两两配对成常规费米子 ($E = \pm 2\sqrt{(t \pm \mu/2)^2 + \Delta^2}$)

- 链两端各剩下一个 Majorana $\gamma_1, \gamma_N$ — 没有伙伴, 因此能量 = 0 (零模)

端点态:

$$f_{\text{end}} = \frac{1}{2}(\gamma_1 + i \gamma_N)$$

核心: $\gamma_1, \gamma_N$ 空间上分开, 不与链内 Majorana 耦合——局部扰动 (杂质、磁场涨落) 不能耦合到它们。

23.A.4 拓扑不变量 — $Z_2$ 不变量

Kitaev 链的拓扑不变量是一个 $Z_2$ 数 (即 0 或 1):

- 平庸相 ($|\mu| > 2t$): 拓扑不变量 = 0

- 拓扑相 ($|\mu| < 2t$): 拓扑不变量 = 1

这个不变量不能被连续形变翻转——只能通过量子相变 (在 $|\mu| = 2t$) 改变。这就是拓扑保护的数学基础。

23.B 附录 B: 编织 = Clifford 群 (Sketch)

23.B.1 4 Majorana 编码 2 qubit

4 个 Majorana $\gamma_1, \gamma_2, \gamma_3, \gamma_4$ 编码2 个 qubit:

$$f_1 = \frac{1}{2}(\gamma_1 + i \gamma_2), \quad f_2 = \frac{1}{2}(\gamma_3 + i \gamma_4)$$

23.B.2 交换操作

单次交换 $\gamma_i \leftrightarrow \gamma_j$ (经过 T-junction 移动):

- 产生 $\pi/2$ 相位: $U_{\text{swap}}(i,j) = e^{i\pi/4 \gamma_i \gamma_j}$

多 Majorana 交换的乘积 = Clifford 群元素 (ch07 复习)。

23.B.3 编织对应量子门

编织量子门
$\gamma_1 \leftrightarrow \gamma_2$$R_x(\pi/2)$ 或 $R_y(\pi/2)$
$\gamma_1 \leftrightarrow \gamma_3$ (跨 qubit)$R_{xx}(\pi/2) = e^{-i\pi/4 \sigma_x \otimes \sigma_x}$
4 Majorana 编织 (3-4 次交换)CNOT 等价
任意 Clifford 序列任意 Clifford 群元素

23.B.4 为什么不是通用

Clifford 群 (ch07) + 单 qubit 门 (Hadamard, Phase, CNOT) 不是通用—— Gottesman-Knill 定理 (ch07) 说明 Clifford 电路可经典模拟。

通用需要 T 门 ($e^{-i\pi/8 \sigma_z}$) 或等价的非 Clifford 门。

Majorana 编织只生成 Clifford → 不是通用——需要辅助 π/8 门 (非拓扑实现) → 工程上可加微波脉冲。

23.B.5 Fibonacci 任意子的不同

Fibonacci 任意子 (理论):

- 2 个 Fibonacci 任意子 = 1 qubit

- 任意编织 = 任意量子门 (1 qubit + 2 qubit)

- 不需要辅助 π/8

- 真正通用

问题: 自然界至今没有已知的 Fibonacci 任意子。理论上拓扑有序的凝聚态系统 (如某些 spin liquid) 可能实现, 实验上仍是梦。

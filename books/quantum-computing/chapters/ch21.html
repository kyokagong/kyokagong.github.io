21.0.2 离子阱的"卖点" — 全连接

ch20 的超导芯片是平面 2D 网格或 heavy-hex 拓扑, 远距 qubit 需要 SWAP 链 (10-20 门) 才能间接纠缠。

离子阱的"绝活": 全连接 (all-to-all connectivity)。

  • $N$ 个离子排成一条链 → 任意两离子直接通过共享振动模耦合
  • 1 个 MS gate = 任意两 qubit 纠缠 (vs SWAP 链 10-20 门)

对比: 实现 50 qubit 之间的 GHZ 态

  • 超导 (2D grid): 至少 ~50 × 10 = 500 CNOT (考虑 SWAP)
  • 离子阱 (链): 49 个 MS gate (1 个中心离子 + 48 个邻居)

21.1 离子阱物理:Paul 阱

21.1.1 为什么需要"阱"?

要让一个离子当 qubit 用, 必须先把它固定在空间某个位置 (不撞容器壁, 不飞走), 再用它做量子操作。

经典办法 (Penning 阱, 1936):

  • 静磁场 (B 方向) + 静电场 (端盖电极)
  • B 让离子在 xy 平面做回旋运动, 端盖电场在 z 方向囚禁
  • 问题: 静电场不能同时囚禁三维 — Earnshaw 定理 (无静电场的稳定平衡点)

革命 (Paul 阱, 1953, 1989 诺奖):

  • 射频 (RF) 电场 替代静电场
  • 利用 RF 场的时间平均效果产生赝势 (pseudopotential) 囚禁

21.1.2 Paul 阱的几何与电场

最简模型: 线性 Paul 阱 (4 根平行电极, 离子链沿轴排列)。

   顶部: +U_RF·cos(Ωt)
    ↑     ↑     ↑     ↑
    |     |     |     |       4 根棒状电极
    |     |     |     |
   ─────────────────────  ← 离子链 (沿 z 轴)
    |     |     |     |
    |     |     |     |
    ↓     ↓     ↓     ↓
   底部: -U_RF·cos(Ωt)

电场 (在离子位置附近近似为四极场):

$$\Phi(x, y, z, t) = \frac{U_{RF} \cos(\Omega t)}{2 r_0^2}(x^2 - y^2)$$

  • $U_{RF}$: RF 电压幅度 (~100-1000 V)
  • $\Omega$: RF 频率 (~10-100 MHz)
  • $r_0$: 离子到电极的距离 (~0.5-2 mm)
  • 关键: 电场在 xy 平面旋转 (从 +x 方向 → +y 方向 → -x → -y → ...), 周期为 $2\pi/\Omega$

21.1.3 赝势 (Pseudopotential) 近似

把离子长时间平均的运动 (远长于 $1/\Omega$) 看成一个有效势阱里的简谐振动。

马修方程 (Mathieu equation) 描述离子在 RF 场中的运动。在 $|a|, |q| \ll 1$ 的稳定区:

$$m \ddot{x} + m \omega_x^2 x \approx 0, \quad \omega_x = \frac{q U_{RF}}{2 m \Omega r_0^2}$$

有效赝势 (沿径向):

$$V_{\text{eff}}(r) = \frac{1}{2} m \omega^2 r^2, \quad \omega \sim \frac{q U_{RF}}{m \Omega r_0^2}$$

物理直觉: RF 场在快速时间尺度 (ns) 上"踢"离子, 在慢时间尺度 (μs-ms) 上平均成一个弹簧。

典型参数:

  • 径向频率 $\omega_r/(2\pi) \sim$ 1-5 MHz
  • 轴向频率 $\omega_z/(2\pi) \sim$ 0.1-1 MHz
  • 阱深 ~1-10 eV (室温 $k_B T \sim 25$ meV → 阱深 100× 大, 离子不会热逃逸)

21.1.4 离子链 — N 离子集体振动

最关键的多体物理: $N$ 个带电离子被同一个 Paul 阱囚禁 → 库仑斥力让它们等距排列成一条一维链。

 离子 1    离子 2   离子 3   ...   离子 N
  ●        ●        ●              ●
  ↑        ↑        ↑              ↑
  |←─ℓ─→|←─ℓ─→|←─ℓ─→|       (ℓ ≈ 2-5 μm)

库仑 + 阱 平衡:

$$m \omega_z^2 z_0 = \frac{e^2}{4 \pi \epsilon_0 (2 z_0)^2}, \quad z_0 = \left(\frac{e^2}{16 \pi \epsilon_0 m \omega_z^2}\right)^{1/3}$$

典型离子间距 $\ell \sim 2-5 \ \mu\text{m}$。

集体振动模 ($N$ 离子 → $N$ 振动模):

模 物理 频率
COM (质心) 模 全部离子同步在 z 方向振动 $\omega_z$
Stretch (拉伸) 模 离子反对称振动 $\sqrt{3} \omega_z$
内模 ($N-2$ 个) 离子之间相对振动 $\omega_p = \sqrt{p(p+1)/2} \cdot \omega_z$

类比: 就像一根有 $N$ 个原子的"弹簧链", 弹性力 + 库仑力 → $N$ 个简正模。

实验意义 (ch21.4 见):

  • COM 模是第一个被用来做两 qubit 门的媒介
  • MS gate 实际上是同时驱动多个集体模 → 更鲁棒

21.1.5 2D 与 3D Paul 阱

1D 链只能容纳 ~50-100 离子 (因为链会"变软", 模频率接近, 串扰严重)。

进一步扩展:

  • 2D 阵列: 用 5 根电极 (4 侧面 + 1 中心) 构成表面 Paul 阱
  • 3D 阵列: 多层电极 + 复杂 RF 场
  • Penning 阱: 静磁场 + 静电场 → 2D 平面排列, 可达 1000+ 离子 (但难单独寻址)

本章 21.7 详细讨论扩展挑战。

21.1.6 Paul 阱的"祖先"

  • Penning 阱 (1936, Dehmelt 1989 诺奖): 静磁 + 静端盖, 离子做回旋运动
  • Paul 阱 (1953, Paul 1989 诺奖): RF 四极场, 离子在赝势中振动
  • 表面 Paul 阱 (2006, NIST): 平面电极, 集成在芯片上 → 可扩展

主流选择:

        ↑ F=1  ↑ F=0
        |       |
        |       |
        └───────┘  ^2S_{1/2} (基态, 4f^{14} 6s)
  • 基态 $^2S_{1/2}$ 有两个超精细能级 $F=0$ 和 $F=1$ (12.6 GHz 分裂)
  • 选择 $\lvert 0\rangle = \lvert F=0\rangle$ 和 $\lvert 1\rangle = \lvert F=1\rangle$ 作 qubit
  • 优点: 12.6 GHz 微波可驱动 → 也可用拉曼激光 (355 nm)

21.2.2 Doppler 冷却 — 第一步

问题: 刚被 Paul 阱捕获的离子温度 ~1000 K (远远热于振动基态, 室温已经很高)。

Doppler 冷却原理:

离子速度 v → 吸收光子 hν' = h(ν₀ - kv)  ←  失谐 Δ = ν_laser - ν₀ < 0
     ↓
 散射光子 hν  (各向同性)
     ↓
每次"吸收-发射"循环, 离子损失动能 = h·(ν' - ν) ≈ h·kv

结果: 离子减速, 温度降到 Doppler 极限:

$$T_D = \frac{\hbar \Gamma}{2 k_B}$$

  • $\Gamma$: 跃迁自然线宽 (典型 10-30 MHz)
  • $T_D$ ~ 0.5-1 mK (对于可见光跃迁)

但: 1 mK 仍然高于振动量子 $\hbar \omega_z / k_B \sim 50 \ \mu\text{K}$ → 需要边带冷却。

21.2.3 边带冷却 (Sideband Cooling) — 第二步

核心思想: 在 Lamb-Dicke 区 ($\eta \ll 1$), 离子的振动量子态会被激光分辨。

激光调到一阶红边带 ($\omega_l = \omega_0 - \omega_z$):

振动能级:  |n+1⟩ ──── ω_z
           |n⟩   ──── 0
电子能级:  |e⟩   ──── ω_0
  • 吸收红边带光子: $\lvert g, n\rangle \to \lvert e, n-1\rangle$ (减少 1 个振动量子)
  • 自发辐射回基态: $\lvert e, n-1\rangle \to \lvert g, n-1\rangle$ (振动不变)
  • 净效果: 振动量子减 1!

重复 ~10-100 次: $\lvert n=0\rangle$ 概率 > 99%。

极限: $\bar{n} < 0.01$ (亚基态)。

21.2.4 Lamb-Dicke 条件

边带冷却要求激光能分辨振动边带, 即 $\omega_z \gg \Gamma$ (电子跃迁线宽)。

等价条件: Lamb-Dicke 参数:

$$\eta = k \cdot x_0 = \sqrt{\frac{E_r}{\hbar \omega_z}} \ll 1$$

  • $k$: 激光波矢
  • $x_0 = \sqrt{\hbar / 2 m \omega_z}$: 振动基态涨落
  • $E_r = \hbar^2 k^2 / 2m$: 反冲能量

物理意义: 离子的振动涨落比光波长短得多 → 离子在 Lamb-Dicke 区内被"冻结"在空间固定点。

典型值: $\eta \sim 0.1$ (边带可分辨) → 边带冷却有效。

21.2.5 冷却流程总结

室温 (~300 K)
  ↓ Doppler 冷却 (~ms, 激光调谐到 -Γ/2)
mK 量级
  ↓ 边带冷却 (~100 μs, 红边带)
振动基态 (n̄ < 0.01)
  ↓ 进入"量子操作"阶段 (coherent dynamics)

"准备时间"代价: ~10-100 ms (Doppler + 边带), 占总算法时间的 ~10-30% (因门时间短)。

21.3 单 qubit 门:激光驱动

21.3.1 Rabi 振荡

共驱动 (Coherent Drive): 把激光调谐到 qubit 频率 ($\omega_l = \omega_{01}$), 持续时间 $t$。

哈密顿量 (旋转波近似):

$$H = \frac{\hbar \Omega_R}{2} (\sigma_+ e^{-i\phi} + \sigma_- e^{i\phi})$$

  • $\Omega_R$: Rabi 频率 (与激光强度成正比)
  • $\phi$: 激光相位 (控制旋转轴)

演化: $\lvert \psi(t)\rangle = \cos(\Omega_R t / 2) \lvert 0\rangle - i e^{i\phi} \sin(\Omega_R t / 2) \lvert 1\rangle$

特殊点:

  • $\Omega_R t = \pi$ → X 门 ($\lvert 0\rangle \leftrightarrow \lvert 1\rangle$)
  • $\Omega_R t = \pi/2$ → Hadamard 门 (叠加态)
  • 任意 $\theta$ 加上任意 $\phi$ → 任意 $SU(2)$ 单 qubit 门

21.3.2 典型参数

平台 频率 门时间 保真度 备注
离子阱 (拉曼) ~12.6 GHz (微波等价) 1-10 μs 99.99% Quantinuum H3
离子阱 (微波) ~12.6 GHz 10-50 μs 99.9% 不需激光
超导 (ch20) 4-8 GHz 10-100 ns 99.5-99.9% 快 100×

直觉: 离子阱慢 100×, 但保真度高 10-100× (因为离子是孤立的, 没有超导的衬底缺陷)。

21.3.3 AC Stark Shift (AC 斯塔克移位)

问题: 激光不是严格单色 → AC Stark 效应使 qubit 频率 $\omega_{01}$ 漂移。

$$\Delta \omega_{AC} \propto I / \Delta$$

  • $I$: 激光强度
  • $\Delta$: 激光失谐

结果: Rabi 频率不准 → 门不保形 (over-/under-rotation)。

补偿:

  • 选大失谐 $\Delta$ (减小 Stark shift, 但减小拉比频率)
  • 用 "复合脉冲" (BB1, SK1, CORPSE) — 多脉冲组合, 抵消一阶 AC Stark
  • 用 "自校准" 序列 — 实时测量 + 反馈

21.3.4 拉曼 vs 直接微波

两种实现单 qubit 门的方法:

A) 拉曼 (Raman) 激光:

  • 两束激光, 频率差 = qubit 频率 (~12.6 GHz)
  • 激光只差频起作用 (不直接共振)
  • 优点: 激光窄线宽 + 空间寻址容易 (光斑小)
  • 缺点: 复杂光学, AC Stark shift

B) 直接微波:

  • 微波 (~12.6 GHz) 直接驱动 qubit
  • 优点: 简单, Stark shift 小
  • 缺点: 波长 ~ cm, 难做单离子寻址 (要多个电极)

商业:

  • Quantinuum 用微波 (H3 是微波门) → 简化
  • IonQ 用拉曼激光

21.3.5 门保真度的"瓶颈"

为什么 99.99% 不容易再提高?

误差源 大小 改进
激光强度涨落 ~$10^{-4}$ 稳定 + 反馈
激光频率漂移 ~$10^{-4}$ 锁相环
AC Stark shift 残余 ~$10^{-4}$ 复合脉冲
自发辐射 ~$10^{-4}$ 选长寿命 qubit 态
磁场涨落 ~$10^{-5}$ 磁屏蔽
离子加热 (振动激发) ~$10^{-4}$ 表面阱设计

当前最高: 99.999% (Kielpinski 2019, NIST 2021) — 接近理论极限。

21.4 两 qubit 门:Cirac-Zoller vs Mølmer-Sørensen

21.4.1 为什么两 qubit 门难?

关键挑战: 离子没有直接 dipole-dipole 相互作用 (不像超导的电容/电感耦合)。

唯一的天然相互作用: 离子共享集体振动模 (phonon)。

所以: 任何两 qubit 门都必须:

  1. 驱动集体振动模
  2. 让两个 qubit 同时与振动模作用
  3. 解耦 振动模 (回到基态)

21.4.2 Cirac-Zoller 门 (1995) — 第一个方案

核心思想: 用单个集体模 (COM 模) 作为"数据总线", 一步一步纠缠两个 qubit。

协议 (CNOT on ions 1, 2):

  1. 把 ion 1 的叠加映射到 COM 模:

$\alpha \lvert 0\rangle_1 + \beta \lvert 1\rangle_1 \to \alpha \lvert 0, 0\rangle_{1, COM} + \beta \lvert 1, 1\rangle_{1, COM}$

  1. 用 COM 模的激发做受控操作 ion 2:

$\lvert 0\rangle_1 \lvert 0\rangle_2 \to \lvert 0\rangle_1 \lvert 0\rangle_2$

$\lvert 0\rangle_1 \lvert 1\rangle_2 \to \lvert 0\rangle_1 \lvert 1\rangle_2$

$\lvert 1\rangle_1 \lvert 0\rangle_2 \to \lvert 1\rangle_1 \lvert 1\rangle_2$

$\lvert 1\rangle_1 \lvert 1\rangle_2 \to \lvert 1\rangle_1 \lvert 0\rangle_2$ (翻转!)

  1. 解除 ion 1 与 COM 模的耦合 (回到 ion 1 自身态)

结果: CNOT(1, 2) 门

问题:

  • 必须精确控制单个集体模 → 难 (因为离子链有 N 个模)
  • 必须冷却到 COM 模基态 → 反复冷却
  • 门时间 ~100 μs (慢)
  • 实验实现: Innsbruck 2003, 第一个 CNOT 离子门

21.4.3 Mølmer-Sørensen 门 (1999, MS gate) — 革命

核心思想: 不用单个模, 不用单个qubit 控制, 而是同时驱动所有离子和所有集体模。

协议:

  1. 在红失谐 ($\omega_l = \omega_0 - \omega_z + \delta$, $\delta$ 小) 双向同时照射 ion 1 和 ion 2
  2. 激光与集体振动的耦合 → 虚拟激发集体模
  3. 积累 几何相位 (Berry 相位, 见 21.4.5)
  4. 当 $\delta T = 2\pi$ 时, 集体模解耦 (回基态), 净效果是两 qubit 纠缠

哈密顿量 (简化):

$$H_{MS} = \hbar \Omega J_x^{(12)} \otimes \bar{a}^\dagger \bar{a} \cdot ...$$

结果: $\text{MS}(\pi/2) = \exp(-i \pi/4 \cdot X \otimes X)$ 类的纠缠门

门时间: 10-100 μs (比 Cirac-Zoller 快 ~10×)

保真度: 99.9-99.99% (Quantinuum H3 99.99%)

21.4.4 MS gate 的"魔法"

为什么 MS 不需要单模分辨**?

A) Cirac-Zoller 必须区分激发哪个模 → 需要 $\omega_z \gg$ 模间间隔 → 难

B) MS 是双光子过程, 失谐 $\delta$ 同时覆盖多个模 → 所有模一起演化 → 模不分辨也没事

为什么 MS 更快**?

A) Cirac-Zoller 必须精确等到 COM 模完成 1 个循环 → $\pi/\omega_z$ 量级

B) MS 用几何相位, 只关心封闭路径, 不必等到谐振 → 10× 短

为什么 MS 更容错**?

A) Cirac-Zoller 对单模的初态和末态都敏感 (必须基态)

B) MS 对热初态更容错 (几何相位部分抵消热噪声)

21.4.5 几何相位 (Berry Phase) 机制

MS gate 的深层物理: 激光 + 集体振动 + 离子 → 相空间 (Re, Im of $\alpha$) 中的圆轨迹。

    Im(α)
      ↑
      |     ● 起点 (t=0, α=0)
      |    /  \
      |   /    \
      |  /  →→  \    ← 圆 (半径 ~ Ω/δ)
      |  \  ←←  /
      |   \    /
      |    \  /
      |     ● 终点 (t=2π/δ, α=0)  ← 回到原点
      |
      └──────────────→ Re(α)
  • 离子周期 = $2\pi/\delta$ (激光失谐决定)
  • 在一个周期后, 振动模回到基态 (因为 $\alpha(T) = 0$)
  • 但离子积累了几何相位 (面积) → 两 qubit 纠缠!

关键: 不依赖中间具体路径, 只看包围的面积 → 几何相位是拓扑的 → 对小扰动鲁棒。

21.5 全连接:离子链的"超级武器"

21.5.1 离子链 = 天然全连接

关键观察: $N$ 个离子排成一条链, 每个离子都与每一个集体模有非零耦合。

结果: 任何两离子直接通过共享的集体模相互作用。

数学: 集体模 $m$ 的位置是 $\lvert m\rangle = \sum_i b_{i,m} \lvert i\rangle$, 其中 $b_{i,m}$ 是正交矩阵的元素 → 任意两离子总能找到一个或多个模同时耦合两者。

vs 超导 (ch20.5):

  • 超导: heavy-hex (IBM) / 2D grid (Google)
  • 远距 qubit → SWAP 链 (10-20 门) 间接纠缠
  • 100 qubit 全纠缠 = O($N^2$) CNOT = ~5000 门

vs 离子阱:

  • 离子链 → 1 MS gate 纠缠任意两 qubit
  • 100 qubit 全纠缠 = $N(N-1)/2 = 4950$ MS gate (但每个 MS 是 1 门, 不是 10 门)

对比:

  • 超导 100 qubit 全纠缠 = 5000 × 10 (SWAP 链) = 50000 单门操作
  • 离子阱 100 qubit 全纠缠 = 4950 MS (1 门) = 4950 两门操作

虽然离子阱门慢 100×, 但门数少 10×, 总时间还是短 (但优势主要是保真度, 见 21.5.4)。

21.5.2 离子链的"瓶颈":模拥挤 (Mode Crowding)

问题: 离子链越长 → 集体模频率越接近 (模间隔 $\Delta \omega \sim 1/N$)。

N = 2:  ω_COM, ω_stretch   (间隔 100%)
N = 4:  ω_1, ω_2, ω_3, ω_4  (间隔 30%)
N = 10: 间隔 ~10%
N = 50: 间隔 ~2%  ← 模**几乎简并**
N = 100: 间隔 ~1% ← **严重**拥挤

后果:

  • MS gate 失谐 $\delta$ 必须避开所有模 → 难
  • 模串扰 → 门不保形
  • 实际 离子链通常 ≤ 50 离子 (Quantinuum H3 是 56)

21.5.3 QCCD 架构 (Quantinuum 2022+)

思想: 把大链分成多个小链 (5-10 离子/链), 用电极把离子搬运到一起做两 qubit 门, 然后搬回去。

   链 1    链 2    链 3    ...
   ●●●     ●●●     ●●●
    ↓       ↓       ↓
   ←─ 电极搬运 (10-100 μs) ─→
    ↓
   临时合并链: ●●●●●●●●●●●  (做 1 个 MS)
    ↓
   拆分 (10-100 μs)

优点:

  • 链小 → 模不拥挤 → 高保真度
  • 总体可扩展 (理论上 1000+ 离子, Quantinuum 路线图)

代价:

  • 搬运 时间 ~10-100 μs (搬一个离子 = 几个门时间)
  • 搬运 加热 → 必须冷却 (增加时间)

QCCD = Quantum Charge-Coupled Device — 类比经典电子学的 CCD。

21.6 读出:态依赖荧光

21.6.1 核心方法

经典办法: 用激光区分两个 qubit 态。

|1⟩  → 共振激光 → 散射荧光 → 探测器测到光子
|0⟩  → 暗态      → 不散射  → 探测器测到 0

物理: 选 $|1\rangle$ 与强跃迁 $\lvert 1\rangle \to \lvert e\rangle$ 共振, $|0\rangle$ 不与任何激光共振。

典型:

  • $^{40}$Ca$^+$: $\lvert 1\rangle = D_{5/2}$ (亚稳, τ ~ 1 s) → 397 nm 散射
  • $^{171}$Yb$^+$: $\lvert 1\rangle = F=1$ → 369 nm 散射, $|0\rangle = F=0$ → 暗

21.6.2 收集光子的"工程"

挑战: 1 个离子散射的总光子数 $\sim \Gamma \times t$ (线宽 × 时间)。

  • 散射率 $\Gamma/(2\pi) \sim 10-30$ MHz → 1 ms 散 $\sim 10^7$ 光子
  • 物镜 NA ~0.4 → 收集立体角 ~2-5% → 实际收集 $\sim 10^5-10^6$ 光子
  • 测 ms 即可 99.9% 区分 $|0\rangle$ vs $|1\rangle$

成像:

  • 单离子: 1 个 PMT (光电倍增管)
  • 多离子 (N=50): 1 个 EMCCD (电子倍增 CCD) 相机, 空间分辨 ~1 μm → 同时测 50 离子

21.6.3 串扰问题

问题: 测 ion 1 时, 邻居 ion 2 也散射荧光 → 误读。

解法 1: 空间分辨 (EMCCD)

  • 物镜成像到 EMCCD → 空间上分开 → 串扰 < 0.1%

解法 2: 频率分辨

  • 用不同 Zeeman 子能级 → 不同跃迁频率 → 频率滤波
  • 但慢, 因为要扫频

解法 3: 时间分辨

  • 先测 ion 1 (ms 量级), 再测 ion 2 → 慢
  • Quantinuum 用空间分辨 + 短测量

21.6.4 读出保真度

平台 单 qubit 读出保真度 备注
离子阱 99.99% 散射大量光子, 高信噪比
超导 (ch20) 99% 色散读出, 信噪比有限
光量子 (ch22) 95-99% 单光子探测
中性原子 (ch24) 99% 荧光

原因: 离子阱的"亮态 vs 暗态"对比极强 (有光 vs 无光), 而超导的"色散移位"是小信号 → 信噪比低。

21.6.5 量子非破坏 (QND) 读出

重要性质: 离子阱读出通常是 QND 的:

  • 测量 $\lvert 1\rangle$ 后, 离子还是 $\lvert 1\rangle$ (在 $|1\rangle$ 散射完光子后仍然回到 $|1\rangle$)
  • 测量 $\lvert 0\rangle$ 后, 离子还是 $\lvert 0\rangle$ (不散射)

与 ch20.6.1 的超导读出对比:

  • 超导: 测量破坏 qubit (resonator 拿走 1 个光子 → T_2 ↓)
  • 离子阱: 测量不破坏 qubit (散射后回到原态)

代价: 离子阱读出慢 (ms) vs 超导快 (ns), 但无反作用 → 适合反馈。

21.7 扩展挑战:从 50 到 1000+ 离子

21.7.1 1D 链的极限

为什么 1D 链不能直接到 100+ 离子?

A) 模拥挤 (21.5.2): 模频率间隔 $\sim 1/N$ → N=100 时 1% → MS 难选 $\delta$

B) 链"软化": 长链中间离子约束弱 (端帽电场衰减) → 离子间距变化大

C) 寻址困难: 激光光斑 ~1 μm, 离子间距 2-5 μm → 邻离子串扰

D) 加热率: 表面 Paul 阱的电极表面有噪声电场 → 离子异常加热 (Einfeld 加热)

经验: 1D 链实际上限 ~ 50-100 离子。

21.7.2 2D Paul 阱 (表面阱)

思想: 在芯片表面做 Paul 阱 → 离子被悬浮在表面 ~50-100 μm 上方。

优点:

  • 可扩展: 类似超导, 在同一芯片上做 2D 阵列
  • 集成: 电极 + 激光集成在芯片
  • QCCD 容易实现

缺点:

  • 加热率比宏观阱高 100× (表面噪声)
  • 需复杂电极几何

代表: MIT Lincoln Lab, Sandia, Duke, U. Sussex (Universal Quantum)

21.7.3 Penning 阱 (2D 离子晶体)

完全不同的思路: 用强静磁场 + 静电端盖 → 离子在 xy 平面做回旋运动 → 排列成2D 圆环或盘。

        _____
      /  o o  \
     /  o o o  \      ← 2D 离子晶体
     \  o o o  /          (数十到数千离子)
      \  o o  /
        ‾‾‾‾‾
        ← B 方向

代表: U. Maryland (Bollinger 组), Imperial College (Home 组)

优点:

  • 规模大: 数百到数千离子
  • 稳定: 静场 → 无 RF 加热

缺点:

  • 旋转: 整个晶体在转 → Doppler 移位大
  • 寻址难: 离子都在转, 激光跟离子相对运动复杂
  • 门保真度比 1D 链低 (旋转效应难校准)

21.7.4 模块化:光子互连

终极想法: 多个离子阱, 每个阱 5-50 离子, 用光子在阱间纠缠。

  [5 离子]      [5 离子]      [5 离子]
      |             |             |
   激光+光纤     激光+光纤     激光+光纤
      |             |             |
      └──── 光子分束器 ────┘
              ↓
      远距离纠缠 (10-100 km)

机制:

  • 每个离子发射单光子 (与电子态纠缠)
  • 两个离子各自发射的光子在分束器干涉
  • 干涉结果投影到两离子纠缠态

代表: U. Oxford (Lucas 组), U. Maryland (Monroe 组), IonQ

  • 短距 (m): 实验演示

  • 长距 (100+ km): 卫星-地面 (中国墨子号已演示)

21.10.6 4 道思考题

A1: 为什么离子阱的 T1 (秒-小时) 比超导的 T1 (~100 μs) 长得多? 物理根源是什么?

A3: Quantinuum H3 有 56 离子, 1D 链. 为什么 1D 链的离子数通常 ≤ 50-100? 给出 3 个物理原因.

A4: 假设你想构造 1 个 100 logical qubit 量子计算机, 2 种选择:

  • A: 1000 物理 qubit, 单门保真度 99.9%, 连接 heavy-hex, 2 个 逻辑qubit 之间需要 10 个物理门
  • B: 5000 物理 qubit, 单门保真度 99.99%, 连接全连, 1 个 MS = 1 个逻辑门

21.10.7 思考题详细答案

A1: 长 T1 的物理根源:

  • 离子被囚禁在真空中 (~$10^{-11}$ Torr), 没有碰撞
  • 离子没有衬底 (不像超导在 chip 上), 没有 TLS (二能级系统) 引起弛豫
  • 离子被屏蔽于外界电磁场 (Paul 阱是 RF 场, 对电子态影响小)
  • qubit 态通常选长寿命能级 (e.g., 超精细 $F=0, F=1$ → 寿命秒-小时)
  • 离子是同位素纯净的 (e.g., $^{171}$Yb$^+$ 单一同位素) → 没有核自旋噪声

A2: MS gate 几何相位的"容错"机制:

  • 几何相位 = $\oint A \cdot d\ell$ (相空间中的面积)
  • 只依赖封闭路径的形状, 不依赖具体演化时间或速度
  • 即使失谐 $\delta$ 有小扰动 $\delta \to \delta + \epsilon$, 净面积变化只是二阶 ($\sim \epsilon^2$)
  • 而动力学相位 (Cirac-Zoller) 对单模精确共振敏感 → 一阶误差
  • 结论: MS = 几何 (容错), CZ = 动力学 (敏感)

A3: 1D 链 ≤ 50-100 离子的 3 个物理原因:

  1. 模拥挤: 模频率间隔 $\sim 1/N$ → $N=100$ 时 1% → MS 难选 $\delta$
  2. 链"软化": 端帽电场随距离衰减 → 中间离子约束弱 → 离子间距变化大 → 振动不均匀
  3. 寻址困难: 激光光斑 ~1 μm, 离子间距 2-5 μm → 邻离子串扰 ~1%

A4: 100 logical qubit 选哪个:

  • A (超导, heavy-hex): 1 个逻辑门 = 10 个物理门, 物理保真度 99.9%
  • 逻辑门保真度 = $0.999^{10} = 0.990$ = 99.0%
  • 100 logical qubit 纠缠 (类似 21.5.4 估算): ~100×10 = 1000 物理门 → 0.999^1000 = 37% (灾难)
  • 实际: 需纠错码 → Surface code 阈值 ~1%, 物理 99.9% 在阈值外 → 失败
  • B (离子阱, 全连): 1 个逻辑门 = 1 MS (50 μs), 物理保真度 99.99%
  • 逻辑门保真度 = 0.9999 (≈ 1 个门)
  • 100 logical qubit 纠缠: ~100 MS (因为全连) → 0.9999^100 = 99.0% ✓
  • 实际: 5000 物理 → 50 logical (1 logical = 100 物理) → 仍可容错
  • 结论: B (离子阱) 大胜:
  • 全连 → 门数少 10× (关键!)
  • 保真度高 10× (99.99% vs 99.9%)
  • T1 长 10000× (秒 vs 100 μs)
  • 总操作数 + 总累积错误, B 优势大

但: A 有 1000 qubit (vs B 5000), 规模优势.

深层: 容错的"逻辑 qubit" = 资源问题:

  • 离子阱: 1 logical ≈ 100 物理 (因为全连, 1:1 码距)
  • 超导: 1 logical ≈ 1000-10000 物理 (表面码距离 d=10-30, 物理数 $d^2$)

21.A 附录 A: Paul 阱 RF 场与赝势推导

21.A.1 Paul 阱的几何

考虑 4 根平行电极 (沿 z 轴), 离子链沿 z 轴。

电势 (理想四极):

$$\Phi(\mathbf{r}, t) = \frac{U + V \cos(\Omega t)}{2 r_0^2}(x^2 - y^2) + \frac{\kappa U}{z_0^2}(z^2 - \frac{x^2 + y^2}{2})$$

  • $U$: 直流电压 (端帽)
  • $V$: RF 电压幅度
  • $\Omega$: RF 频率
  • $r_0$: 离子到电极距离
  • $\kappa$: 几何因子 (~0.1-0.3)

21.A.2 离子在 RF 场中的运动

x 方向运动方程 (简化为 1D):

$$m \ddot{x} = -e \frac{\partial \Phi}{\partial x} = -\frac{e (U + V \cos \Omega t)}{r_0^2} x$$

引入无量纲参数:

$$a = \frac{4 e U}{m \Omega^2 r_0^2}, \quad q = \frac{2 e V}{m \Omega^2 r_0^2}$$

得到马修方程:

$$\frac{d^2 x}{d \tau^2} + (a - 2 q \cos 2 \tau) x = 0, \quad \tau = \frac{\Omega t}{2}$$

21.A.3 稳定区

Floquet 定理: 方程的解是 $x(\tau) = e^{i \mu \tau} P(\tau)$, 其中 $P$ 是周期函数。

稳定条件: $\mu$ 必须是实数 (不是虚数)。

最简稳定区 ($a = 0$): $|q| < 0.908$

典型操作: $a \approx 0$, $q \approx 0.3-0.5$ (深稳区)

21.A.4 赝势近似

在 $|q| \ll 1$ 区, 离子做快速微振动 (微运动, micromotion), 叠加在慢的赝运动 (secular motion) 上。

微运动 (周期 $2\pi/\Omega$): 振幅 $\sim q x_0$, 频率 $\Omega$。

赝运动 (频率 $\omega$): $\omega \approx \frac{q \Omega}{2 \sqrt{2}}$

有效赝势:

$$V_{\text{eff}}(x) = \frac{1}{2} m \omega^2 x^2$$

等价: 离子在"看不见的"弹簧 ($k = m \omega^2$) 势阱中慢振动。

21.A.5 离子链平衡间距

$N$ 离子平衡间距 (1D 链):

$$z_0 = \left(\frac{e^2}{16 \pi \epsilon_0 m \omega_z^2}\right)^{1/3}$$

典型值: $\omega_z/(2\pi) \sim$ 1 MHz, $m \sim 100$ amu → $z_0 \sim$ 2-5 μm

N 离子总长度: $L = (N-1) z_0$ → $N=50$ → $L \sim 100$ μm (合理)

21.A.6 库仑耦合 + 集体振动模

$N$ 离子的 Lagrangian (在 $z$ 方向, 简化):

$$L = \sum_i \frac{1}{2} m \dot{z}_i^2 - \sum_i \frac{1}{2} m \omega_z^2 z_i^2 - \sum_{i < j} \frac{e^2}{4 \pi \epsilon_0 |z_i - z_j|}$$

集体坐标 (正交变换): $q_m = \sum_i b_{i,m} z_i$, 其中 $b_{i,m}$ 是正交矩阵的元素。

结果: $N$ 个独立简谐振子, 频率 $\omega_p = \sqrt{p(p+1)/2} \cdot \omega_z$ ($p = 1, ..., N$)

  • $p=1$: COM 模 ($\omega_1 = \omega_z$)
  • $p=2$: Stretch 模 ($\omega_2 = \sqrt{3} \omega_z$)
  • $p=N$: 最高频内模

21.B 附录 B: Mølmer-Sørensen 门详细推导

21.B.1 设定

两离子 ($i = 1, 2$), 单集体模 (简化).

哈密顿量 (双光子失谐 $\delta$):

$$H = \hbar \omega_z a^\dagger a + \frac{\hbar \omega_0}{2} \sigma_z^{(1)} + \frac{\hbar \omega_0}{2} \sigma_z^{(2)} + \hbar g (\sigma_+^{(1)} + \sigma_+^{(2)}) (a + a^\dagger) \cos(\omega_l t)$$

激光频率: $\omega_l = \omega_0 - \omega_z + \delta$ (红失谐 + 小失谐)

21.B.2 Lamb-Dicke 极限 + 旋转波近似

在 $\eta \ll 1$ 下, 哈密顿量简化为 (详细计算见 Leibfried 2003):

$$H_{MS} = \hbar \frac{\Omega}{2} (\sigma_+^{(1)} + \sigma_+^{(2)}) a e^{i \delta t} + \text{h.c.}$$

  • $\Omega$: 单光子 Rabi 频率
  • $\delta$: 失谐 (≪ $\omega_z$)
  • $a$: 集体模湮灭算符

21.B.3 求解

两离子算符: $S_+ = \sigma_+^{(1)} + \sigma_+^{(2)}$, $S_- = S_+^\dagger$

集体模算符: $a$, $a^\dagger$

有效两 qubit 算符 (在 $\delta$ 失谐下):

$$H_{eff} = \hbar \frac{\Omega^2}{2 \delta} (S_x^2 - S_y^2 - S_z) = \hbar \frac{\Omega^2}{4 \delta} (S_x^2 - S_y^2)$$

  • 演化算符: $U_{MS}(t) = \exp(-i H_{eff} t / \hbar)$

当 $t = 2\pi / \delta$:

  • 集体模完全解耦 (回到基态)
  • 净效果: 离子间纠缠 (几何相位)

纠缠类型:

$$U_{MS}(\pi/2) = \exp\left(-i \frac{\pi}{4} (X_1 X_2 + Y_1 Y_2)\right)$$

  • 产生两 qubit Bell 态 (类似两比特门)

21.B.4 几何相位的图像

相空间 (Re($a$), Im($a$)):

  • 起点: $a(0) = 0$
  • 演化: $a(t) = \frac{\Omega}{\delta} (1 - e^{i \delta t}) (\sigma_+^{(1)} + \sigma_+^{(2)})$
  • 当 $t = 2\pi/\delta$: $a(2\pi/\delta) = 0$ (回到起点)
  • 净几何相位: $\gamma = \pi \Omega^2 / \delta^2$

关键: 几何相位只依赖圆的面积 ($\propto \Omega^2 / \delta^2$), 不依赖中间具体形状 → 容错。

21.B.5 容错性的"量化"

小扰动: $\delta \to \delta + \epsilon$, $\Omega \to \Omega + \eta$。

几何相位误差: $\Delta \gamma \sim O(\epsilon^2, \eta^2, \epsilon \eta)$ — 二阶!

对比动力学相位 (Cirac-Zoller 类型): 误差一阶。

结论: MS 几何相位对失谐涨落容错**10-100×。

21.C 附录 C: 离子链振动模详细分析

21.C.1 矩阵方法

$N$ 离子的振动哈密顿量 (在 $z$ 方向, 简化为纵向振动):

$$H = \sum_i \frac{p_i^2}{2m} + \frac{1}{2} m \omega_z^2 \sum_i z_i^2 + \frac{e^2}{8 \pi \epsilon_0} \sum_{i \neq j} \frac{1}{|z_i - z_j|}$$

平衡位置: $z_i^{(0)} = (i - (N+1)/2) \cdot z_0$

偏离平衡: $z_i = z_i^{(0)} + q_i$

展开到二阶:

$$H = \sum_i \frac{p_i^2}{2m} + \frac{1}{2} \sum_{ij} V_{ij} q_i q_j$$

势能矩阵 (对称):

$$V_{ii} = m \omega_z^2 + 2 \sum_{j \neq i} \frac{e^2}{4 \pi \epsilon_0 m (z_i^{(0)} - z_j^{(0)})^3}$$

$$V_{ij} = -\frac{e^2}{4 \pi \epsilon_0 m (z_i^{(0)} - z_j^{(0)})^3}, \quad i \neq j$$

21.C.2 简正模求解

特征方程: $V \mathbf{b}_p = \omega_p^2 \mathbf{b}_p$

结果: $N$ 个正交特征向量 $\mathbf{b}_p$, 频率 $\omega_p$ ($p = 1, ..., N$)

简正坐标: $Q_p = \sum_i b_{i,p} q_i$

独立简谐振子: $H = \sum_p \hbar \omega_p (a_p^\dagger a_p + 1/2)$

21.C.3 典型模 (N = 4 例子)

p=1 (COM):    [1, 1, 1, 1] / 2      频率 ω_1 = ω_z
p=2 (Stretch): [3, 1, -1, -3] / √20  频率 ω_2 = √3 ω_z
p=3 (内模):   [1, -1, -1, 1] / 2    频率 ω_3 = √(29/5) ω_z
p=4 (内模):   [1, -3, 3, -1] / √20  频率 ω_4 = √(29/5) ω_z

对称性: COM ($p=1$) 是完全均匀的, 拉伸 ($p=2$) 是反对称的, 内模 ($p \geq 3$) 是更复杂的相对运动。

21.C.4 大 N 极限

模频率 (连续近似):

$$\omega_p \approx \omega_z \sqrt{\frac{p(p+1)}{2}}, \quad p = 1, 2, ..., N$$

关键问题 (21.5.2 节): 频率间隔 $\omega_{p+1} - \omega_p \to 0$ (大 $N$)

定量 ($N = 50$):

  • $\omega_1 = \omega_z$ (1 MHz)
  • $\omega_{50} \approx \omega_z \sqrt{50 \cdot 51 / 2} \approx 36 \omega_z$ (36 MHz)
  • 平均间隔: $35/49 \approx 0.7 \omega_z = 0.7$ MHz
  • 相对间隔: $0.7 / 36 \approx 2\%$

结论: $N = 50$ 时接近模拥挤 → 难做高保真 MS。

21.C.5 与 ch21.4 MS gate 的衔接

MS gate 的"模无关性":

  • 失谐 $\delta$ 是任意小 (≪ $\omega_z - \omega_{z-1}$)
  • 双光子过程累加 $\sum_p \frac{g_p^2}{\omega_p - \omega_l}$ (所有模一起)
  • 净效果: 不依赖单模的精确参数 → 容错

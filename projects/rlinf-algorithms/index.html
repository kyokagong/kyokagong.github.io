RLInf BFM-zero P-BFM RPO RL

在 RLInf 上集成更多运控算法

GitHub Branch ↗ 查看全部项目

项目概述

围绕具身智能强化学习框架 RLInf 扩展前沿行为基础模型与运控算法支持。 通过在 RLInf 中集成 BFM-zero 与 P-BFM 算法， 使框架具备在人形机器人上训练 RPO 运动控制策略的能力。

核心亮点

  • BFM-zero 算法集成：将零样本行为基础模型（BFM-zero）训练与推理流程对接至 RLInf 框架。
  • P-BFM 算法集成：补充 P-BFM 算法实现，丰富 RLInf 的无监督/通用运控策略学习能力。
  • RPO 运控训练闭环：依托新增算法扩展，打通在 RLInf 上直接训练与评估 RPO 运动控制策略的完整链路。

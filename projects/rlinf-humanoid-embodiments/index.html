RLInf Humanoid Locomotion Real Robot

给 RLInf 添加人形机器人本体代码

GitHub Branch ↗ 查看全部项目

项目概述

面向具身智能训练框架 RLInf 扩展多款真实人形机器人本体支持。 通过个人采购的元点机器人，并结合合作导师实验室的 Bumi 与启元 Q1 硬件平台， 在 RLInf 上统一集成这些本体的运动控制训练能力。

核心亮点

  • 多本体适配扩展：覆盖元点机器人、Bumi、启元 Q1 等多款人形机器人硬件配置与本体描述。
  • RLInf 运控训练集成：打通各本体在 RLInf 框架中的环境配置、动作空间映射与运控策略训练流程。
  • 实机动作迁移验证：在真实机器人本体上开展舞蹈/动态运控动作部署与验证（如启元 Q1 跳 G1 舞蹈）。
